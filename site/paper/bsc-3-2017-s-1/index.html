BMC-31

B.Sc. Mathematics · Semester III2017
  1. 1(a) If \((L,U)\) denotes the section of rational numbers where \(L=\{x:x\le0\}\cup\{x>0\text{ and }x^2<2\}\) and \(U=\{x:x>0\text{ and }x^2>2\}\), then show that \(L\) has no greatest member and \(U\) has no least member. \hfill 4
  2. 1(b) Using Dedekind's section of real numbers prove that a non-empty subset of \(\mathbb R\) which has an upper bound has the least upper bound (lub). \hfill 4
  3. 1(c) Find closure of the following sets with proper justifications: (i) \(\mathbb R-\mathbb Z\)\quad ii) \(\mathbb Q-\mathbb Z\). \hfill 2
  4. 2(a) Define limit point of a set. Prove that if a set \(A\) has a limit point then \(A\) must be infinite. \hfill 3
  5. 2(b) Define open set in \(\mathbb R\). Show that complement of an open set in \(\mathbb R\) is a closed set. \hfill 3
  6. 2(c) Prove that for any two sets \(A,B\); \(\overline{A\cap B}\subset\overline A\cap\overline B\) but the reverse inclusion relation is not true in general. \hfill 2
  7. 2(d) Find the derived set of \(\left\{(-1)^n\frac{n}{n+1}: n\in\mathbb N\right\}\). \hfill 2
  8. 3(a) Prove that every open cover of a set \((\subset\mathbb R)\) has a countable subcover. \hfill 3
  9. 3(b) When is a set of \(\mathbb R\) said to be countable? If \(A\) and \(B\) are countable sets then prove that \(A\times B\) is countable. \hfill 4
  10. 3(c) Show that the set of all irrational numbers is uncountable. \hfill 3
  11. 4(a) If \(f\) is continuous on \([a,b]\) and \(f(a),f(b)\) are of opposite signs then show that there is \(\xi\in(a,b)\) such that \(f(\xi)=0\). \hfill 4
  12. 4(b) If \(f:[a,b]\to\mathbb R\) is non-decreasing, then prove that at any \(c\in(a,b)\), \hfill 4 \[ \text{i)}\quad f(c-0)=\sup_{x\in(a,c)}f(x) \qquad \text{ii)}\quad f(c+0)=\operatorname*{Inf}_{x\in(c,b)}f(x). \]
  13. 4(c) Show that if a function \(f\) is continuous on a closed interval \([a,b]\) then \(f\) is uniformly continuous on \([a,b]\). \hfill 2
  14. 5(a) Prove that the function \(f(x)=\dfrac{3}{3+x^2}\) is uniformly continuous on \((0,1)\). \hfill 3
  15. 5(b) Let a function \(f(x,y)\) is given by \hfill 2 \[ f(x,y)=\begin{cases} \dfrac{xy(x-y)}{x^2+y^2} & \text{if }(x,y)\ne(0,0)\\ 0 & \text{if }(x,y)=(0,0). \end{cases} \] Examine if the function \(f(x,y)\) is continuous at \((0,0)\).
  16. 5(c) Evaluate \(\displaystyle\operatorname*{\mathit{Lt}}_{(x,y)\to(0,0)}xy\frac{x^2-y^2}{x^2+y^2}\). \hfill 2
  17. 5(d) State Euler's theorem for a homogenous function of two variables and verify this theorem for the function \(u=\sin\frac{x^2+y^2}{xy}\). \hfill 3
  18. 6(a) When is a function \(f(x,y)\) said to be differentiable at \((a,b)\)? If \(f(x,y)\) is differentiable at \((a,b)\) then prove that (i) \(f(x,y)\) is continuous at \((a,b)\) and (ii) \(f_x\) and \(f_y\) exist at \((a,b)\). \hfill 3
  19. 6(b) Let \(f(x,y)=x\sin(4\tan^{-1}\frac{y}{x})\) for \(x>0\) and \(f(0,y)=0\) for all \(y\). Verify the following: \hfill 4 \begin{enumerate} \renewcommand{\labelenumi}{\roman{enumi})} \item Continuity of \(f_x(x,y)\) at \((0,0)\). \item Differentiability of \(f(x,y)\) at \((0,0)\). \end{enumerate}
  20. 6(c) If \(f(x,y)=|x^2-y^2|\), then find the value of \(f_{xy}(0,0)\) and \(f_{yx}(0,0)\). \hfill 3 \def\paperplural{s}
