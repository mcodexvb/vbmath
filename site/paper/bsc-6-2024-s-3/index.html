DSEMA-3A

B.Sc. Mathematics · Semester VI2024
  1. 1 What do you mean by a flowchart? Using standard symbols, draw a flowchart to calculate and print the value of $S$, where $S=\displaystyle\sum_{J=1}^{100}\sum_{I=1}^{30} I\times J$. [1+4]
  2. 2(a) Name different types of variables with appropriate examples which are recognised, by FORTRAN 77. [2]
  3. 2(b) Write down the FORTRAN expression of the following mathematical expression: \[\sinh\left(\frac{a^3+3d^2-\log_{10}d}{\tan(b^2+c^2)e^{-|x^3y|}}\right)+ \frac{x+n\cos^{-1}x}{\sqrt{2024+x^3y^3}}\] [2]
  4. 2(c) Given the logical variables $X,Y$ and $Z$, write a logical expression that is true if and only if $X$ and $Y$ are true and $Z$ is false. [1]
  5. 3(a) What values will be printed for the variables after execution of the following program: \begin{verbatim} INTEGER D LOGICAL B COMPLEX A CHARACTER*8 C READ*, X, Y, Z, A, B Y = Y * Y Z = X + Y + Z X = Y + Z C = 'HEATWAVE' B = .FALSE. D = A + X PRINT*, X, Y, Z, C, B, D STOP END \end{verbatim} The input data/line is given as \verb|2.0, 3.0, 5.0, (-1., 3.0), .TRUE.| \par\textbf{(You must mention all the necessary steps)} [3]
  6. 3(b) Design an algorithm to compute the factorial of a positive integer $n$. [2]
  7. 4(a) Write a FORTRAN 77 program to arrange a sequence of $n$ real numbers ($n\le2024$) in ascending order. [3]
  8. 4(b) Write a FORTRAN 77 statement to carry out the following actions: \par If $n=1,2,8$, transfer control to statement 20, if $n=3,7$, transfer control to the statement 21, if $n=4,5,6$ transfer control to the statement 22. [2]
  9. 5(a) Point out errors (if any) in the following. Justify your answer. \begin{verbatim} (i) GO TO(1,2,3,4), VALUE (ii) READ*, X, Y + 3, Z, Z5 (iii) TAN = TAN(X) * X ** 0.5 \end{verbatim}
  10. 5(b) Rewrite the following FORTRAN 77 segment using IF statements. \begin{verbatim} DO 10 I = 1, 100 DO 20 J = 1, 25 WRITE(*,1) I, J 20 CONTINUE 10 CONTINUE \end{verbatim} [2]
  11. 6(a) State (with examples) two important differences between ARITHMETIC IF statement and LOGICAL IF statement. [2]
