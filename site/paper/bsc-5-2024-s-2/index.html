CCMA-12

B.Sc. Mathematics · Semester V2024
  1. 1 Answer any five questions: [$5\times2=10$]
  2. 1(a) Round off the numbers 2.47235, 0.0035008, 42.3085, $-72.0506$ to three decimal places.
  3. 1(b) Show that the average operator $\mu$ and shift operator $E$ are commutative.
  4. 1(c) Prove or disprove: If the $n$-th forward difference of a polynomial is constant, then it is of degree $n$.
  5. 1(d) How big should the spacing $(h)$ be so that the error in computing $\int_0^1 e^x\,dx$, using the composite Trapezoidal rule, is less than or equal to $0.5\times10^{-5}$?
  6. 1(e) State one advantage and one disadvantage of Newton-Raphson method.
  7. 1(f) State the principle of numerical differentiation.
  8. 1(g) Prove or disprove: If $A$ is a strictly diagonally dominant matrix of order $n$, then $A^T$ is strictly diagonally dominant.
  9. 1(h) Compute $y(0.1)$, from the initial value problem $y'=x^2-y$, $y(0)=1$, taking $h=0.1$, by Modified Euler's method, correct to three decimal places.
  10. 2(a) What do you mean by memory overflow and underflow? Explain. [3]
  11. 2(b) Find the decimal equivalent to the following floating point machine number: \[\texttt{0 10000001010 1001001100000000000000000000000000000000000000000000}.\] [4]
  12. 2(c) Find absolute, relative and percentage error in $f(x)=4\cos x-6x-9$ for $x=0$ when the error in $x$ is 0.005. [3]
  13. 3(a) Show that $1-e^{-hD}\equiv-\frac{\delta^2}{2}+\delta\sqrt{1+\frac{\delta^2}{4}}$. [4]
  14. 3(b) Find a formula for $\Delta\left[\frac{f(x)}{g(x)}\right]$ and hence find $\Delta\left[\frac{2^x}{(x+1)!}\right]$, taking $h=1$. [3]
  15. 3(c) Show that $f(E)a^x=a^xf(a)$ where $f(E)$ is a polynomial of degree $n$ in $E$ taking unity as the interval of spacing. [3]
  16. 4(a) Considering the limit of the three point Lagrange's interpolating polynomial for the values $x_0,x_0+\epsilon$ and $x_1$ as $\epsilon\to0$, obtain the following formula \[\begin{aligned} f(x)={}&\frac{(x_1-x)(x+x_1-2x_0)}{(x_1-x_0)^2}f(x_0) +\frac{(x-x_0)(x_1-x)}{(x_1-x_0)}f'(x_0)\\ &+\frac{(x-x_0)^2}{(x_1-x_0)^2}f(x_1)+E(x), \end{aligned}\] where $E(x)=\frac16(x-x_0)^2(x-x_1)f'''(\xi)$, $\xi\in(x_0,x_1)$. [5]
  17. 4(b) The following table gives pressure $(P)$ of a steam plant at a given temperature $(T)$. \[\begin{array}{|c|c|c|c|c|c|}\hline T({}^\circ\mathrm C):&140&150&160&170&180\\\hline P(\mathrm{dyn/cm^2}):&3.685&4.854&6.302&8.076&10.225\\\hline \end{array}\] Using suitable interpolation formula, compute the pressure for a temperature of $172^\circ$C correct to three decimal places. [5]
  18. 5(a) Deduce numerical differentiation formula for the function $y=f(x)$ from Newton's backward interpolation formula at an interpolating point. Also derive the error involved in this formula. [2]
  19. 5(b) The solid of revolution obtained by rotating the region under the curve $y=f(x)$, $a\le x\le b$, about the $x$-axis has surface area given by \[A=2\pi\int_a^b y\sqrt{1+y'^2}\,dx.\] Find the surface area for the function $f(x)=\cos x$, $0\le x\le\frac{\pi}{4}$, using Weddle's rule by taking 13-ordinates. [5]
  20. 6(a) Discuss the convergence/divergence of the fixed point iteration method geometrically in solving one real root of the equation $f(x)=0$ or $x=\phi(x)$, for the cases $0<\phi'(x)<1$, $-1<\phi'(x)<0$, $\phi'(x)>1$ and $\phi'(x)<-1$. [5]
  21. 6(b) The iteration scheme \[x_{n+1}=x_n-\frac{3\log_e x_n-e^{-x_n}}{p}\] is used to find the real root of the equation $e^{-x}-3\log_e x=0$. Determine the value of $p$ for which the iteration scheme ensures the fastest possible convergence. [5]
  22. 7(a) Show that the $n$-th order forward difference of a function $f(x)$, which is continuously differentiable sufficient number of times, is related with its $n$-th order derivative by the following relation \[\Delta^n f(x)=h^n f^{(n)}(x)+O(h^n),\] where, $h$ is the step length and $O(h^n)$ is a function of the form $h^nR_n(x,h)$ such that $R_n(x,h)\to0$ as $h\to0$. [5]
  23. 7(b) Find the root of the equation $\log_{10}(x)+8=2x^2$ by Regula-Falsi method, correct to 6-significant figures. [5]
  24. 8(a) Carry out the total operational count required for solving a system of $n$ linear equations in $n$ unknowns by Gauss-Jordan elimination method. [5]
  25. 8(b) Solve the following system of equations \[\begin{aligned} x_1+x_2+4x_3&=9\\ 8x_1-3x_2+2x_3&=20\\ 4x_1+11x_2-x_3&=33 \end{aligned}\] using the Gauss-Seidel iteration method in error format correct to four decimal places. [5]
  26. 9(a) If $f(x,y)$ has continuous partial derivatives upto sufficient number of times for $(x,y)\in D$ where, $D=\{(x,y):a\le x\le b,-\infty<y<\infty\}$ then show that the grid error $E$ for a single-step method in solving the initial value problem $\frac{dy}{dx}=f(x,y)$, $y(a)=y_0$ is given by \[E=\frac{Kh^p}{M}\left(e^{(b-a)M}-1\right),\] where, $K$, $M$ are positive constants, $p$ is the order of the single-step method. [5]
  27. 9(b) Compute $y(0.2)$ from the initial value problem $\frac{dy}{dt}=t+t^2y$, $y(0)=1$ by Picard's method, correct to five decimal places. [5]
