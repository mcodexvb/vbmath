MMC-15

Partial Differential Equations
M.Sc. Mathematics · Semester I2024
  1. 1(a) When is a partial differential equation (PDE) said to be well-posed in the sense of Hadamard? [2]
  2. 1(b) Solve the the following Cauchy problem and find the value of $u(1/\sqrt2,1/\sqrt2)$. \[ x\frac{\partial u}{\partial y}-y\frac{\partial u}{\partial x}=u,\quad u(x,0)=\sin\left(\frac{\pi x}4\right). \] Also, characterize the nature of the integral surface so obtained. [3+1]
  3. 1(c) Obtain the singular integral of the following PDE and give its geometrical interpretation. \[ \left(x\frac{\partial u}{\partial x}+y\frac{\partial u}{\partial y}-u\right)^2 =1+\left(\frac{\partial u}{\partial x}\right)^2+\left(\frac{\partial u}{\partial y}\right)^2. \] [4]
  4. 2(a) Find by the Cauchy's method of characteristics the integral surface of the following PDE that passes through the curve $u=y$, $x=0$. \[ x\frac{\partial u}{\partial x}+y\frac{\partial u}{\partial y} =\frac{\partial u}{\partial x}\frac{\partial u}{\partial y}. \] [5]
  5. 2(b) Show that a linear PDE of the form \[ \sum_{r,s}C_{rs}x^ry^s\frac{\partial^{r+s}u}{\partial x^r\partial y^s}=f(x,y) \] can be reduced to one with constant coefficients by the substitutions: $\xi=\log_e x$ and $\eta=\log_e y$. Hence, find the complete integral of the following PDE. \[ x^2\frac{\partial^2u}{\partial x^2}-3xy\frac{\partial^2u}{\partial x\partial y} +2y^2\frac{\partial^2u}{\partial y^2}+5y\frac{\partial u}{\partial y}-2u=\cos[\log_e(xy)]. \]
  6. 3(a) Solve the following PDE by Monge's method. \[ xy\left(\frac{\partial^2u}{\partial x^2}-\frac{\partial^2u}{\partial y^2}\right) -(x^2-y^2)\frac{\partial^2u}{\partial x\partial y}+y\frac{\partial u}{\partial x}-x\frac{\partial u}{\partial y}=0. \] [5]
  7. 3(b) Find the two families of characteristics of the PDE, given by, \[ \frac{\partial^2u}{\partial x^2}-2\frac{\partial^2u}{\partial x\partial y} +\frac{\partial^2u}{\partial y^2}+\frac{\partial u}{\partial x}-\frac{\partial u}{\partial y}=e^{2x+3y} \] and hence convert the equation to a canonical form.
  8. 4(a) Using Laplace integral transform method, solve the following initial boundary value problem (IBVP): \[ \frac{\partial^2u}{\partial x^2}=\frac1{c^2}\frac{\partial^2u}{\partial t^2}-\cos(2t),\quad 0\leq x<\infty,\ 0\leq t<\infty, \] BC's: $u(0,t)=0$, $u(x,t)$ is bounded as $x\to\infty$, IC's: $u(x,0)=0$, $\frac{\partial u}{\partial t}|_{(x,0)}=0$. [5]
  9. 4(b) Solve the following PDE by using the finite Fourier sine transform method: \begin{align*} \frac{\partial u}{\partial t}&=4\frac{\partial^2u}{\partial x^2},\quad 0<x<2,\ t>0,\\ u(0,t)&=0=u(2,t),\quad t>0,\\ u(x,0)&=\begin{cases}x,&0\leq x\leq1\\2-x,&1\leq x\leq2.\end{cases} \end{align*} [5]
  10. 5(a) Find the value of $u(2,3)$ for the following PDE. \[ \frac{\partial^2u}{\partial x\partial y}+x^3y^2u=0,\qquad u(x,0)=e^{(x^4/4)}. \] [4]
  11. 5(b) If $u(x,t)=Ae^{-t}\sin x$ is a solution of the following IBVP, then find the value of $A$. \begin{align*} \frac{\partial u}{\partial t}&=\frac{\partial^2u}{\partial x^2},\quad 0<x<\pi,\ t>0,\\ u(0,t)&=0=u(\pi,t),\quad t>0,\\ u(x,0)&=\begin{cases}60,&0\leq x\leq\frac\pi2\\40,&\frac\pi2\leq x\leq\pi.\end{cases} \end{align*} [3]
  12. 5(c) Let $u(x,t)$ be a function that satisfies the PDE: \[ \frac{\partial^2u}{\partial x^2}-\frac{\partial^2u}{\partial t^2}=e^x+6t,\quad x\in\mathbb R,\ t>0, \] with $u,\frac{\partial u}{\partial x}\to0$ as $x\to\pm\infty$ and the initial conditions: $u(x,0)=\sin x$, $\frac{\partial u}{\partial t}|_{(x,0)}=0$ for every $x\in\mathbb R$. Find the value of $u(\frac\pi2,\frac\pi2)$. [3]
  13. 6(a) State maximum-minimum principle for a function $u(x,y)$, which is continuous in a closed region: $\overline{\mathbb R}$ ($=\mathbb R\cup\partial\mathbb R$) and which satisfies the Laplace equation: $\frac{\partial^2u}{\partial x^2}+\frac{\partial^2u}{\partial y^2}=0$ in the interior of $\mathbb R$. [2]
  14. 6(b) Prove that, if the Dirichlet problem has a solution $u(x,y)$, which is continuous in a bounded region: $\overline{\mathbb R}$ and which satisfies the Laplace equation: $\frac{\partial^2u}{\partial x^2}+\frac{\partial^2u}{\partial y^2}=0$ in the interior of $\mathbb R$, then it is unique. [2]
  15. 6(c) Solve the following Neumann problem for a rectangle. PDE: $\dfrac{\partial^2u}{\partial x^2}+\dfrac{\partial^2u}{\partial y^2}=0$, $0\leq x\leq a$, $0\leq y\leq b$, BC's: $\dfrac{\partial u}{\partial x}|_{(0,y)}=0=\dfrac{\partial u}{\partial x}|_{(a,y)}$, $\dfrac{\partial u}{\partial y}|_{(x,0)}=0$, $\dfrac{\partial u}{\partial y}|_{(x,b)}=f(x)$. [6]
