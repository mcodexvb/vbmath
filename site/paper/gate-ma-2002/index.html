GATE Mathematics · Mathematics (MA), 2002

  1. 1.1 The dimension of the vector space of all $3 \times 3$ real symmetric matrices is \begin{enumerate}[label=(\alph*)] \item $3$ \item $9$ \item $6$ \item $4$ \end{enumerate}
  2. 1.2 Let $A$ be a non-zero upper triangular matrix all of whose eigenvalues are $0$. Then $I + A$ is \begin{enumerate}[label=(\alph*)] \item invertible \item singular \item idempotent \item nilpotent \end{enumerate}
  3. 1.3 The eigenvalues of a skew-symmetric matrix are \begin{enumerate}[label=(\alph*)] \item negative \item real \item of absolute value $1$ \item purely imaginary or zero \end{enumerate}
  4. 1.4 The function $f(z) = z^2$ maps the first quadrant onto \begin{enumerate}[label=(\alph*)] \item itself \item upper half plane \item third quadrant \item right half plane \end{enumerate}
  5. 1.5 The radius of convergence of the power series of the function $f(z) = \dfrac{1}{1 - z}$ about $z = \dfrac{1}{4}$ is \begin{enumerate}[label=(\alph*)] \item $1$ \item $\dfrac{1}{4}$ \item $\dfrac{3}{4}$ \item $0$ \end{enumerate}
  6. 1.6 Let $\Gamma$ be any circle enclosing the origin and oriented counter-clockwise. Then the value of the integral $\displaystyle\int_\Gamma \frac{\cos z}{z^2}\,dz$ is \begin{enumerate}[label=(\alph*)] \item $2\pi i$ \item $0$ \item $-2\pi i$ \item undefined \end{enumerate}
  7. 1.7 Suppose $S_1$, $S_2$, and $S_3$ are measurable subsets of $[0,1]$, each of measure $3/4$, such that the measure of $S_1 \cup S_2 \cup S_3$ is $1$. Then, the measure of $S_1 \cap S_2 \cap S_3$ lies in \begin{enumerate}[label=(\alph*)] \item $\left[0, \dfrac{1}{16}\right]$ \item $\left[\dfrac{1}{16}, \dfrac{1}{8}\right]$ \item $\left[\dfrac{1}{8}, \dfrac{1}{4}\right]$ \item $\left[\dfrac{1}{4}, 1\right]$ \end{enumerate}
  8. 1.8 Let $f : [0,1] \to \mathbb{R}$ be a bounded Riemann integrable function and let $g : \mathbb{R} \to \mathbb{R}$ be continuous. Then $g \circ f$ is \begin{enumerate}[label=(\alph*)] \item Riemann integrable \item continuous \item Lebesgue integrable, but not Riemann integrable \item not necessarily measurable \end{enumerate}
  9. 1.9 Let $V$ be the volume of a region bounded by a smooth closed surface $S$. Let $\mathbf{r}$ denote the position vector and $\hat{\mathbf{n}}$ denote the outward unit normal to $S$. Then the integral $\displaystyle\iint_S \mathbf{r} \cdot \hat{\mathbf{n}}\,dS$ equals \begin{enumerate}[label=(\alph*)] \item $V$ \item $\dfrac{V}{3}$ \item $3V$ \item $0$ \end{enumerate}
  10. 1.10 Let $G$ be a cyclic group of order $6$. Then the number of elements $g \in G$ such that $G = \langle g \rangle$ is \begin{enumerate}[label=(\alph*)] \item $5$ \item $3$ \item $4$ \item $2$ \end{enumerate}
  11. 1.11 The number of elements of order $5$ in the symmetric group $S_5$ is \begin{enumerate}[label=(\alph*)] \item $5$ \item $20$ \item $12$ \item $24$ \end{enumerate}
  12. 1.12 The order of the element $(\bar{2}, \bar{2})$ in $\mathbb{Z}_4 \times \mathbb{Z}_6$ is \begin{enumerate}[label=(\alph*)] \item $2$ \item $6$ \item $4$ \item $12$ \end{enumerate}
  13. 1.13 Which of the following Banach spaces is not separable? \begin{enumerate}[label=(\alph*)] \item $L^1[0,1]$ \item $L^\infty[0,1]$ \item $L^2[0,1]$ \item $C[0,1]$ \end{enumerate}
  14. 1.14 For a subset $A$ of a metric space, which of the following implies the other three? \begin{enumerate}[label=(\alph*)] \item $A$ is closed \item $A$ is bounded \item Closure of $B$ is compact for every $B \subseteq A$ \item $A$ is compact \end{enumerate}
  15. 1.15 Let $n$ be a nonnegative integer. The eigenvalues of the Sturm--Liouville problem \[ \frac{d^2y}{dx^2} + \lambda y = 0, \] with boundary conditions $y(0) = y(2\pi)$, $\dfrac{dy}{dx}(0) = \dfrac{dy}{dx}(2\pi)$, are \begin{enumerate}[label=(\alph*)] \item $n$ \item $n^2\pi^2$ \item $n\pi$ \item $n^2$ \end{enumerate}
  16. 1.16 The Bessel's functions $\{J_0(\alpha_k x)\}_{k=1}^{\infty}$ with $\alpha_k$ denoting the $k$-th zero of $J_0(x)$ form an orthogonal system on $[0,1]$ with respect to weight function \begin{enumerate}[label=(\alph*)] \item $1$ \item $x^2$ \item $x$ \item $\sqrt{x}$ \end{enumerate}
  17. 1.17 Linear combinations of solutions of an ordinary differential equation are also solutions if the differential equation is \begin{enumerate}[label=(\alph*)] \item Linear nonhomogeneous \item Linear homogeneous \item Nonlinear homogeneous \item Nonlinear nonhomogeneous \end{enumerate}
  18. 1.18 Which of the following, concerning the solution of the Neumann problem for Laplace's equation on a smooth bounded domain, is true? \begin{enumerate}[label=(\alph*)] \item Solution is unique \item Solution is unique up to an additive constant \item Solution is unique up to a multiplicative constant \item No conclusion can be drawn about uniqueness \end{enumerate}
  19. 1.19 Which of the following satisfies the heat equation (without source terms and with diffusion constant $1$) in one space dimension? \begin{enumerate}[label=(\alph*)] \item $\sin\!\left(\dfrac{x^2}{4t}\right)$ \item $e^t\sin x$ \item $x^2 - t$ \item $\dfrac{e^{-x^2/(4t)}}{\sqrt{t}}$ \end{enumerate}
  20. 1.20 Which of the following is elliptic? \begin{enumerate}[label=(\alph*)] \item Laplace equation \item Wave equation \item Heat equation \item $u_{xx} + 2u_{xy} - 4u_{yy} = 0$ \end{enumerate}
  21. 1.21 Consider the motion of a three-particle system in the $3$-dimensional space. Suppose that all pairs of particles are at invariant distance apart, so that the system constitutes a rigid body. For such a system, the number of degrees of freedom is \begin{enumerate}[label=(\alph*)] \item $6$ \item $3$ \item $1$ \item $9$ \end{enumerate}
  22. 1.22 If $f(x)$ has an isolated zero of multiplicity $3$ at $x = \xi$, and the iteration \[ x_{n+1} = x_n - \frac{3f(x_n)}{f'(x_n)}, \qquad n = 0, 1, 2, \dots, \] converges to $\xi$, then the rate of convergence is \begin{enumerate}[label=(\alph*)] \item linear \item faster than linear but slower than quadratic \item quadratic \item cubic \end{enumerate}
  23. 1.23 The best possible error estimate in the Gauss--Hermite formula with $3$ points, for calculating the integral $\displaystyle\int_{-\infty}^{\infty} x^4 e^{-x^2}\,dx$, is \begin{enumerate}[label=(\alph*)] \item $0$ \item $0.30$ \item $0.65$ \item $1.20$ \end{enumerate}
  24. 1.24 Let $P(X = n) = \dfrac{\lambda}{n^2(n+1)}$, $n = 1, 2, \dots$, where $\lambda$ is an appropriate constant. Then $E(X)$ is \begin{enumerate}[label=(\alph*)] \item $2\lambda + 1$ \item $\lambda$ \item $\infty$ \item $2\lambda$ \end{enumerate}
  25. 1.25 Let $x$ be a non-optimal feasible solution of a linear programming maximization problem and $y$ a dual feasible solution. Then \begin{enumerate}[label=(\alph*)] \item The primal objective value at $x$ is greater than the dual objective value at $y$ \item The primal objective value at $x$ could equal the dual objective value at $y$ \item The primal objective value at $x$ is less than the dual objective value at $y$ \item The dual could be unbounded \end{enumerate}
  26. 2.1 Let $A$ be a $3 \times 3$ matrix with eigenvalues $1, -1, 0$. Then the determinant of $I + A^{100}$ is \begin{enumerate}[label=(\alph*)] \item $6$ \item $4$ \item $9$ \item $100$ \end{enumerate}
  27. 2.2 Let $A$ be a $2 \times 2$ orthogonal matrix of trace $1$ and determinant $1$. Then the angle between $Au$ and $u$ ($u = [1\;\;0]^t$) is \begin{enumerate}[label=(\alph*)] \item $15^\circ$ \item $30^\circ$ \item $45^\circ$ \item $60^\circ$ \end{enumerate}
  28. 2.3 Let $w(z) = \dfrac{az + b}{cz + d}$ and $f(z) = \dfrac{\alpha z + \beta}{\gamma z + \delta}$ be bilinear (M\"obius) transformations. Then the following is also a bilinear transformation: \begin{enumerate}[label=(\alph*)] \item $f(z)w(z)$ \item $f(w(z))$ \item $f(z) + w(z)$ \item $f(z) + \dfrac{1}{w(z)}$ \end{enumerate}
  29. 2.4 For the function $f(z) = \sin\dfrac{1}{z}$, $z = 0$ is a \begin{enumerate}[label=(\alph*)] \item removable singularity \item simple pole \item branch point \item essential singularity \end{enumerate}
  30. 2.5 Pick out the largest of the sets given below on which the sequence of functions $\{e^{-n\cos^2 x}\}_{n=1}^{\infty}$ converges uniformly: \begin{enumerate}[label=(\alph*)] \item $\left[0, \dfrac{9\pi}{20}\right) \cup \left(\dfrac{11\pi}{20}, \pi\right]$ \item $\left[0, \dfrac{\pi}{2}\right) \cup \left(\dfrac{\pi}{2}, \pi\right]$ \item $\left[0, \dfrac{\pi}{2} - \delta\right) \cup \left(\dfrac{\pi}{2} + \delta, \pi\right]$, $0 < \delta < \dfrac{\pi}{100}$ \item $[0, \pi]$ \end{enumerate}
  31. 2.6 Let $f : \mathbb{R}^2 \to \mathbb{R}$ be a smooth function with positive definite Hessian at every point. Let $(a, b) \in \mathbb{R}^2$ be a critical point of $f$. Then \begin{enumerate}[label=(\alph*)] \item $f$ has a global minimum at $(a, b)$ \item $f$ has a local, but not a global minimum at $(a, b)$ \item $f$ has a local, but not a global maximum at $(a, b)$ \item $f$ has a global maximum at $(a, b)$ \end{enumerate}
  32. 2.7 Let $G$ be a group of order $30$. Let $A$ and $B$ be normal subgroups of orders $2$ and $5$ respectively. Then the order of the group $G / AB$ is \begin{enumerate}[label=(\alph*)] \item $10$ \item $3$ \item $2$ \item $5$ \end{enumerate}
  33. 2.8 Let $m$ and $n$ be coprime natural numbers. Then the kernel of the ring homomorphism $\phi : \mathbb{Z} \to \mathbb{Z}_m \times \mathbb{Z}_n$ defined by $\phi(x) = (\bar{x}, \bar{x})$ is \begin{enumerate}[label=(\alph*)] \item $m\mathbb{Z}$ \item $mn\mathbb{Z}$ \item $n\mathbb{Z}$ \item $\mathbb{Z}$ \end{enumerate}
  34. 2.9 Consider the Banach space $C[0, \pi]$ with the supremum norm. The norm of the linear functional $l : C[0, \pi] \to \mathbb{R}$, given by $l(f) = \displaystyle\int_0^\pi f(x)\sin^2 x\,dx$, is \begin{enumerate}[label=(\alph*)] \item $1$ \item $\dfrac{\pi}{2}$ \item $\pi$ \item $2\pi$ \end{enumerate}
  35. 2.10 The topology on the real line $\mathbb{R}$ generated by left-open right-closed intervals $(a, b]$ is \begin{enumerate}[label=(\alph*)] \item strictly coarser than the usual topology \item strictly finer than the usual topology \item not comparable with the usual topology \item same as the usual topology \end{enumerate}
  36. 2.11 Let $X, Y$ be topological spaces and $f : X \to Y$ be a continuous and bijective map. Then $f$ is a homeomorphism if \begin{enumerate}[label=(\alph*)] \item $X$ and $Y$ are compact \item $X$ is Hausdorff and $Y$ is compact \item $X$ is compact and $Y$ is Hausdorff \item $X$ and $Y$ are Hausdorff \end{enumerate}
  37. 2.12 If the integrating factor of $(x^7 y^2 + 3y)\,dx + (3x^8 y - x)\,dy = 0$ is $x^m y^n$, then \begin{enumerate}[label=(\alph*)] \item $m = -7,\ n = 1$ \item $m = 1,\ n = -7$ \item $m = n = 0$ \item $m = n = 1$ \end{enumerate}
  38. 2.13 The initial value problem $(x^2 - x)\dfrac{dy}{dx} = (2x - 1)y$, $y(x_0) = y_0$, has a unique solution if $(x_0, y_0)$ equals \begin{enumerate}[label=(\alph*)] \item $(2, 1)$ \item $(1, 1)$ \item $(0, 0)$ \item $(0, 1)$ \end{enumerate}
  39. 2.14 If $u$ is harmonic on $\{(x,y) \mid x^2 + y^2 \le 1\}$, then $\displaystyle\int_0^{2\pi} \frac{\partial u}{\partial n}\,d\theta$ (where $\dfrac{\partial u}{\partial n}$ is the normal derivative of $u$ on the boundary of the unit disc) equals \begin{enumerate}[label=(\alph*)] \item $2\pi$ \item $1$ \item $\pi$ \item $0$ \end{enumerate}
  40. 2.15 Let $u$ be a solution of the initial value problem \[ \frac{\partial^2 u}{\partial t^2} - \frac{\partial^2 u}{\partial x^2} = 0; \qquad u(x,0) = x^2, \quad \frac{\partial u}{\partial t}(x,0) = 0. \] Then $u(0, 1)$ equals \begin{enumerate}[label=(\alph*)] \item $1$ \item $0$ \item $2$ \item $\dfrac{1}{2}$ \end{enumerate}
  41. 2.16 Euler's equations of motion of a rigid body about a fixed point $O$ in the absence of external forces are \begin{align*} A\frac{d\omega_1}{dt} - (B - C)\omega_2\omega_3 &= 0, \\ B\frac{d\omega_2}{dt} - (C - A)\omega_3\omega_1 &= 0, \\ C\frac{d\omega_3}{dt} - (A - B)\omega_1\omega_2 &= 0, \end{align*} where $\omega_1, \omega_2, \omega_3$ are components of the angular velocity of the rigid body in the direction of principal axes of inertia at $O$; $A, B, C$ are principal moments of inertia at $O$. Let $T$ denote the kinetic energy during the motion and $h$ the magnitude of the angular momentum of the body about $O$. Then, during the motion \begin{enumerate}[label=(\alph*)] \item $T$ and $h$ both vary \item $T$ varies but $h$ remains constant \item $T$ remains constant but $h$ varies \item $T$ and $h$ both remain constant \end{enumerate}
  42. 2.17 The fourth divided difference of the polynomial $3x^3 + 11x^2 + 5x + 71$ over the points $x = 0, 1, 4, 6$, and $7$ is \begin{enumerate}[label=(\alph*)] \item $18$ \item $11$ \item $3$ \item $0$ \end{enumerate}
  43. 2.18 The degree of the polynomial of least degree interpolating the data $(0, 4), (1, 5), (2, 8), (3, 13)$ is \begin{enumerate}[label=(\alph*)] \item $4$ \item $3$ \item $2$ \item $1$ \end{enumerate}
  44. 2.19 For the matrix \[ \begin{bmatrix} 0 & 1 & -1 & 1 \\ 1 & 0 & 0 & 2 \\ -1 & 0 & 0 & 0 \\ 1 & 2 & 0 & 0 \end{bmatrix}, \] the bound for the eigenvalues predicted by Gershgorin's theorem is \begin{enumerate}[label=(\alph*)] \item $3$ \item $1$ \item $2$ \item $4$ \end{enumerate}
  45. 2.20 An extremal of the functional $I[y(x)] = \displaystyle\int_a^b F\!\left(x, y, \frac{dy}{dx}\right)dx$; $y(a) = y_1$, $y(b) = y_2$, satisfies Euler's equation, which in general \begin{enumerate}[label=(\alph*)] \item is a second order linear ordinary differential equation (ODE) \item is a nonlinear ODE of order greater than two \item admits a unique solution satisfying the conditions $y(a) = y_1$, $y(b) = y_2$ \item may not admit a solution satisfying the conditions $y(a) = y_1$, $y(b) = y_2$ \end{enumerate}
  46. 2.21 A lot of $1000$ screws contains $1\%$ with major defects and $5\%$ with minor defects. If $50$ screws are picked at random and inspected, then the ordered pair (expected number of major defectives, expected number of minor defectives) is \begin{enumerate}[label=(\alph*)] \item $(1, 5)$ \item $(2.5, 0.5)$ \item $(0.5, 2.5)$ \item $(5, 1)$ \end{enumerate}
  47. 2.22 The sample correlation of the transformed random variables $aX + b$ and $cY + d$ is the same as that of $X$ and $Y$ provided \begin{enumerate}[label=(\alph*)] \item $ac < 0;\ b, d \in (0, \infty)$ \item $ac < 0;\ b, d \in (-\infty, 0)$ \item $ac > 0;\ b, d \in \mathbb{R}$ \item $ac < 0;\ b, d \in \mathbb{R}$ \end{enumerate}
  48. 2.23 There are two identical locks, with two identical keys, and the keys are among the six different ones which a person carries in his pocket. In a hurry he drops one key somewhere. Then the probability that the locks can still be opened by drawing one key at random is equal to \begin{enumerate}[label=(\alph*)] \item $\dfrac{1}{3}$ \item $\dfrac{5}{6}$ \item $\dfrac{1}{30}$ \item $\dfrac{1}{12}$ \end{enumerate}
  49. 2.24 The system $Ax \le 0$, where $A$ is an $n \times n$ matrix, \begin{enumerate}[label=(\alph*)] \item may not have a nonzero solution \item always has a nonzero solution \item always has at least $2$ linearly independent solutions \item always has at least $n$ linearly independent solutions \end{enumerate}
  50. 2.25 Consider the following linear program $P$: \[ \max \sum_{j=1}^{n} c_j x_j \qquad \text{subject to } \sum_{j=1}^{n} a_{ij} x_j \le b_i \;\; (1 \le i \le m) \quad \text{and} \quad x_j \ge 0 \;\; (1 \le j \le n). \] Suppose that we are keeping the $c_j$ and $a_{ij}$ fixed and varying the $b_i$'s. Suppose that $P$ is unbounded for some set of the parameter values $b_i$. Then, for every choice of $b_i$, \begin{enumerate}[label=(\alph*)] \item $P$ is unbounded or infeasible \item $P$ is unbounded \item The dual problem to $P$ has a finite optimum \item The dual problem to $P$ is unbounded \end{enumerate}
  51. 3 Let $J_n$ be the $n \times n$ matrix each of whose entries equals $1$. Find the nullity and the characteristic polynomial of $J_n$.
  52. 4 Evaluate the integral $\displaystyle\int_{-\infty}^{\infty} \frac{dx}{(x^2 + a^2)^2}$, $a > 0$, by the method of residue calculus.
  53. 5 Let $a, b$ be real numbers with $0 < a < b$. Define sequences $\{a_n\}$ and $\{b_n\}$ recursively by \[ a_{n+1} = \sqrt{a_n b_n} \qquad \text{and} \qquad b_{n+1} = \frac{a_n + b_n}{2}, \qquad \text{where } a_1 = a,\ b_1 = b. \] Show that $\{a_n\}$ is an increasing sequence, $\{b_n\}$ is a decreasing sequence, and both converge to the same limit.
  54. 6 Let $f(t)$ be a real-valued continuous function on $[0, 1]$ such that \[ \int_0^1 f(t) t^n\,dt = 0 \qquad \text{for all } n = 0, 1, 2, \dots \] Prove that $f(t)$ vanishes identically.
  55. 7 Let $p$ be a prime and $q$ be a prime divisor of $2^p - 1$. Find the order of $\bar{2}$ (the residue class of $2$) in the multiplicative group $G$ of non-zero residue classes of integers modulo $q$. Conclude that $q > p$.
  56. 8 Let $X$ be an infinite dimensional Banach space. Prove that $X$ cannot have countable dimension as a vector space.
  57. 9 Show that $X$ is a Hausdorff topological space if and only if the diagonal $\Delta$ defined by \[ \Delta = \{(x, y) \in X \times X \mid x = y\} \] is a closed subset of $X \times X$ (with product topology).
  58. 10 Find the general solution of the differential equation \[ \frac{d^4y}{dx^4} - y = x\sin x. \]
  59. 11 Find the general solution of the differential equation [\textit{equation clipped/illegible in source PDF scan on page 28}] in powers of $(x - 1)$ using the Frobenius method.
  60. 12 Solve the initial value problem \[ \frac{\partial^2 u}{\partial t^2} - \frac{\partial^2 u}{\partial x^2} = 0, \qquad t > 0,\ x \in (-\infty, \infty), \] \[ u(x, 0) = x, \qquad \frac{\partial u}{\partial t}(x, 0) = \frac{x}{1 + x^2}. \]
  61. 13 Consider the initial value problem \[ \frac{\partial u}{\partial y} + u\frac{\partial u}{\partial x} = 0, \qquad y > 0,\ x \in \mathbb{R}, \qquad u(x, 0) = f(x). \] Show that the solution is constant along the characteristics. Hence deduce that if $f$ is decreasing monotonically, the solution cannot exist as a single valued function for all $y > 0$.
  62. 14 Consider a pendulum consisting of a bob of mass $m$ at the end of a rod of length $a$. If the bob is pulled to one side through an angle $\alpha$ to the downward vertical and released, show that the time required for one complete oscillation is given by \[ T = 4\sqrt{\frac{a}{g}}\int_0^{\pi/2} \frac{d\phi}{\sqrt{1 - k^2\sin^2\phi}}, \] where $k = \sin\!\left(\dfrac{\alpha}{2}\right)$ and $g$ is the acceleration due to gravity. Assume that the mass of the rod and the air resistance are negligible.
  63. 15 Determine the $LU$ decomposition of the matrix \[ A = \begin{bmatrix} 5 & -2 & -3 \\ 20 & -5 & -13 \\ 35 & -5 & -17 \end{bmatrix} \] with $L$ having all its diagonal entries $1$; and hence solve the system $AX = [0\;\;2\;\;13]^t$.
  64. 16 Using the Runge--Kutta method of order $4$ and taking the step size $h = 0.1$, determine $y(0.1)$, where $y(x)$ is the solution of \[ \frac{dy}{dx} + 2xy^2 = 0, \qquad y(0) = 1. \]
  65. 17 Solve the integral equation \[ \phi(x) = x + \int_0^1 (x - \xi)\phi(\xi)\,d\xi. \]
  66. 18 Let $X_1, X_2, \dots, X_{100}$ be independent and identical Poisson random variables with parameter $\lambda = 0.03$. Let $S = \displaystyle\sum_{i=1}^{100} X_i$. Use the Central Limit Theorem to evaluate $P(\{S \ge 3\})$ and compare the result with the exact probability of the event $\{S \ge 3\}$.
  67. 19 Let $X_1, X_2, \dots, X_n$ be a random sample from exponential density $f_\theta(x) = \theta e^{-\theta x}$, $x \ge 0$, $\theta > 0$. Find the maximum likelihood estimate (MLE) of $\theta$. Also, find the MLE of $P_\theta(X_1 \ge 1)$. Further show that both the estimators are consistent.
  68. 20 \begin{itemize} \item[(a)] Let $X \sim B(n_1, p_1)$ and $Y \sim B(n_2, p_2)$ where $p_1$ and $p_2$ are unknowns. Further, let $X$ and $Y$ be statistically independent. Construct an approximate $100(1-\alpha)\%$ confidence interval for $(p_1 - p_2)$. \hfill [3] \item[(b)] An antibiotic for pneumonia was injected into $100$ patients with kidney malfunctions (uremic patients) and into $100$ patients with no kidney malfunctions (normal patients). Some allergic reaction developed in $38$ of the uremic patients and in $21$ of the normal patients. Use the result in part (a) to construct a $95\%$ confidence interval for the difference between the two population proportions (Use the appropriate table value $Z_{0.025} = 1.960$, $Z_{0.05} = 1.645$). \hfill [2] \end{itemize}
  69. 21 Consider the Linear Program \[ \max \sum_{i=1}^{4} c_i x_i \qquad \text{subject to } \sum_{i=1}^{4} a_i x_i \le a_0, \quad 0 \le x_1, x_2, x_3, x_4 \le 1, \] where $a_i > 0$, $c_i > 0$ for $i = 1, 2, 3, 4$ and $a_0 > 0$. \begin{itemize} \item[(i)] Write the dual of this Linear Programming Problem. \hfill [3] \item[(ii)] Assuming $\dfrac{c_1}{a_1} \ge \dfrac{c_2}{a_2} \ge \dfrac{c_3}{a_3} \ge \dfrac{c_4}{a_4}$, $a_1 + a_2 \le a_0$, and $a_1 + a_2 + a_3 > a_0$, show that the feasible solution $x_1 = x_2 = 1$, $x_3 = \dfrac{a_0 - a_1 - a_2}{a_3}$, $x_4 = 0$, is an optimal solution. \hfill [2] \end{itemize}
  70. 22 Consider the optimal assignment problem, in which $n$ persons $P_1, P_2, \dots, P_n$ are to be assigned $n$ jobs $J_1, J_2, \dots, J_n$ and where the effectiveness rating of the person $P_i$ for the job $J_j$ is $a_{ij} > 0$. The objective is to find an assignment of persons to jobs, that is, a permutation $\sigma : \{1, 2, \dots, n\} \to \{1, 2, \dots, n\}$ which assigns person $P_i$ to job $J_{\sigma(i)}$, so as to maximize the total effectiveness $\displaystyle\sum_{i=1}^{n} a_{i,\sigma(i)}$. Show that in any optimal assignment, at least one person is assigned a job at which he is best.
