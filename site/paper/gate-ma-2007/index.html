  1. 1 Consider $\mathbb{R}^2$ with the usual topology. Let $S = \{(x, y) \in \mathbb{R}^2 : x \text{ is an integer}\}$. Then $S$ is \begin{enumerate}[label=(\Alph*)] \item open but NOT closed \item both open and closed \item neither open nor closed \item closed but NOT open \end{enumerate}
  2. 2 Suppose $X = \{\alpha, \beta, \delta\}$. Let $\mathcal{T}_1 = \{\phi, X, \{\alpha\}, \{\alpha, \beta\}\}$ and $\mathcal{T}_2 = \{\phi, X, \{\alpha\}, \{\beta, \delta\}\}$. Then \begin{enumerate}[label=(\Alph*)] \item both $\mathcal{T}_1 \cap \mathcal{T}_2$ and $\mathcal{T}_1 \cup \mathcal{T}_2$ are topologies \item neither $\mathcal{T}_1 \cap \mathcal{T}_2$ nor $\mathcal{T}_1 \cup \mathcal{T}_2$ is a topology \item $\mathcal{T}_1 \cup \mathcal{T}_2$ is a topology but $\mathcal{T}_1 \cap \mathcal{T}_2$ is NOT a topology \item $\mathcal{T}_1 \cap \mathcal{T}_2$ is a topology but $\mathcal{T}_1 \cup \mathcal{T}_2$ is NOT a topology \end{enumerate}
  3. 3 For a positive integer $n$, let $f_n : \mathbb{R} \to \mathbb{R}$ be defined by \[ f_n(x) = \begin{cases} \dfrac{1}{4n + 5}, & \text{if } 0 \le x \le n, \\ 0, & \text{otherwise.} \end{cases} \] Then $\{f_n(x)\}$ converges to zero \begin{enumerate}[label=(\Alph*)] \item uniformly but NOT in $L^1$ norm \item uniformly and also in $L^1$ norm \item pointwise but NOT uniformly \item in $L^1$ norm but NOT pointwise \end{enumerate}
  4. 4 Let $P_1$ and $P_2$ be two projection operators on a vector space. Then \begin{enumerate}[label=(\Alph*)] \item $P_1 + P_2$ is a projection if $P_1 P_2 = P_2 P_1 = 0$ \item $P_1 - P_2$ is a projection if $P_1 P_2 = P_2 P_1 = 0$ \item $P_1 + P_2$ is a projection \item $P_1 - P_2$ is a projection \end{enumerate}
  5. 5 Consider the system of linear equations \[ x + y + z = 3, \qquad x - y - z = 4, \qquad x - 5y + kz = 6. \] Then the value of $k$ for which this system has an infinite number of solutions is \begin{enumerate}[label=(\Alph*)] \item $k = -5$ \item $k = 0$ \item $k = 1$ \item $k = 3$ \end{enumerate}
  6. 6 Let $A = \begin{bmatrix} 1 & 1 & 1 \\ 2 & 2 & 3 \\ x & y & z \end{bmatrix}$ and let $V = \{(x, y, z) \in \mathbb{R}^3 : \det(A) = 0\}$. Then the dimension of $V$ equals \begin{enumerate}[label=(\Alph*)] \item $0$ \item $1$ \item $2$ \item $3$ \end{enumerate}
  7. 7 Let $S = \{0\} \cup \left\{\dfrac{1}{4n + 7} : n = 1, 2, \dots\right\}$. Then the number of analytic functions which vanish only on $S$ is \begin{enumerate}[label=(\Alph*)] \item infinite \item $0$ \item $1$ \item $2$ \end{enumerate}
  8. 8 It is given that $\displaystyle\sum_{n=0}^{\infty} a_n z^n$ converges at $z = 3 + i4$. Then the radius of convergence of the power series $\displaystyle\sum_{n=0}^{\infty} a_n z^n$ is \begin{enumerate}[label=(\Alph*)] \item $\le 5$ \item $\ge 5$ \item $< 5$ \item $> 5$ \end{enumerate}

  12. 12 Consider the linear programming problem: $\max z = c_1 x_1 + c_2 x_2$, $c_1, c_2 > 0$, subject to $x_1 + x_2 \le 3$, $2x_1 + 3x_2 \le 4$, $x_1, x_2 \ge 0$. Then \begin{enumerate}[label=(\Alph*)] \item the primal has an optimal solution but the dual does NOT have an optimal solution \item both the primal and the dual have optimal solutions \item the dual has an optimal solution but the primal does NOT have an optimal solution \item neither the primal nor the dual has optimal solutions \end{enumerate}

  14. 14 Let $X$ and $Y$ be jointly distributed random variables having the joint probability density function \[ f(x, y) = \begin{cases} \dfrac{1}{\pi}, & \text{if } x^2 + y^2 \le 1, \\ 0, & \text{otherwise.} \end{cases} \] Then $P(Y > \max(X, -X)) =$ \begin{enumerate}[label=(\Alph*)] \item $\dfrac{1}{2}$ \item $\dfrac{1}{3}$ \item $\dfrac{1}{4}$ \item $\dfrac{1}{6}$ \end{enumerate}
