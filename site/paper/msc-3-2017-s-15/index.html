MMO-31(P4)

Advanced Complex Analysis-I
M.Sc. Mathematics · Semester III2017
  1. 1(a) Prove that a necessary and sufficient condition for a function $f(z)=u(x,y)+iv(x,y)$ to be analytic in a domain $D$ is that its real part $u(x,y)$ and imaginary part $v(x,y)$ be conjugate harmonic functions in $D$. [3]
  2. 1(b) Prove that any analytic function defined in a domain $D$ has the mean value property in $D$. [2]
  3. 1(c) State and prove Poisson's integral formula. [3]
  4. 1(d) Let $f(z)$ be a function regular in the closed disc $|z|\le R$ and let $u(r,\theta)$ be its real part. If $u(r,\theta)\ge0$ throughout the disc, then prove that\par \[\frac12u(0,0)\le u(r,\theta)\le2u(0,0),\ 0\le\theta\le2\pi,\ 0\le r\le R.\] [2]
  5. 2(a) Let $u(x,y)$ and $v(x,y)$ be two harmonic functions in a bounded domain $D$ and continuous in $\bar D$. If $u(x,y)=v(x,y)$ on the boundary of $D$, then show that $u(x,y)=v(x,y)$ in $\bar D$. [2]
  6. 2(b) Let $f(z)$ be a non-constant analytic function in $|z|<R$ and $M(r)$ denote the maximum value of $|f(z)|$ on $|z|=r$. Then show that $M(r)$ is a steadily increasing function of $r$ in $0\le r<R$. [2]
  7. 2(c) If $f(z)=\displaystyle\sum_{n=0}^{\infty}a_nz^n\ (|z|<\infty)$, then show that $|a_n|r^n+2Rl\{f(0)\}\le\max\{4A(r),0\}$ for all values of $n>0,\ r>0$. [4]
  8. 2(d) If $f(z)$ is analytic for all finite values of $z$ and $A(r)$ is bounded, then prove that $f(z)$ is constant. [2]
  9. 3(a) Let $f(z)$ be an analytic function regular in $|z|\le R$ and $M(r)$ and $A(r)$ denote respectively the maximum value of $|f(z)|$ and $Rl\{f(z)\}$ on $|z|=r$. Then show that\par \[\max_{|z|=r}\left|f^{(n)}(z)\right|\le\frac{2^{n+2}n!R}{(R-r)^{n+1}}\left\{A(R)+|f(0)|\right\}.\] [3]
  10. 3(b) If $f(z)$ is an integral function with $f(0)\ne0$, then show that $f(z)=f(0)G(z)e^{g(z)}$, where $G(z)$ is a product of primary factors and $g(z)$ is an integral function. \par\hfill P.T.O. [2]
  11. 3(c) Define order of an entire function. Find the order of $P(z)=b_0+b_1z+b_2z^2+\ldots+b_nz^n,\ b_n\ne0$. [1+3]
  12. 3(d) State Borel's first theorem. [1]
  13. 4(a) If $f(z)$ is an entire function of order $\rho$ and $P(z)$ is a non-constant polynomial such that $f(z)/P(z)$ is an entire function, then show that $f(z)/P(z)$ is of order $\rho$. [2]
  14. 4(b) If $f(z)$ is an entire function of order $\rho$ then show that for every $\epsilon>0$, the inequality $n(r)\le r^{\rho+\epsilon}$ holds for all sufficiently large $r$, where $n(r)$ denotes the number of zeros of $f(z)$ in the closed disc $|z|\le r$. [4]
  15. 4(c) State and prove Picard's theorem. [3]
  16. 4(d) Give an example of an entire function $f(z)$ for which $\rho=\rho_1$, where $\rho$ be the order and $\rho_1$ be the exponent of convergence of zeros of $f(z)$. [1]
  17. 5(a) Define canonical product for an entire function $f(z)$. If $\rho_1$ be the exponent of convergence of zeros of $f(z)$ and if $P$ be the genus, then show that $\rho_1-1\le P\le\rho_1$. [3]
  18. 5(b) Find the exponent of convergence of the zeros of $\sin2z$. [2]
  19. 5(c) Represent $\sin\pi z$ in the form of canonical product. [3]
  20. 5(d) Define type of an integral function. Find the type of $f(z)=z^3e^{4z}$. [2]
  21. 6(a) If $f(z)=\displaystyle\sum_{n=0}^{\infty}a_nz^n$ is an integral function of finite non-zero order $\rho$ and type $\sigma$, then prove that $\sigma=\dfrac1{e\rho}\displaystyle\limsup_{n\to\infty}n|a_n|^{\rho/n}$. [5]
  22. 6(b) Show that the function $f(z)=\displaystyle\sum_{n=2}^{\infty}\left(\frac{e\rho\log n}n\right)^{n/\rho}z^n$ is of order $\rho$ and of maximal type. [2]
  23. 6(c) Prove that for two entire functions $f$ and $g$, if $\rho_f\ne\rho_g$, then $\sigma_{f+g}\le\max\{\sigma_f,\sigma_g\}$. [2]
  24. 6(d) Give an example of an entire function having same order and type. [1]
