MMC-31

Old New
M.Sc. Mathematics · Semester III2018
  1. 1(a) Establish the validity of\par \hspace*{2em}$(A\vee B)\to((C\vee D)\to E);$\par \hspace*{2em}$\therefore A\to((C\wedge D)\to E).$ \par Construct a proof of invalidity of\par \hspace*{2em}$T\equiv U$\par \hspace*{2em}$U\equiv(V\wedge W)$\par \hspace*{2em}$V\equiv(T\vee X)$\par \hspace*{2em}$T\vee X$\par \hspace*{2em}$\therefore T\wedge X$ [3]
  2. 1(b) Establish the validity / invalidity of the argument:\par Only citizens are voters. Not all citizens are residents. Therefore, some voters are not residents. [4]
  3. 2(a) Show that\par $(\forall x)F(x)\wedge(\forall x)G(x)\equiv(\forall x)(F(x)\wedge G(x))$ is a valid biconditional whereas\par $(\forall x)F(x)\vee(\forall x)G(x)\to(\forall x)(F(x)\vee G(x))$ is conditional truth. [4]
  4. 2(b) Construct a formal proof of validity for the argument:\par If any jewellery is missing, then if all servants are honest, it will be returned. If any servant is honest, they all are. So if any jewellery is missing, then if at least one servant is honest, it will be returned. [4]
  5. 2(c) Symbolize the following:\par If any husband is unsuccessful, then if some wives are ambitious, he will be unhappy. [2]
  6. 3(a) Define Hamiltonian graph. Let $G$ be a graph with $n$ vertices, and let $u,v$ be non-adjacent vertices in $G$ such that $d(u)+d(v)\ge n$. Show that $G$ is Hamiltonian if and only if $G+uv$ is Hamiltonian.
  7. 3(b) Write algorithm for Depth-First-Search Spanning tree. [2]
  8. 3(c) Define planar graph. State and prove Euler's formula for a connected plane graph $G$ with `$v$' vertices, `$e$' edges and `$f$' faces. If all cycles in $G$ have length at least 4, then show that $e\le 2v-4$, where $v\ge3$. \par\hfill P.T.O.
  9. 4(a) Show that if $G$ is a loop free graph and $v\ge3$, then $G$ has a cycle of even length. [2]
  10. 4(b) Define a tree. Show that if $T$ is a tree in which the neighbour of every leaf has degree at least 3, then some pair of leaves have a common neighbour.
  11. 4(c) Explain vertex colouring of a graph $G$. Define chromatic number of $G$. Show that for any simple graph $G$\par \hspace*{2em}$\chi(G)\le\Delta(G)+1.$
  12. 5(a) Compute / Count the number of paths of length $n$ in the $xy$-plane starting from the origin with steps\par \hspace*{2em}$R:(x,y)\to(x+1,y),$\par \hspace*{2em}$L:(x,y)\to(x-1,y)$ and\par \hspace*{2em}$U:(x,y)\to(x,y+1).$\par It is given that step $R$ is not followed by step $L$ and vice-versa. [4]
  13. 5(b) State Pigeon-hole principle. Use it to show that if a poset $\langle P,\le\rangle$ has at least $n^2+1$ elements then it has either a chain of size $n+1$ or an anti-chain of size $n+1$.
  14. 5(c) Show that if $n+1$ numbers are chosen from $\{1,2,\ldots,2n\}$, then one must divide the other. [2]
  15. 6(a) State the principle of Inclusion-Exclusion. Use it to count the number of derangements of the permutations of $\{1,2,\ldots,n\}$.
  16. 6(b) State and prove Burnside's theorem on counting. Illustrate the result with an example of your choice.
