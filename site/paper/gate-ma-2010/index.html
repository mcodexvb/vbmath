  1. 1 Let $E$ and $F$ be any two events with $P(E \cup F) = 0.8$, $P(E) = 0.4$, and $P(E \mid F) = 0.3$. Then $P(F)$ is \begin{enumerate}[label=(\Alph*)] \item $\dfrac{3}{7}$ \item $\dfrac{4}{7}$ \item $\dfrac{3}{5}$ \item $\dfrac{2}{5}$ \end{enumerate}
  2. 2 Let $X$ have a binomial distribution with parameters $n$ and $p$, where $n$ is an integer greater than $1$ and $0 < p < 1$. If $P(X = 0) = P(X = 1)$, then the value of $p$ is \begin{enumerate}[label=(\Alph*)] \item $\dfrac{1}{n - 1}$ \item $\dfrac{n}{n + 1}$ \item $\dfrac{1}{n + 1}$ \item $\dfrac{1}{1 + n^{1/(n-1)}}$ \end{enumerate}
  3. 3 Let $u(x,y) = 2x(1 - y)$ for all real $x$ and $y$. Then a function $v(x,y)$ so that $f(z) = u(x,y) + i v(x,y)$ is analytic is \begin{enumerate}[label=(\Alph*)] \item $x^2 - (y - 1)^2$ \item $(x - 1)^2 - y^2$ \item $(x - 1)^2 + y^2$ \item $x^2 + (y - 1)^2$ \end{enumerate}
  4. 4 Let $f(z)$ be analytic on $D = \{z \in \mathbb{C} : |z - 1| < 1\}$ such that $f(1) = 1$. If $f(z) = f(z^2)$ for all $z \in D$, then which one of the following statements is NOT correct? \begin{enumerate}[label=(\Alph*)] \item $f(z) = [f(z)]^2$ for all $z \in D$ \item $f\!\left(\dfrac{z}{2}\right) = \dfrac{1}{2}f(z)$ for all $z \in D$ \item $f(z^3) = [f(z)]^3$ for all $z \in D$ \item $f'(1) = 0$ \end{enumerate}

  10. 10 Let $A$ and $B$ be disjoint subsets of $\mathbb{R}$ and let $m^*$ denote the Lebesgue outer measure on $\mathbb{R}$.   11. 11 Let $f : \mathbb{R} \to [0, \infty)$ be a Lebesgue measurable function and $E$ be a Lebesgue measurable subset of $\mathbb{R}$ such that $\displaystyle\int_E f\,dm = 0$, where $m$ is the Lebesgue measure on $\mathbb{R}$.   22. 22 Let $X = C[0, 1]$ with the norm $\|x\|_1 = \displaystyle\int_0^1 |x(t)|\,dt$, $x \in C[0, 1]$, and $\Omega = \{f \in X' : \|f\| = 1\}$, where $X'$ is the dual space of $X$.
