  1. 1 Let $s_{n}=1+\frac{(-1)^{n}}{n}, n \in \mathbb{N}$. Then the sequence $\left\{s_{n}\right\}$ is \begin{enumerate}[label=(\alph*)] \item monotonically increasing and is convergent to 1 \item monotonically decreasing and is convergent to 1 \item neither monotonically increasing nor monotonically decreasing but is convergent to 1 \item divergent \end{enumerate}
  2. 2 Let $f(x)=2 x^{3}-9 x^{2}+7$. Which of the following is true? \begin{enumerate}[label=(\alph*)] \item $f$ is one-one in the interval $[-1,1]$ \item $f$ is one-one in the interval $[2,4]$ \item $f$ is NOT one-one in the interval $[-4,0]$ \item $f$ is NOT one-one in the interval $[0,4]$ \end{enumerate}
  3. 3 Which of the following is FALSE? \begin{enumerate}[label=(\alph*)] \item $\lim _{x \rightarrow \infty} \frac{x}{e^{x}}=0$ \item $\lim _{x \rightarrow 0^{+}} \frac{1}{x e^{1 / x}}=0$ \item $\lim _{x \rightarrow 0^{+}} \frac{\sin x}{1+2 x}=0$ \item $\lim _{x \rightarrow 0^{+}} \frac{\cos x}{1+2 x}=0$ \end{enumerate}
  4. 4 Let $g: \mathbb{R} \rightarrow \mathbb{R}$ be a twice differentiable function. If $f(x, y)=g(y)+x g^{\prime}(y)$, then \begin{enumerate}[label=(\alph*)] \item $\frac{\partial f}{\partial x}+y \frac{\partial^{2} f}{\partial x \partial y}=\frac{\partial f}{\partial y}$ \item $\frac{\partial f}{\partial y}+y \frac{\partial^{2} f}{\partial x \partial y}=\frac{\partial f}{\partial x}$ \item $\frac{\partial f}{\partial x}+x \frac{\partial^{2} f}{\partial x \partial y}=\frac{\partial f}{\partial y}$ \item $\frac{\partial f}{\partial y}+x \frac{\partial^{2} f}{\partial x \partial y}=\frac{\partial f}{\partial x}$ \end{enumerate}

  8. 8 Let $T: \mathbb{R}^{2} \rightarrow \mathbb{R}^{2}$ be the linear transformation given by $T(x, y)=(-x, y)$.
