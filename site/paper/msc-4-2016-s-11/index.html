MMO-41

Advanced Real Analysis-II
M.Sc. Mathematics · Semester IV2016
  1. 1(a) What are $F_\sigma$ and $G_\delta$ sets? Give examples of a $F_\sigma$ set which is not closed and a $G_\delta$ set which is not open. [3]
  2. 1(b) If $\{E_n\}$ be a sequence of sets show that $\displaystyle\liminf_{n\to\infty}E_n\subset\limsup_{n\to\infty}E_n$ [3]
  3. 1(c) Suppose $\psi$ be a completely additive set function defined on an algebra $\mathcal A$ and $\{E_n\}$ be a monotone increasing sequence of sets in $\mathcal A$ such that $\bigcup E_n\in\mathcal A$. Show that $\lim\psi(E_n)=\psi(\lim E_n).$ [3]
  4. 1(d) Show that a additive set function on an algebra is non-decreasing if and only if it is non-negative. [3]
  5. 2(a) What do you mean by the terms pre-measure and covering family? Show that outer measure can be constructed using pre-measure. Also show that this outer measure is regular iff all elements of the covering family are measurable. [1+1+3+4]
  6. 2(b) What is complete measure space. Show that Lebesgue measure is complete. [3]
  7. 3(a) State and prove Caratheodary Hahn Extension theorem. w.r.t. outer measure. [8]
  8. 3(b) Give definition of Lebesgue-Stieltjes outer measure $\mu_f^*$. Show that\par \[\mu_f^*(ab]=f(b)-f(a).\] [4]
  9. 4(a) When is an outer measure $\mu^*$ on a metric space X called a metric outer measure? Show that every Borel set in a metric space X is measurable if and only if the outer measure $\mu^*$ is a metric outer measure. [1+6]
  10. 4(b) Suppose X is metric space and $\phi:X\to X$ is continuous and f is measurable w.r.t. metric measure. Show that $\phi_of$ is measurable. [2]
  11. 4(3)) What is almost uniformly convergence for a sequence of function $\{f_n\}$ in a measure space $(X,M,\mu)$. Show that almost uniformly convergence implies convergence in measure. \par\hfill P.T.O. [3]
  12. 5(a) Suppose a measurable function defined on a measure space $(X,\mathcal M,\mu)$. Let $E,F\in\mathcal M$ and $E\cap F=\phi$. Show that $\displaystyle\int_{E\cup F}f=\int_Ef+\int_Ff$, provided $f$ is integrable on $E\cup F$. [4]
  13. 5(b) Let $(X,\mathcal M,\mu)$ be a measure space; let $f$ be a non negative measurable function and for each $E\in\mathcal M,\ \nu(E)=\displaystyle\int_Ef\,d\mu.$\par Show that\par \hspace*{1em}i)\enspace $\nu$ is measure on $\mathcal M$.\par \hspace*{1em}ii)\enspace If $g$ be a non negative measurable function then $\displaystyle\int_Eg\,d\nu=\int_Egf\,d\mu.$ [2+4]
  14. 5(c) If $\mu(E)=0$, then show that for any function $f,\ \displaystyle\int_Ef\,d\mu=0.$ [2]
  15. 6 Answer any Two.\par
  16. 6(a) Let $f$ be a non negative measurable function, $E$ a measurable set and $\alpha>0$. Show that $\mu\{x\in E:f(x)>\alpha\}\le\dfrac1\alpha\displaystyle\int_Ef\,d\mu.$ [2]
  17. 6(b) Let $f(x)=0$ if $x<0$\par \hspace*{3.6em}$=1$ if $0\le x<1$\par \hspace*{3.6em}$=2$ \ $x\ge1$\par and $\mu_f$ be associated Legesgue Stieltjes measure, show that\par $\mu_f(0,1)<\mu_f(0\,1]<\mu_f[0,1]$ [2]
  18. 6(c) Show that greatest integer function $[x]$ defined on any finite interval is a simple function. [2]
