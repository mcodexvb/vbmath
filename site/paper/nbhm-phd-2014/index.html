NBHM · 2014 · Doctoral scholarship

  1. 1.1 Let $G$ be a finite group of order $n \ge 2$. Which of the following statements are true? \begin{enumerate}[a.] \item There always exists an injective homomorphism from $G$ into $S_n$. \item There always exists an injective homomorphism from $G$ into $S_m$ for some $m < n$. \item There always exists an injective homomorphism from $G$ into $GL_n(\R)$. \end{enumerate}
  2. 1.2 Let $\C^*$ denote the multiplicative group of non-zero complex numbers and let $P$ denote the subgroup of positive (real) numbers. Identify the quotient group $\C^*/P$.
  3. 1.3 Given a finite group and a prime $p$ which divides its order, let $N(p)$ denote the number of $p$-Sylow subgroups of $G$. If $G$ is a group of order $21$, what are the possible values for $N(3)$ and $N(7)$?
  4. 1.4 Let $V$ be the real vector space of all polynomials, in a single variable and with real coefficients, of degree at most $3$. Let $V^*$ be its dual space. Let $t_1 = 1, t_2 = 2, t_3 = 3, t_4 = 4$. Which of the following sets of functionals $\{f_i,\ 1 \le i \le 4\}$ form a basis for $V^*$? \begin{enumerate}[a.] \item For $1 \le i \le 4$, and for all $p \in V$, $f_i(p) = p(t_i)$. \item For all $p \in V$, $f_i(p) = p(t_i)$ for $i = 1, 2$, $f_3(p) = p'(t_1)$ and $f_4(p) = p'(t_2)$. \item For all $p \in V$, $f_i(p) = p(t_i)$ for $1 \le i \le 3$ and $f_4(p) = \int_1^2 p'(t)\,dt$. \end{enumerate}
  5. 1.5 Let $V$ be a finite dimensional real vector space and let $f$ and $g$ be non-zero linear functionals on $V$. Assume that $\ker(f) \subset \ker(g)$. Which of the following statements are true? \begin{enumerate}[a.] \item $\ker(f) = \ker(g)$. \item $f = \lambda g$ for some real number $\lambda \neq 0$. \item The linear map $A : V \to \R^2$ defined by $Ax = (f(x), g(x))$, for all $x \in V$, is onto. \end{enumerate}
  6. 1.6 Let $V$ be a finite dimensional real vector space and let $A : V \to V$ be a linear map such that $A^2 = A$. Assume that $A \neq 0$ and that $A \neq I$. Which of the following statements are true? \begin{enumerate}[a.] \item $\ker(A) \neq \{0\}$. \item $V = \ker(A) \oplus \mathcal{R}(A)$. \item The map $I + A$ is invertible. \end{enumerate}
  7. 1.7 Let $A \in \M_2(\R)$ be a matrix which is not a diagonal matrix. Which of the following statements are true? \begin{enumerate}[a.] \item If $\tr(A) = -1$ and $\det(A) = 1$, then $A^3 = I$. \item If $A^3 = I$, then $\tr(A) = -1$ and $\det(A) = 1$. \item If $A^3 = I$, then $A$ is diagonalizable over $\R$. \end{enumerate}
  8. 1.8 Let $x \in \R^n$ be a non-zero (column) vector. Define $A = xx^T \in \M_n(\R)$. \begin{enumerate}[a.] \item What is the rank of $A$? \item What is the necessary and sufficient condition for $I - 2A$ to be an orthogonal matrix? \end{enumerate}
  9. 1.9 Let $A \in GL_n(\R)$ have integer entries. Let $b \in \R^n$ be a (column) vector, also with integer entries. Which of the following statements are true? \begin{enumerate}[a.] \item If $Ax = b$, then the entries of $x$ are also integers. \item If $Ax = b$, then the entries of $x$ are rational. \item The matrix $A^{-1}$ has integer entries if, and only if, $\det(A) = \pm 1$. \end{enumerate}
  10. 1.10 In each of the following cases, describe the smallest subset of $\C$ which contains all the eigenvalues of every member of the set $S$. \begin{enumerate}[a.] \item $S = \{A \in \M_n(\C) \mid A = BB^* \text{ for some } B \in \M_n(\C)\}$. \item $S = \{A \in \M_n(\C) \mid A = B + B^* \text{ for some } B \in \M_n(\C)\}$. \item $S = \{A \in \M_n(\C) \mid A + A^* = 0\}$. \end{enumerate}
  11. 2.1 Find the largest interval for which the following series is convergent at all points $x$ in it: \[ \sum_{n=1}^{\infty} \frac{2^n(3x - 1)^n}{n}. \]
  12. 2.2 Let $m$ and $k$ be fixed positive integers. Evaluate: \[ \lim_{n \to \infty} \left(\frac{(n+1)^m + (n+2)^m + \dots + (n+k)^m}{n^{m-1}} - kn\right). \]
  13. 2.3 Which of the following statements are true? \begin{enumerate}[a.] \item If $f$ is twice continuously differentiable in $]a, b[$ and if for all $x \in ]a, b[$, $f''(x) + 2f'(x) + 3f(x) = 0$, then $f$ is infinitely differentiable in $]a, b[$. \item Let $f \in \mathcal{C}[a, b]$ be differentiable in $]a, b[$. If $f(a) = f(b) = 0$, then, for any real number $\alpha$, there exists $x \in ]a, b[$ such that $f'(x) + \alpha f(x) = 0$. \item The function defined below is not differentiable at $x = 0$: \[ f(x) = \begin{cases} x^2 \left|\cos\frac{\pi}{x}\right|, & x \neq 0, \\ 0, & x = 0. \end{cases} \] \end{enumerate}
  14. 2.4 Let $f : \R \to \R$ be continuous. Which of the following statements are true? \begin{enumerate}[a.] \item If $f$ is bounded, then $f$ is uniformly continuous. \item If $f$ is differentiable and if $f'$ is bounded, then $f$ is uniformly continuous. \item If $\lim_{|x| \to \infty} f(x) = 0$, then $f$ is uniformly continuous. \end{enumerate}
  15. 2.5 In which of the following cases, is the function $f$ of bounded variation on $[0, 1]$? \begin{enumerate}[a.] \item The function $f : [0, 1] \to \R$ such that, for all $x, y \in [0, 1]$, $|f(x) - f(y)| \le 3|x - y|$. \item The function $f$ is monotonically decreasing on $[0, 1]$. \item If for some non-negative Riemann integrable function $g$ on $[0, 1]$, $f(x) = \int_0^x g(t)\,dt$ for all $x \in [0, 1]$. \end{enumerate}
  16. 2.6 Let $g_n(x) = n\left[f\left(x + \frac{1}{n}\right) - f(x)\right]$, where $f : \R \to \R$ is a continuous function. Which of the following statements are true? \begin{enumerate}[a.] \item If $f(x) = x^3$, then $g_n \to f'$ uniformly on $\R$ as $n \to \infty$. \item If $f(x) = x^2$, then $g_n \to f'$ uniformly on $\R$ as $n \to \infty$. \item If $f$ is differentiable and if $f'$ is uniformly continuous on $\R$, then $g_n \to f'$ uniformly on $\R$ as $n \to \infty$. \end{enumerate}
  17. 2.7 Which of the following statements are true? \begin{enumerate}[a.] \item The series $\displaystyle\sum_{n=1}^{\infty} \frac{x^2}{1 + n^2 x^2}$ does not converge uniformly on $\R$. \item The series in (a) above converges uniformly on $\R$. \item The sum of the series $\displaystyle\sum_{n=1}^{\infty} \frac{\sin nx^2}{1 + n^3}$ defines a continuously differentiable function on $\R$. \end{enumerate}
  18. 2.8 Find the sum of the series: $\displaystyle\sum_{n=1}^{\infty} \frac{(-1)^{n+1}}{n(n+1)}$.
  19. 2.9 Let $\{f_n\}$ be a sequence of bounded real valued functions on $[0, 1]$ converging to $f$ at all points of this interval. Which of the following statements are true? \begin{enumerate}[a.] \item If $f_n$ and $f$ are all continuous, then $\lim_{n \to \infty} \int_0^1 f_n(t)\,dt = \int_0^1 f(t)\,dt$. \item If $f_n \to f$ uniformly, as $n \to \infty$, on $[0, 1]$, then $\lim_{n \to \infty} \int_0^1 f_n(t)\,dt = \int_0^1 f(t)\,dt$. \item If $\int_0^1 |f_n(t) - f(t)|\,dt \to 0$ as $n \to \infty$, then $\lim_{n \to \infty} \int_0^1 f_n(t)\,dt = \int_0^1 f(t)\,dt$. \end{enumerate}
  20. 2.10 Let $f : [0, \pi] \to \R$ be a continuous function such that $f(0) = 0$. Which of the following statements are true? \begin{enumerate}[a.] \item If $\int_0^{\pi} f(t)\cos nt\,dt = 0$ for all $n \in \{0\} \cup \N$, then $f \equiv 0$. \item If $\int_0^{\pi} f(t)\sin nt\,dt = 0$ for all $n \in \N$, then $f \equiv 0$. \item If $\int_0^{\pi} t^n f(t)\,dt = 0$ for all $n \in \{0\} \cup \N$, then $f \equiv 0$. \end{enumerate}
  21. 3.1 Let $A$ and $B$ be subsets of $\R^n$. Define $A + B = \{a + b \mid a \in A,\ b \in B\}$. Consider the sets \begin{align*} W &= \{(x, y) \in \R^2 \mid x > 0,\ y > 0\}, & X &= \{(x, y) \in \R^2 \mid x \in \R,\ y = 0\}, \\ Y &= \{(x, y) \in \R^2 \mid xy = 1\}, & Z &= \{(x, y) \in \R^2 \mid |x| \le 1,\ |y| \le 1\}. \end{align*} Which of the following statements are true?\\ a.\ The set $W + X$ is open. \qquad b.\ The set $X + Y$ is closed. \qquad c.\ The set $Y + Z$ is closed.
  22. 3.2 Let $X$ be a topological space and let $A$ be a subset of $X$. Which of the following statements are true? \begin{enumerate}[a.] \item If $A$ is dense in $X$, then $A^\circ$ (the interior of $A$), is also dense in $X$. \item If $A$ is dense in $X$, then $X \setminus A$ is nowhere dense. \item If $A$ is nowhere dense, then $X \setminus A$ is dense. \end{enumerate}
  23. 3.3 Consider the space $X = \mathcal{C}[0, 1]$ with its usual `sup-norm' topology. Let $S = \left\{f \in X \;\middle|\; \int_0^1 f(t)\,dt \neq 0\right\}$. Which of the following statements are true?\\ a.\ The set $S$ is open. \qquad b.\ The set $S$ is dense in $X$. \qquad c.\ The set $S$ is connected.
  24. 3.4 Consider the space $X = \mathcal{C}[0, 1]$ with its usual `sup-norm' topology. Let $S = \left\{f \in X \;\middle|\; \int_0^1 f(t)\,dt = 0\right\}$. Which of the following statements are true?\\ a.\ The set $S$ is closed. \qquad b.\ The set $S$ is connected. \qquad c.\ The set $S$ is compact.
  25. 3.5 Let $(X, d)$ be a metric space. Which of the following statements are true? \begin{enumerate}[a.] \item A sequence $\{x_n\}$ converges to $x$ in $X$ if, and only if, the sequence $\{y_n\}$ is a Cauchy sequence in $X$, where, for $k \ge 1$, $y_{2k-1} = x_k$ and $y_{2k} = x$. \item If $f : X \to X$ maps Cauchy sequences into Cauchy sequences, then $f$ is continuous. \item If $f : X \to X$ is continuous, then it maps Cauchy sequences into Cauchy sequences. \end{enumerate}
  26. 3.6 Which of the following spaces are separable? \begin{enumerate}[a.] \item The space $\mathcal{C}[a, b]$ with its usual `sup-norm' topology. \item The space $\mathcal{C}[0, 1]$ with the metric defined by $d(f, g) = \int_0^1 |f(t) - g(t)|\,dt$. \item The space $\ell_\infty$ consisting of all bounded real sequences with the metric $d(\{x_n\}, \{y_n\}) = \sup_{n \in \N} |x_n - y_n|$. \end{enumerate}
  27. 3.7 Consider the space $\M_2(\R)$ with its usual topology. Which of the following sets are dense? \begin{enumerate}[a.] \item The set of all invertible matrices. \item The set of all matrices with both eigenvalues real. \item The set of all matrices $A$ such that $\tr(A) = 0$. \end{enumerate}
  28. 3.8 Which of the following statements are true? \begin{enumerate}[a.] \item If $f : \R \to \R$ is injective and continuous, then it is strictly monotonic. \item If $f \in \mathcal{C}[0, 2]$ is such that $f(0) = f(2)$, then there exist $x_1$ and $x_2$ in $[0, 2]$ such that $x_1 - x_2 = 1$ and $f(x_1) = f(x_2)$. \item Let $f$ and $g$ be continuous real valued functions on $\R$ such that for all $x \in \R$, we have $f(g(x)) = g(f(x))$. If there exists $x_0 \in \R$ such that $f(f(x_0)) = g(g(x_0))$, then there exists $x_1 \in \R$ such that $f(x_1) = g(x_1)$. \end{enumerate}
  29. 3.9 Which of the following statements are true? \begin{enumerate}[a.] \item Let $V = \mathcal{C}_c(\R)$, the space of continuous functions on $\R$ with compact support endowed with the metric $d(f, g) = \left(\int_{-\infty}^{\infty} |f(t) - g(t)|^2\,dt\right)^{\frac{1}{2}}$. Let $f : \R \to \R$ be a continuous function which vanishes outside $[0, 1]$. Define $f_n(x) = f(x - n)$ for $n \in \N$. Then $\{f_n\}$ has a convergent subsequence in $V$. \item Let $\varphi, \psi$ be continuous functions on $[0, 1]$. Let $\{f_n\}$ be a sequence in $\mathcal{C}[0, 1]$ with its usual `sup-norm' topology such that, for all $n \in \N$, the functions $f_n$ are continuously differentiable and for all $x \in [0, 1]$, and for all $n \in \N$ we have $|f_n(x)| \le \varphi(x)$ and $|f_n'(x)| \le \psi(x)$. Then there exists a subsequence of $\{f_n\}$ which converges in $\mathcal{C}[0, 1]$. \item Let $\{A_n\}$ be a sequence of orthogonal matrices in $\M_2(\R)$. Then it has a convergent subsequence. \end{enumerate}
  30. 3.10 Which of the following pairs of sets are homeomorphic? \begin{enumerate}[a.] \item The sets $\Q$ and $\Z$ with their usual topologies inherited from $\R$. \item The sets $]0, 1[$ and $]0, \infty[$ with their usual topologies inherited from $\R$. \item The sets $S^1 = \{z \in \C \mid z = e^{i\theta},\ 0 \le \theta < 2\pi\}$ and $A = \{z \in \C \mid z = re^{i\theta},\ 1 \le r \le 2,\ 0 \le \theta < 2\pi\}$ with their usual topologies inherited from $\C \cong \R^2$. \end{enumerate}
  31. 4.1 Let $S = \{x = (x_1, x_2, \dots, x_n) \in \R^n \mid 0 \le x_1 \le x_2 \le \dots \le x_n \le 1\}$. Find the volume of the set $S$.
  32. 4.2 Let $F : ]0, \infty[ \to \R$ be defined by $F(x) = \displaystyle\int_{-x}^{x} \frac{1 - e^{-xy}}{y}\,dy$. Compute $F'(x)$.
  33. 4.3 Let $f(x, y) = x^2 + 5y^2 - 6x + 10y + 6$. Where are the maxima/minima of $f$ (if any) located?
  34. 4.4 Evaluate: $\displaystyle\int_{-\infty}^{\infty}\int_{-\infty}^{\infty} e^{-(2x^2 + 2xy + 2y^2)}\,dxdy$.
  35. 4.5 Write down the Taylor series expansion about the origin, up to the term involving $x^7$, for the function $f(x) = \frac{1}{2}\left[x\sqrt{1 - x^2} + \sin^{-1} x\right]$.
  36. 4.6 Solve: $-\dfrac{d^2 u}{dr^2} - \dfrac{1}{r}\dfrac{du}{dr} = 1$, in $0 < r < 1$, $u'(0) = 0 = u(1)$.
  37. 4.7 Which of the following two-point boundary value problems admit a unique solution? \begin{enumerate}[a.] \item $-u''(x) = 2x$ in $0 < x < 1$ and $u(0) = u(1) = 0$. \item $-u''(x) = 2x$ in $0 < x < 1$ and $u(0) = u'(1) = 0$. \item $-u''(x) = 2x$ in $0 < x < 1$ and $u'(0) = u'(1) = 0$. \end{enumerate}
  38. 4.8 Which of the following statements are true? \begin{enumerate}[a.] \item Let $\psi$ be a non-negative and continuously differentiable function on $]0, \infty[$ such that $\psi'(x) \le \psi(x)$ for all $x \in ]0, \infty[$. Then $\lim_{x \to \infty} \psi(x) = 0$. \item Let $\psi$ be a non-negative function continuous on $[0, \infty[$ and differentiable on $]0, \infty[$ such that $\psi(0) = 0$ and such that $\psi'(x) \le \psi(x)$ for all $x \in ]0, \infty[$. Then $\psi \equiv 0$. \item Let $\varphi$ be a non-negative and continuous function on $[0, \infty[$ and such that $\varphi(x) \le \int_0^x \varphi(t)\,dt$ for all $x \in [0, \infty[$. Then $\varphi \equiv 0$. \end{enumerate}
  39. 4.9 Write down the expression for the Laplace transform $F(s)$ of the function $f(x) = x^n$, where $n \in \N$.
  40. 4.10 Amongst all smooth curves $y(x)$ passing through the points $(x_1, 0)$ and $(x_2, 0)$ in the plane, we wish to find that whose surface of revolution about the $x$-axis has the least surface area. Write down the functional that must be minimised to find this curve.
  41. 5.1 Let $A = (a_{ij}) \in \M_n(\R)$ be defined by $a_{ij} = \begin{cases} i, & \text{if } i + j = n + 1, \\ 0, & \text{otherwise.} \end{cases}$ Compute $\det(A)$.
  42. 5.2 Let $n \in \N$ be fixed. For $0 \le k \le n$, let $C_k$ denote the usual binomial coefficient $\binom{n}{k}$ of choosing $k$ objects from a set of $n$ objects. Evaluate: $C_0^2 + C_1^2 + \dots + C_n^2$.
  43. 5.3 Which of the following numbers are prime?\\ a.\ $179$. \qquad b.\ $197$. \qquad c.\ $199$.
  44. 5.4 Given $f : \R \to \R$, define $f^2(x) = f(f(x))$. Which of the following statements are true? \begin{enumerate}[a.] \item If $f$ is strictly monotonic, then $f^2$ is strictly increasing. \item If $f^2(x) = -x$ for all $x \in \R$, then $f$ is injective. \item There does not exist a continuous function $f : \R \to \R$ such that $f^2(x) = -x$ for all $x \in \R$. \end{enumerate}
  45. 5.5 Let $a$ be a fixed positive real number. Evaluate: \[ \max_{\substack{x_i \ge 0,\ 1 \le i \le n \\ \sum_{i=1}^{n} x_i = a}} x_1 x_2 \cdots x_n. \]
  46. 5.6 A real number is said to be \emph{algebraic} if it is the root of a non-zero polynomial of degree at least one with integer coefficients. Otherwise the number is said to be \emph{transcendental}. Which of the following statements are true? \begin{enumerate}[a.] \item Algebraic numbers are dense in $\R$. \item Transcendental numbers are dense in $\R$. \item The number $\cos\left(\frac{\pi}{13}\right)$ is algebraic. \end{enumerate}
  47. 5.7 Let $f : ]a, b[ \to \R$ be a given function. Which of the following statements are true? \begin{enumerate}[a.] \item If $f$ is convex in $]a, b[$, then the set $\Gamma = \{(x, y) \in \R^2 \mid x \in ]a, b[,\ y \ge f(x)\}$ is a convex set. \item If $f$ is convex in $]a, b[$, then the set $\Gamma = \{(x, y) \in \R^2 \mid x \in ]a, b[,\ y \le f(x)\}$ is a convex set. \item If $f$ is convex in $]a, b[$, then $|f|$ is also convex in $]a, b[$. \end{enumerate}
  48. 5.8 Two fair dice are rolled. What is the probability that the sum of the numbers on the top faces is $8$?
  49. 5.9 Let $\{f_n\}_{n=1}^{\infty}$ and $f$ be real valued functions defined on $\R$. For $\varepsilon > 0$ and for $m \in \N$, define $E_m(\varepsilon) = \{x \in \R \mid |f_m(x) - f(x)| \ge \varepsilon\}$. Let $S = \{x \in \R \mid \text{the sequence } \{f_n(x)\} \text{ does not converge to } f(x)\}$. Express $S$ in terms of the sets $\{E_m(\varepsilon)\}_{m \in \N, \varepsilon > 0}$ (using the set theoretic operations of unions and intersections).
  50. 5.10 Consider the Fibonacci sequence $\{a_n\}_{n=0}^{\infty}$ defined by $a_0 = a_1 = 1$ and $a_n = a_{n-1} + a_{n-2}$, $n \ge 2$. Let $F(z) = \sum_{n=0}^{\infty} a_n z^n$ be the generating function. Express $F$ in closed form as a function of $z$.
