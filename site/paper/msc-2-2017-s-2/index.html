MMC-22

Topology
M.Sc. Mathematics · Semester II2017
  1. 1(a) State and prove Schroeder-Berstein theorem. [5]
  2. 1(b) Show for any set $A$, $\overline{\overline A}<\overline{\overline{\wp(A)}}$. [3]
  3. 1(c) Prove that any nondegenerated interval has the same cardinality as that of $\mathbb R$. [2]
  4. 2(a) If $\tau_l$ and $\tau_u$ be respectively the lower limit and upper limit topologies on $\mathbb R$ then show that \begin{romanparts} \item if $\tau$ is a topology on $\mathbb R$ containing $\tau_l\cup\tau_u$ then $\tau$ is the discrete topology on $\mathbb R$. \item If $\tau=\tau_l\cap\tau_u$ then $\tau$ is the usual topology on $\mathbb R$. \end{romanparts} [2]
  5. 2(b) Let $X$ be a nonempty set and for each $x\in X$, $\eta_x$ be a family of subsets of $X$ satisfying \begin{romanparts} \item $U\in\eta_x\implies x\in U$ \item $U,V\in\eta_x\implies U\cap V\in\eta_x$ \item $U\supset V\in\eta_x\implies U\in\eta_x$ \item For $U\in\eta_x$ there exists $V\in\eta_x$ such that $V\subset U$ and $V\in\eta_y\ \forall y\in V$. \end{romanparts} Then show that there is a unique topology $\tau$ on $X$ such that $\eta_x$ coincides with the family of all $\tau$-neighbourhoods of $x$. [4]
  6. 2(c) Show that in a topological space $X$, $X\mid\bar A=(X\mid A)^\circ$, $A\subset X$. [2]
  7. 3(a) Prove that a set $A$ in a topological space $X$ is dense iff $A$ intersects every nonempty open set in $X$. Is the set of reals with cocountable topology separable? Answer with justifications. [3+2]
  8. 3(b) Prove that every 2nd countable space is Lindeloff. Give an example of a 1st countable space which is not 2nd countable. [3+2]
  9. 4(a) Prove that a topological space is $T_1$ iff every single pointic set is closed. Give an example of $T_1$ space which is not $T_2$. [2+2]
  10. 4(b) Prove that every completely regular space is a regular space. [3]
  11. 4(c) Prove that a topological space is normal iff for any closed set $F$ and for any open set $U\supset F$ there is an open set $V$ such that $U\supset\bar V\supset V\supset F$. [3]
  12. 5(a) Prove that every compact Hausdorff space is normal. [4]
  13. 5(b) Prove that every real-valued continuous function over a compact space is bounded and attains its bounds. Give an example to show that the result does not hold if the compactness of the space is withdrawn. [4+2]
  14. 6(a) Prove that a set of real numbers is connected with respect to usual topology iff it is an interval. Prove that continuous image of a connected space is continuous. Prove that no function over $\mathbb R$ with rational values is continuous with respect to usual topology. [3+2+1]
  15. 6(b) Prove that cartesian product of two connected spaces is connected. \endgroup [4]
