  1. 1 Let $0<\alpha<1$ be a real number. The number of differentiable functions $y:[0,1] \rightarrow[0, \infty)$, having continuous derivative on $[0,1]$ and satisfying $$ \begin{aligned} &y^{\prime}(t)=(y(t))^{\alpha}, \quad t \in[0,1], \\ &y(0)=0 \end{aligned} $$ is \begin{enumerate}[label=(\alph*)] \item exactly one. \item exactly two. \item finite but more than two. \item infinite. \end{enumerate}
  2. 2 Let $P: \mathbb{R} \rightarrow \mathbb{R}$ be a continuous function such that $P(x)>0$ for all $x \in \mathbb{R}$. Let $y$ be a twice differentiable function on $\mathbb{R}$ satisfying $y^{\prime \prime}(x)+P(x) y^{\prime}(x)-y(x)=0$ for all $x \in \mathbb{R}$. Suppose that there exist two real numbers $a, b(a<b)$ such that $y(a)=y(b)=0$. Then \begin{enumerate}[label=(\alph*)] \item $y(x)=0$ for all $x \in[a, b]$. \item $y(x)>0$ for all $x \in(a, b)$. \item $y(x)<0$ for all $x \in(a, b)$. \item $y(x)$ changes sign on $(a, b)$. \end{enumerate}
  3. 3 Let $f: \mathbb{R} \rightarrow \mathbb{R}$ be a continuous function satisfying $f(x)=f(x+1)$ for all $x \in \mathbb{R}$. Then \begin{enumerate}[label=(\alph*)] \item $f$ is not necessarily bounded above. \item there exists a unique $x_{0} \in \mathbb{R}$ such that $f\left(x_{0}+\pi\right)=f\left(x_{0}\right)$. \item there is no $x_{0} \in \mathbb{R}$ such that $f\left(x_{0}+\pi\right)=f\left(x_{0}\right)$. \item there exist infinitely many $x_{0} \in \mathbb{R}$ such that $f\left(x_{0}+\pi\right)=f\left(x_{0}\right)$. \end{enumerate}
  4. 4 Let $f: \mathbb{R} \rightarrow \mathbb{R}$ be a continuous function such that for all $x \in \mathbb{R}$, $$ \int_{0}^{1} f(x t) d t=0 $$ Then \begin{enumerate}[label=(\alph*)] \item $f$ must be identically 0 on the whole of $\mathbb{R}$. \item there is an $f$ satisfying $(*)$ that is identically 0 on $(0,1)$ but not identically 0 on the whole of $\mathbb{R}$. \item there is an $f$ satisfying $(*)$ that takes both positive and negative values. \item there is an $f$ satisfying $(*)$ that is 0 at infinitely many points, but is not identically zero. \end{enumerate}
  5. 5 Let $p$ and $t$ be positive real numbers. Let $D_{t}$ be the closed disc of radius $t$ centered at $(0,0)$, i.e., $D_{t}=\left\{(x, y) \in \mathbb{R}^{2}: x^{2}+y^{2} \leq t^{2}\right\}$. Define $$ I(p, t)=\iint_{D_{t}} \frac{d x d y}{\left(p^{2}+x^{2}+y^{2}\right)^{p}} $$ Then $\lim _{t \rightarrow \infty} I(p, t)$ is finite \begin{enumerate}[label=(\alph*)] \item only if $p>1$. \item only if $p=1$. \item only if $p<1$. \item for no value of $p$. \end{enumerate}
  6. 6 How many elements of the group $\mathbb{Z}_{50}$ have order 10 ? \begin{enumerate}[label=(\alph*)] \item 10 \item 4 \item 5 \item 8 \end{enumerate}
  7. 7 For every $n \in \mathbb{N}$, let $f_{n}: \mathbb{R} \rightarrow \mathbb{R}$ be a function. From the given choices, pick the statement that is the negation of "For every $x \in \mathbb{R}$ and for every real number $\epsilon>0$, there exists an integer $N>0$ such that $\sum_{i=1}^{p}\left|f_{N+i}(x)\right|<\epsilon$ for every integer $p>0 . "$ \begin{enumerate}[label=(\alph*)] \item For every $x \in \mathbb{R}$ and for every real number $\epsilon>0$, there does not exist any integer $N>0$ such that $\sum_{i=1}^{p}\left|f_{N+i}(x)\right|<\epsilon$ for every integer $p>0$. \item For every $x \in \mathbb{R}$ and for every real number $\epsilon>0$, there exists an integer $N>0$ such that $\sum_{i=1}^{p}\left|f_{N+i}(x)\right| \geq \epsilon$ for some integer $p>0$ \item There exists $x \in \mathbb{R}$ and there exists a real number $\epsilon>0$ such that for every integer $N>0$, there exists an integer $p>0$ for which the inequality $\sum_{i=1}^{p}\left|f_{N+i}(x)\right| \geq \epsilon$ holds. \item There exists $x \in \mathbb{R}$ and there exists a real number $\epsilon>0$ such that for every integer $N>0$ and for every integer $p>0$ the inequality $\sum_{i=1}^{p}\left|f_{N+i}(x)\right| \geq \epsilon$ holds. \end{enumerate}
  8. 8 Which one of the following subsets of $\mathbb{R}$ has a non-empty interior? \begin{enumerate}[label=(\alph*)] \item The set of all irrational numbers in $\mathbb{R}$. \item The set $\{a \in \mathbb{R}: \sin (a)=1\}$. \item The set $\left\{b \in \mathbb{R}: x^{2}+b x+1=0\right.$ has distinct roots $\}$. \item The set of all rational numbers in $\mathbb{R}$. \end{enumerate}

  10. 10 Let $n>1$ be an integer. Consider the following two statements for an arbitrary $n \times n$ matrix $A$ with complex entries. I.
