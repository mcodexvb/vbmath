Paper

B.Sc. Mathematics · Semester V2022
  1. 1(a) Define the convex combination of a set of vectors. Prove that set of all convex combinations of a finite number of linearly independent vectors $\vec v_1,\vec v_2,\ldots,\vec v_m$ is a convex set. [1+4]
  2. 1(b) Use a graphical method for obtaining an optimal solution of the LPP \[\begin{aligned} &\text{Maximize }Z=x_1+x_2\\ &\text{subject to}\\ x_1+x_2 &\le 1,\\ -3x_1+x_2 &\ge 3,\\ x_1,x_2 &\ge 0, \end{aligned}\] if exists. [3]
  3. 1(c) Define the vertex of a convex set. Give an example of a convex set in which all boundary points are vertices. [1+1]
  4. 2(a) Establish that whenever an LPP has a basic feasible solution, if we drop one of the basis vectors and append a suitable non-basis vector in the basis set, the new solution is also a basic feasible solution. [6]
  5. 2(b) Examine whether $x_1=2$, $x_2=1$ is a basic feasible solution to \[\begin{aligned}x_1+2x_2+x_3&=4\\2x_1+x_2+5x_3&=5.\end{aligned}\] Find other basic feasible solutions, if available. [4]
  6. 3(a) Prove that a basic feasible solution to an LPP must correspond to an extreme point of the convex set of all feasible solutions. [4]
  7. 3(b) Obtain the optimal solution to the LPP \[\begin{aligned} &\text{Minimize } Z=x_1+x_2\\ &\text{subject to}\\ 2x_1+x_2&\ge4,\\ x_1+7x_2&\ge7,\\ x_1,x_2&\ge0. \end{aligned}\] if it exists, by Big-M or the two-phase method. Justify the answer by solving the same by graphical method. [6]
  8. 4(a) Use duality to solve the LPP \[\begin{aligned} &\text{Maximize } Z=8x_1+6x_2\\ &\text{subject to}\\ x_1-x_2&\le\frac35,\\ x_1-x_2&\ge2,\\ x_1,x_2&\ge0. \end{aligned}\] if the optimal solution exists. [5]
  9. 4(b) In a factory, there are four workers $A,B,C,D$ and five machines $M_1,M_2,M_3,M_4,M_5$. The operating cost for each worker to handle each machine is given in the table below. Find the optimal assignment and the assignment cost. Also, find which machine will remain idle. \[\begin{array}{c|ccccc|} &M_1&M_2&M_3&M_4&M_5\\\cline{2-6} A&12&15&14&11&16\\ B&15&12&14&13&15\\ C&16&18&12&15&15\\ D&12&14&13&13&14\\\cline{2-6} \end{array}\] [5]
  10. 5(a) For $C=[c_{ij}]_{n\times n}$, a cost matrix for an assignment problem, if another matrix is constructed in the form $C^*=[c_{ij}^*]_{n\times n}$ where $c_{ij}^*=c_{ij}+\alpha_i+\beta_j$, $\alpha_i,\beta_j$ being arbitrary constants, prove that the optimal solution of $C^*$ will be identical with that of $C$. [3]
  11. 5(b) Can pure strategies be applied to obtain the solution of a game with the following payoff matrix? Justify the answer. Then use dominance to reduce the payoff matrix and find the value of the game. \[\begin{array}{c@{\quad}c} &B\\ A&\begin{array}{|r|r|r|r|}\hline -1&-1&2&1\\\hline 2&2&0&1\\\hline 3&-2&1&-2\\\hline 2&1&-3&2\\\hline \end{array} \end{array}\] [2+5]
  12. 1(a) Define a \emph{random sample} of a population. Show that if the size of a random sample is large, the distribution of the sample approximates to that of the population. [1+2]
  13. 1(b) Define an \emph{estimate} of a population characteristic. When is an estimate said to be consistent and biased?
  14. 1(c) If $\Gamma$ is an unbiased estimate of a population parameter $\gamma$, show that $\Gamma^2$ is a biased estimate of $\gamma^2$; but if $\Gamma$ is a consistent estimate of $\gamma$ then show that $\Gamma^2$ is also a consistent estimate of $\Gamma^2$. [2+2]
  15. 2(a) For a continuous population explain what are meant by \emph{class intervals}, \emph{class limits}, and \emph{grouping of data}. Describe how to obtain a graphical representation of \emph{grouped data}. [3+2]
  16. 2(b) Define a \emph{statistic} and sampling distribution of a \emph{statistic}. Find the sampling distribution of the mean for the binomial $(N,p)$ population.
  17. 3(a) A random variable $X$ can take all non-negative integral values and $P(X=i)=p(1-p)^i$, $i=0,1,2,\ldots$, where $p$ $(0<p<1)$ is a parameter. Find the maximum likelihood estimate of $p$ on the basis of a sample of size $n$ from the population of $X$. Examine whether the estimate is consistent. [3+2]
  18. 3(b) Show that approximate confidence limits for large samples for the parameter $\mu$ of a Poisson population having confidence coefficient $1-\epsilon$ are given by the roots of the quadratic equation in $\mu$: $n(\bar x-\mu)^2=u_\epsilon^2\mu$, which, to the order of $1/\sqrt n$, are approximately $\bar x\pm u_\epsilon\sqrt{\bar x/n}$, where $\bar x$ is the mean of a sample of size $n$ and $u_\epsilon$ is given by \[\int_{-u_\epsilon}^{u_\epsilon}\phi(x)\,dx=1-\epsilon\] with $\phi(x)$ denoting the standard normal density function. [3+2]
  19. 4(a) Define (i) Simple hypothesis, (ii) Composite hypothesis, and (iii) Null hypothesis and give examples of each of them. [2+2+2]
  20. 4(b) The probability density function of a population with parameter $\alpha$ is given by \[f(x,\alpha)=\alpha e^{-\alpha x},\quad 0\le x<\infty,\quad \alpha>0.\] The null hypothesis $H_0:\alpha=2$ will be tested against the alternative $H_1:\alpha>2$ on the assumption that $H_0$ should be rejected for a sample $x\ge6$. Find the probability of Type-I error and the power of the test. [2+2]
  21. 5 State the Neyman-Pearson theorem of statistical testing. Using it construct a test of the null hypothesis $H_0:m=m_0$ against an alternative $H_1:m=m_1$ for a normal $(m,\sigma)$ population when $m_0$, $m_1$, and $\sigma$ are known and $m_0\ne m_1$. [2+8]
