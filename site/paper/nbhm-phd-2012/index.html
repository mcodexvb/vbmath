NBHM · 2012 · Doctoral scholarship

  1. 1.1 Which of the following are subgroups of $GL_3(\C)$? \begin{enumerate}[a.] \item $H = \{A \in \M_3(\C) \mid \det(A) = 2^l,\ l \in \Z\}$. \item $H = \left\{\begin{bmatrix} 1 & \alpha & \beta \\ 0 & 1 & \gamma \\ 0 & 0 & 1 \end{bmatrix} \;\middle|\; \alpha, \beta, \gamma \in \C\right\}$. \item $H = \left\{\begin{bmatrix} 1 & 0 & \alpha \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix} \;\middle|\; \alpha \in \C\right\}$. \end{enumerate}
  2. 1.2 Let $S_7$ denote the symmetric group of all permutations of the symbols $\{1, 2, 3, 4, 5, 6, 7\}$. Pick out the true statements: \begin{enumerate}[a.] \item $S_7$ has an element of order $10$; \item $S_7$ has an element of order $15$; \item the order of any element of $S_7$ is at most $12$. \end{enumerate}
  3. 1.3 Let $\mathcal{C}(\R)$ denote the ring of all continuous real-valued functions on $\R$, with the operations of pointwise addition and pointwise multiplication. Which of the following form an ideal in this ring? \begin{enumerate}[a.] \item The set of all $\mathcal{C}^\infty$ functions with compact support. \item The set of all continuous functions with compact support. \item The set of all continuous functions which vanish at infinity, \emph{i.e.}\ functions $f$ such that $\lim_{|x| \to \infty} f(x) = 0$. \end{enumerate}
  4. 1.4 Find the number of non-zero elements in the field $\Z_p$, where $p$ is an odd prime number, which are squares, \emph{i.e.}\ of the form $m^2$, $m \in \Z_p$, $m \neq 0$.
  5. 1.5 Find the inverse in $\Z_5$ of the following matrix: \[ \begin{bmatrix} 1 & 2 & 0 \\ 0 & 2 & 4 \\ 0 & 0 & 3 \end{bmatrix}. \]
  6. 1.6 Let $\mathcal{P}_3$ denote the (real) vector space of all polynomials (in one variable), with real coefficients and of degree less than, or equal to, $3$, equipped with the standard basis $\{1, x, x^2, x^3\}$. Write down the matrix (with respect to this basis) of the linear transformation \[ L(p) = p'' - 2p' + p,\quad p \in \mathcal{P}_3. \]
  7. 1.7 Find the unique polynomial $p \in \mathcal{P}_3$ (see Question 1.6 above) such that $p'' - 2p' + p = x^3$.
  8. 1.8 Let $A = (a_{ij}) \in \M_n(\R)$, $n \ge 3$. Let $B = (b_{ij})$ be the matrix of its cofactors, \emph{i.e.}\ $b_{ij}$ is the cofactor of the entry $a_{ij}$ in $A$. What is the rank of $B$ when \begin{enumerate}[a.] \item the rank of $A$ is $n$? \item the rank of $A$ is less than, or equal to, $n - 2$? \end{enumerate}
  9. 1.9 Let $A \in \M_3(\R)$ which is \textbf{not} a diagonal matrix. Pick out the cases when $A$ is diagonalizable over $\R$: \begin{enumerate}[a.] \item when $A^2 = A$; \item when $(A - 3I)^2 = 0$; \item when $A^2 + I = 0$. \end{enumerate}
  10. 1.10 Let $A \in \M_3(\R)$ which is \textbf{not} a diagonal matrix. Let $p$ be a polynomial (in one variable), with real coefficients and of degree $3$ such that $p(A) = 0$. Pick out the true statements: \begin{enumerate}[a.] \item $p = cp_A$ where $c \in \R$ and $p_A$ is the characteristic polynomial of $A$; \item if $p$ has a complex root (\emph{i.e.}\ a root with non-zero imaginary part), then $p = cp_A$, with $c$ and $p_A$ as above; \item if $p$ has a complex root, then $A$ is diagonalizable over $\C$. \end{enumerate}
  11. 2.1 Which of the following statements are true? \begin{enumerate}[a.] \item Let $\{a_{mn}\}$, $m, n \in \N$, be an arbitrary double sequence of real numbers. Then $\sum_{m=1}^{\infty}\sum_{n=1}^{\infty} a_{mn}^3 = \sum_{n=1}^{\infty}\sum_{m=1}^{\infty} a_{mn}^3$. \item Let $\{a_{mn}\}$, $m, n \in \N$, be an arbitrary double sequence of real numbers. Then $\sum_{m=1}^{\infty}\sum_{n=1}^{\infty} a_{mn}^2 = \sum_{n=1}^{\infty}\sum_{m=1}^{\infty} a_{mn}^2$. \item Let $\{a_{mn}\}$, $m, n \in \N$, be a double sequence of real numbers such that $|a_{mn}| \le \sqrt{m/n}$ for all $m, n \in \N$. Then $\sum_{m=1}^{\infty}\sum_{n=1}^{\infty} \frac{a_{mn}}{m^2 n} = \sum_{n=1}^{\infty}\sum_{m=1}^{\infty} \frac{a_{mn}}{m^2 n}$. \end{enumerate}
  12. 2.2 Let $f \in \mathcal{C}[-1, 1]$. Evaluate: $\displaystyle\lim_{h \to 0} \frac{1}{h}\int_{-h}^{h} f(t)\,dt$.
  13. 2.3 Let $f \in \mathcal{C}^1[-1, 1]$. Evaluate: $\displaystyle\lim_{n \to \infty} \frac{1}{n}\sum_{k=1}^{n} f'\left(\frac{k}{3n}\right)$.
  14. 2.4 Let $f \in \mathcal{C}[-\pi, \pi]$. Evaluate: \begin{enumerate}[a.] \item $\displaystyle\lim_{n \to \infty} \int_{-\pi}^{\pi} f(t)\cos nt\,dt$; \item $\displaystyle\lim_{n \to \infty} \int_{-\pi}^{\pi} f(t)\cos^2 nt\,dt$; \end{enumerate}
  15. 2.5 In each of the following cases, examine whether the given sequence (or series) of functions converges uniformly over the given domain: \begin{enumerate}[a.] \item $f_n(x) = \dfrac{nx}{1+nx}$, $x \in ]0, \infty[$; \item $\displaystyle\sum_{n=1}^{\infty} \frac{n\sin nx}{e^n}$, $x \in [0, \pi]$; \item $f_n(x) = \dfrac{x^n}{1+x^n}$, $x \in [0, 2]$. \end{enumerate}
  16. 2.6 Compute $F'(x)$ where $F(x) = \displaystyle\int_{-x}^{x} \frac{1 - e^{-xy}}{y}\,dy,\ x > 0$.
  17. 2.7 Let $a > 0$ and let $k \in \N$. Evaluate: $\displaystyle\lim_{n \to \infty} a^{-nk} \prod_{j=1}^{k} \left(a + \frac{j}{n}\right)^n$.
  18. 2.8 Write down the power series expansion of the function $f(z) = 1/z^2$ about the point $z = 2$.
  19. 2.9 Let $C$ be the circle $|z + 2| = 3$ described in the anti-clockwise (\emph{i.e.}\ positive) sense in the complex plane. Evaluate: $\displaystyle\int_C \frac{dz}{z^3(z+4)}$.
  20. 2.10 Which of the following statements are true? \begin{enumerate}[a.] \item There exists an entire function $f : \C \to \C$ which takes only real values and is such that $f(0) = 0$ and $f(1) = 1$. \item There exists an entire function $f : \C \to \C$ such that $f\left(n + \frac{1}{n}\right) = 0$ for all $n \in \N$. \item There exists an entire function $f : \C \to \C$ which is onto and which is such that $f(1/n) = 0$ for all $n \in \N$. \end{enumerate}
  21. 3.1 Let $A$ and $B$ be subsets of $\R^n$. Define $A + B = \{x + y \mid x \in A,\ y \in B\}$. Pick out the true statements: \begin{enumerate}[a.] \item if $A$ and $B$ are closed sets, then $A + B$ is a closed set; \item if $A$ is an open set and if $B$ is a closed set, then $A + B$ is an open set; \item if $A$ and $B$ are compact sets, then so is $A + B$. \end{enumerate}
  22. 3.2 Let $X$ and $Y$ be metric spaces and let $f : X \to Y$ be a mapping. Pick out the true statements: \begin{enumerate}[a.] \item if $f$ is uniformly continuous, then the image of every Cauchy sequence in $X$ is a Cauchy sequence in $Y$; \item if $X$ is complete and if $f$ is continuous, then the image of every Cauchy sequence in $X$ is a Cauchy sequence in $Y$; \item if $Y$ is complete and if $f$ is continuous, then the image of every Cauchy sequence in $X$ is a Cauchy sequence in $Y$; \end{enumerate}
  23. 3.3 Which of the following statements are true? \begin{enumerate}[a.] \item If $A$ is a dense subset of a topological space $X$, then $X \setminus A$ is nowhere dense in $X$. \item If $A$ is a nowhere dense subset of a topological space $X$, then $X \setminus A$ is dense in $X$. \item The set $\R$, identified with the $x$-axis in $\R^2$, is nowhere dense in $\R^2$. \end{enumerate}
  24. 3.4 Which of the following metric spaces are separable? \begin{enumerate}[a.] \item The space $\mathcal{C}[0, 1]$, with the usual `sup-norm' metric. \item The space $\ell_1$ of all absolutely convergent real sequences, with the metric $d_1(\{a_i\}, \{b_i\}) = \sum_{i=1}^{\infty} |a_i - b_i|$. \item The space $\ell_\infty$ of all bounded real sequences, with the metric $d_\infty(\{a_i\}, \{b_i\}) = \sup_{1 \le i < \infty} |a_i - b_i|$. \end{enumerate}
  25. 3.5 Which of the following sets are compact? \begin{enumerate}[a.] \item The closed unit ball centred at $0$ and of radius $1$ of $\ell_1$ (see Question 3.4(b) above). \item The set of all unitary matrices in $\M_2(\C)$. \item The set of all matrices in $\M_2(\C)$ with determinant equal to unity. \end{enumerate}
  26. 3.6 Which of the following sets are connected? \begin{enumerate}[a.] \item The set $\{(x, y) \in \R^2 \mid xy = 1\}$ in $\R^2$. \item The set of all symmetric matrices in $\M_n(\R)$. \item The set of all orthogonal matrices in $\M_n(\R)$. \end{enumerate}
  27. 3.7 Which of the following metric spaces are complete? \begin{enumerate}[a.] \item The space of all continuous real-valued functions on $\R$ with compact support, with the usual `sup-norm' metric. \item The space $\mathcal{C}[0, 1]$ with the metric $d_1(f, g) = \int_0^1 |f(t) - g(t)|\,dt$. \item The space $\mathcal{C}^1[0, 1]$ with the metric $d(f, g) = \max_{t \in [0, 1]} |f(t) - g(t)|$. \end{enumerate}
  28. 3.8 Let $X_j = \mathcal{C}[0, 1]$ with the metric $d_1$ (see Question 3.7(b) above) when $j = 1$, the metric $d_2(f, g) = \left(\int_0^1 |f(t) - g(t)|^2\,dt\right)^{\frac{1}{2}}$ when $j = 2$ and the usual `sup-norm' metric when $j = 3$. Let $\mathrm{id} : \mathcal{C}[0, 1] \to \mathcal{C}[0, 1]$ be the identity map. Pick out the true statements: \begin{enumerate}[a.] \item $\mathrm{id} : X_2 \to X_1$ is continuous; \item $\mathrm{id} : X_1 \to X_3$ is continuous; \item $\mathrm{id} : X_3 \to X_2$ is continuous. \end{enumerate}
  29. 3.9 Which of the following statements are true? \begin{enumerate}[a.] \item Consider the subspace $S^1 = \{(x, y) \in \R^2 \mid x^2 + y^2 = 1\}$ of $\R^2$. Then, there exists a continuous function $f : S^1 \to \R$ which is onto. \item There exists a continuous function $f : S^1 \to \R$ which is one-one. \item Let $X = \{A = (a_{ij}) \in \M_2(\R) \mid \tr(A) = 0 \text{ and } |a_{ij}| \le 2 \text{ for all } 1 \le i, j \le 2\}$. Let $Y = \{\det(A) \mid A \in X\} \subset \R$. Then, there exist $\alpha < 0$ and $\beta > 0$ such that $Y = [\alpha, \beta]$. \end{enumerate}
  30. 3.10 Let $S^1 \subset \R^2$ be as in Question 3.9(a) above. Let $D = \{(x, y) \in \R^2 \mid x^2 + y^2 \le 1\}$ and $E = \{(x, y) \in \R^2 \mid 2x^2 + 3y^2 \le 1\}$ be also considered as subspaces of $\R^2$. Which of the following statements are true? \begin{enumerate}[a.] \item If $f : D \to S^1$ is a continuous mapping, then there exists $x \in S^1$ such that $f(x) = x$. \item If $f : S^1 \to S^1$ is a continuous mapping, then there exists $x \in S^1$ such that $f(x) = x$. \item If $f : E \to E$ is a continuous mapping, then there exists $x \in E$ such that $f(x) = x$. \end{enumerate}
  31. 4.1 Find the family of orthogonal trajectories of the family of curves $y = cx^2$.
  32. 4.2 Let $f \in \mathcal{C}[0, 1]$ be given. Consider the problem: find a curve $u$ such that $u(0) = u(1) = 0$ which minimizes the functional \[ J(v) = \frac{1}{2}\int_0^1 (v'(x))^2\,dx - \int_0^1 f(x)v(x)\,dx \] over all admissible curves $v$. Write down the boundary value problem (Euler-Lagrange equation) satisfied by the solution $u$.
  33. 4.3 Let $\omega \in \R$ be a constant. Solve: \[ \frac{dx(t)}{dt} = x(t) - \omega y(t),\quad \frac{dy(t)}{dt} = \omega x(t) + y(t),\quad t > 0,\qquad x(0) = y(0) = 1. \]
  34. 4.4 Let $b \in \R$ be a constant. Solve: \[ \frac{\partial u}{\partial t}(x, t) + b\frac{\partial u}{\partial x}(x, t) = 0,\quad x \in \R,\ t > 0,\qquad u(x, 0) = x^2. \]
  35. 4.5 Let $v$ be a smooth harmonic function on $\R^n$. If $r^2 = \sum_{i=1}^{n} |x_i|^2$, where $x = (x_1, \dots, x_n) \in \R^n$, and if $v$ is a radial function, \emph{i.e.}\ $v(x) = v(r)$, write down the ordinary differential equation satisfied by $v$.
  36. 4.6 Let $a$ and $b$ be positive constants. Let $y$ satisfy $y''(t) + ay'(t) + by(t) = 0$, $t > 0$, $y(0) = 1$ and $y'(0) = 1$. Write down the Laplace transform of $y$.
  37. 4.7 Write down the Newton-Raphson iteration scheme to find $1/\sqrt{a}$, where $a > 0$, by solving the equation $x^{-2} - a = 0$.
  38. 4.8 Let $B \in \M_n(\R)$ and let $b \in \R^n$ be a given fixed vector. Consider the iteration scheme $x_{n+1} = Bx_n + b$, $x_0$ given. Pick out the true statements: \begin{enumerate}[a.] \item the scheme is always convergent for any initial vector $x_0$. \item if the scheme is always convergent for any initial vector $x_0$, then $I - B$ is invertible. \item if the scheme is always convergent for any initial vector $x_0$, then every eigenvalue $\lambda$ of $B$ satisfies $|\lambda| < 1$. \end{enumerate}
  39. 4.9 Let \[ A = \begin{bmatrix} 1 & -2 & 3 & -2 \\ 1 & 1 & 0 & 3 \\ -1 & 1 & 1 & -1 \\ 0 & -3 & 1 & 1 \end{bmatrix}. \] Pick out the smallest disc in the complex plane containing all the eigenvalues of $A$ from amongst the following:\\ a.\ $|z - 1| \le 7$; \qquad b.\ $|z - 1| \le 6$; \qquad c.\ $|z - 1| \le 4$.
  40. 4.10 Solve: maximize $z = 7x + 5y$ such that $x \ge 0$, $y \ge 0$ and $x + 2y \le 6$, $4x + 3y \le 12$.
  41. 5.1 Which of the following sets are countable? \begin{enumerate}[a.] \item The set of all sequences of non-negative integers. \item The set of all sequences of non-negative integers with only a finite number of non-zero terms. \item The set of all roots of all monic polynomials in one variable with rational coefficients. \end{enumerate}
  42. 5.2 A magic square of order $N$ is an $N \times N$ matrix with positive integral entries such that the elements of every row, every column and the two diagonals all add up to the same number. If a magic square is filled with numbers in arithmetic progression starting with $a \in \N$ and common difference $d \in \N$, what is the value of this common sum?
  43. 5.3 A committee consists of $n$ members and a group photograph is to be taken by seating them in a row. If two particular members do not get along with each other, in how many ways can the committee members be seated so that these two are never adjacent to each other?
  44. 5.4 Let $n \ge 2$ and let $D_n$ be the number of permutations of $\{1, 2, \dots, n\}$ which leave no symbol fixed. (For example: $D_2 = 1$). Write down an expression for $D_n$ in terms of $D_k$, $2 \le k \le n - 1$.
  45. 5.5 Five letters are addressed to five different persons and the corresponding envelopes are prepared. The letters are put into the envelopes at random. What is the probability that no letter is in its proper envelope?
  46. 5.6 Which of the following statements are true? \begin{enumerate}[a.] \item The $9$-th power of any positive integer is of the form $19m$ or $19m \pm 1$. \item For any positive integer $n$, the number $n^{13} - n$ is divisible by $2730$. \item The number $18! + 1$ is divisible by $437$. \end{enumerate}
  47. 5.7 Let $a_i$, $1 \le i \le n$ be non-negative real numbers. Let $S$ denote their sum. Pick out the true statements: \begin{enumerate}[a.] \item $\prod_{k=1}^{n} (1 + a_k) \ge 1 + S$; \item $\prod_{k=1}^{n} (1 + a_k) \le 1 + \frac{S}{1!} + \frac{S^2}{2!} + \dots + \frac{S^n}{n!}$; \item $\prod_{k=1}^{n} (1 + a_k) \le \frac{1}{1 - S}$, if $S < 1$. \end{enumerate}
  48. 5.8 Consider the Fibonacci sequence $\{a_n\}$ defined by $a_0 = 0$, $a_1 = 1$, $a_{n+1} = a_n + a_{n-1}$, $n \ge 1$. Write down its enumerating function, \emph{i.e.}\ the function with the formal power series expansion $\sum_{n=0}^{\infty} a_n x^n$.
  49. 5.9 Find the lengths of the semi-axes of the ellipse whose equation is given by $5x^2 - 8xy + 5y^2 = 1$.
  50. 5.10 Let $x_0 = a$ and $x_1 = b$. Define $x_{n+1} = \left(1 - \frac{1}{2n}\right)x_n + \frac{1}{2n}x_{n-1}$, $n \ge 1$. Find $\lim_{n \to \infty} x_n$.
