MMC-12

Complex Analysis
M.Sc. Mathematics · Semester I2025
  1. 1(a) Let $f(z)$ be a continuous function in a simply connected domain $D$ and $z_0$ be any arbitrary but fixed point in $D$. If $F(z)=\int_{z_0}^zf(w)dw$, where the integral is independent of the path so long as the path lies in $D$, then show that $F^\prime(z)=f(z)$ for every $z$ in $D$. [5]
  2. 1(b) State Maximum modulus theorem. Using this theorem show that $f(z)=z^{10}+z^5+1$ vanishes at least for one point in $|z|<2$. [1+3]
  3. 1(c) State minimum modulus theorem. [1]
  4. 2(a) State and prove Laurent's theorem. [1+5]
  5. 2(b) Expand $f(z)=\dfrac1{(z-2)(z-4)}$ in Laurent series in the region $|z|>4$. [3]
  6. 2(c) State Casorati-Weierstrass theorem. [1]
  7. 3(a) State and prove Schwarz's lemma. [1+3]
  8. 3(b) Show that if $\alpha$ is a pole of $f(z)$ of order $n$ then $f(z)=\frac{\phi(z)}{(z-\alpha)^n}$, where $\phi(z)$ is analytic at $\alpha$ and $\phi(\alpha)\ne0$. [3]
  9. 3(c) If $f(z)$ has a pole at $\alpha$ of order $n$ then show that $|f(z)|\to\infty$ as $z\to\alpha$ in any manner. [3]
  10. 4(a) Define zeros of a non-constant analytic function. Prove that the zeros of a non-constant analytic function are isolated points. [1+3]
  11. 4(b) Find the singularities of the function $f(z)=tan(\frac1z)$ and determine the nature of the singularities. [3]
  12. 4(c) Prove that limit point of the zeros of an analytic function is an essential singularity of the function, unless the function is identically zero. [3]
  13. 5(a) Let $f(z)$ be analytic within and on a positively oriented simple closed curve $C$ except for a finite number of poles within $C$ and let $f(z)\ne0$ any where on $C$, then show that\par \hspace*{2em}$\frac1{2\pi}\Delta_C\,\mathrm{arg}f(z)=Z-P,$\par where $Z=$ the number of zeros of $f(z)$ within $C$, a zero of order $m$ being counted $m$ times,\par and $P=$ the number of poles of $f(z)$ within $C$, a pole of order $n$ being counted $n$ times. [6]
  14. 5(b) State Cauchy's residues theorem. Using this theorem evaluate $\int_C\frac{z-1}{z^2-2z}dz$, where $C$ is the circle $|z|=\frac52$. [1+2]
  15. 5(c) State Rouche's theorem. [1]
  16. 6(a) Prove that a function which is analytic every where including the point at infinity is a constant. [2]
  17. 6(b) Find $Res[f(z),\infty]$, where $f(z)=\frac z{z^2-1}$ . [3]
  18. 6(c) Evaluate any one of the following by the method of contour integration:\par (i) $\int_0^\infty\cos x^2dx$, ; (ii) $\int_{-\infty}^\infty\frac{x\sin x\,dx}{a^2x^2+b^2},a,b>0.$ [5]
