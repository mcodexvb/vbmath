MMO-41(P3)

Advanced Real Analysis-II
M.Sc. Mathematics · Semester IV2023
  1. 1(a) When is a sequence of sets $\{E_n\}$ called convergent? Show that a monotone sequence of sets is convergent. [[4]]
  2. 1(b) Show that a sequence of sets $\{E_n\}$ is monotone if and only if the sequence of its characteristic function $\{\chi_{E_n}\}$ is monotone of the same type. [[4]]
  3. 1(c) Suppose $\psi$ is a completely additive set function defined on an algebra $\mathcal A$ and if $\{E_n\}\subset\mathcal A$ is an increasing sequence of sets such that $\bigcup E_n\in\mathcal A$, then show that $\lim_{n\to\infty}\psi(E_n)=\psi(\lim_{n\to\infty}E_n)$. [[4]]
  4. 2(a) State and prove Caratheodary Hahn extension theorem [[7]]
  5. 2(b) Define finite and $\sigma$-finite measure. Show that the Lebesgue measure on $\mathbb R$ is $\sigma$-finite. [[3]]
  6. 2(c) Show that the Lebesgue measure is complete. [[2]]
  7. 3(a) Describe Method-I construction of outer measure $\mu^*$. Show that this outer measure is regular. [[3+2]]
  8. 3(b) Prove that there exist outer measures which are not regular. [[3]]
  9. 3(c) Define metric outer measure. Suppose $\mu^*$ is a metric outer measure on a metric space $X$. Show that all Borel sets in $X$ are $\mu^*$-measurable. [[1+3]]
  10. 4(a) Define Lebesgue Stieltjes outer measure. Show that for any semiclosed interval $(a,b]$, $\mu_f^*((a,b])=f(b)-f(a)$. [[2+5]]
  11. 4(b) Prove that every Borel measure $\mu$ is the Lebesgue - Stieltjes measure induced by the distribution function corresponding to $\mu$ [[5]]
  12. 5(a) If $f$ and $g$ are integrable on $E$ and $f\ge g$ on $E$ then show that $\int_E f\,d\mu\ge\int_E g\,d\mu$. [[3]]
  13. 5(b) State and prove Monotone convergence theorem for a measure space $X$. Show that for any sequence of non negative measurable functions $\{f_n\}$ defined on $X$ \[\int_X\left(\sum_{n=1}^\infty f_n\right)d\mu=\sum_{n=1}^\infty\left(\int_X f_n\,d\mu\right)\] [[2+2]]
  14. 5(c) If $f$ is a nonnegative measurable function on $X$ and $\nu(E)=\int_E f\,d\mu$, then show that $\nu$ is a measure on $X$. Also show that for another nonnegative function $g$, \[\int_E g\,d\nu=\int_E gf\,d\mu\] [[2+3]]
  15. 6 Answer any two
  16. 6(a) Give examples of a complete and an incomplete measure. [[2]]
  17. 6(b) Let $X$ be a non void set. Define $\mu^*(\emptyset)=0$ and $\mu^*(E)=1$ for every set $E\subset X,E\ne\emptyset$. Show that $\mu^*$ is an outer measure and if $X$ contains more than one point then $\mu^*$ is not a measure. [[2]]
  18. 6(c) Let $(\mathbb N,\mathcal P(\mathbb N),\mu)$ be a measure space, where $\mu$ is counting measure. Show that $\{x_n\}$ is integrable if and only if $\sum x_n$ absolutely convergent. [[2]]
