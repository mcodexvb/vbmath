MMO-31(P9)

Advanced Real Analysis-I
M.Sc. Mathematics · Semester III2017
  1. 1(a) Define upper limit and lower limit of a function at a point $x$. Using definition, show that upper limit of $\sin\frac1x$ at zero is 1. [4]
  2. 1(b) Show that for any function $f$ the set of all points at which $f$ assumes a strict maximum value or strict minimum value is countable. [2]
  3. 1(c) For any function $f:\mathbb R\to\mathbb R$ show that the set $\{x:D^-f(x)<D_+f(x)\}$ is countable. [3]
  4. 1(d) Suppose $f$ is continuous on an interval $I$ and $D^+f\ge0$ except on a countable set in $I$. Then show that $f$ is nondecreasing on $I$. [3]
  5. 2(a) What do you mean by a Vitali cover for a given set? State and prove Vitali covering theorem. [2+1+6]
  6. 2(b) If $f:[a,b]\to\mathbb R$ is absolutely continuous and $f'(x)\ge0$ a.e on $[a,b]$, then show that $f$ is nondecreasing on $[a,b]$. [3]
  7. 3(a) If $f:[a,b]\to\mathbb R$ is monotone increasing then show that $f'$ is Lebesgue integrable in $[a,b]$ and $0\le\displaystyle\int_a^bf'(x)dx\le f(b)-f(a)$. [4]
  8. 3(b) If $f$ is Lebesgue integrable on $[a,b]$ then show that $F(x)=\displaystyle\int_a^xf(t)dt,\ x\in[a,b]$ is absolutely continuous on $[a,b]$. [4]
  9. 3(c) Define contor function on $[0,1]$. Show that it is nondecreasing. [4]
  10. 4(a) Let $f:[a,b]\to\mathbb R$. Prove that the function $f$ is u.s.c. on $[a,b]$ if and only on the set $E=\{x\in[a,b]:f(x)\ge c\}$ is closed for each real no. $c$. [6]
  11. 4(b) If $f$ is Baire-1 on $[a,b]$ then show that the set of points of discontinuity of $f$ is of 1st category. \par\hfill P.T.O. [6]
  12. 5(a) Let $I$ be an interval and $f:I\to\mathbb R$ be a convex function. Show that $f$ is continuous on a interior of $I$. [2]
  13. 5(b) State and Prove Jensen's inequality for a convex function. [2]
  14. 5(c) State and prove three chords lemma for a convex function. Show also that for a convex function $f:(a,b)\to\mathbb R$, $f'_+$ and $f'_-$ exist at every $x\in(a,b)$ and they are nondecreasing. [3+5]
  15. 6 Answer any two of the following. \par \hspace*{1em}a) Show that $f(x)=x^4+\sin x$ is absolutely continuous on $[0,1]$. \par \hspace*{1em}b) Define $F_\sigma$ set and $G_\delta$ set. Give examples with justifications of $F_\sigma$ and $G_\delta$ sets which are neither closed nor open. \par \hspace*{1em}c) For a function $f:[a,b]\to\mathbb R$ if $D^+f$ is continuous on $[a,b]$ then show that $f'$ exists on $[a,b]$ and $f'=D^+f$ on $[a,b]$. [2]
