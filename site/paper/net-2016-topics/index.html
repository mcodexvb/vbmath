Let $D$ be the open unit disc in $C$ and $H(D)$ be the collection of all holomorphic funct ions on it.Let \\ $S=\{f\in H(D):f(\frac{1}{2})=\frac{1}{2},f(\frac{1}{4})=\frac{1}{4},\cdots,f(\frac{1}{2n})=\frac{1}{2n},\cdots\}$ \\and\\ $T=\{f\in H(D):f(\frac{1}{2})=f(\frac{1}{3})=\frac{1}{2},f(\frac{1}{4})=f(\frac{1}{5})=\frac{1}{4},\cdots,f(\frac{1}{2n})=f(\frac{1}{2n+1})=\frac{1}{2n},\cdots\}$ \begin{enumerate} \item Both $S,T$ are singleton sets \item $S$ is a singleton set but $T=\phi$ \item $T$ is a singleton set but $S=\phi$ \item Both $S,T$ are empty \end{enumerate} % booklet-4C q no.-34 page no.6
  2. The residue of the function\\ $f(z)=e^{-e^{\frac{1}{z}}}$ at $z=0$ is: \begin{enumerate} \item $1+e^{-1}$ \item $e^{-1}$ \item $-e^{-1}$ \item $1-e^{-1}$ \end{enumerate} % booklet-4C q no.-36 page no.6
  3. Consider the function $F(z)=\int\limits_{1}^{2}\frac{1}{(x-z)^2}dx$ ,$Im(z)>0$.\\Then there is a meromorphic function $G(z)$ on $\mathbb{C}$ that agrees with $F(z)$ when $Im(z)>0$,such that \begin{enumerate} \item $1,\infty$ are poles of $G(z)$ \item $0,1,\infty$ are poles of $G(z)$ \item $1,2$ are poles of $G(z)$ \item $1,2$ are simple poles of $G(z)$ \end{enumerate} [M] % booklet-4C q no.-80 page no.12
  4. Let $f:\mathbb{C}\rightarrow \mathbb{C}$ be an entire function.Suppose that $f=u+iv$ where $u,v$ are the real and imaginary parts of $f$ respectively.Then $f$ is constant if \begin{enumerate} \item $\{u(x,y):z=x+iy\in \mathbb{C}\}$ is bounded \item $\{v(x,y):z=x+iy\in \mathbb{C}\}$ is bounded \item $\{u(x,y)+v(x,y):z=x+iy\in \mathbb{C}\}$ is bounded \item $\{u^2(x,y)+v^2(x,y):z=x+iy\in \mathbb{C}\}$ is bounded \end{enumerate} [M] % booklet-4C q no.-81 page no.12
  5. Let $H=z=x+iy\in \mathbb{C}:y>0$ be the upper half plane plane and $D=\{z\in \mathbb{C}:|z|<1\}$ be the open unit disc.Suppose that $f$ is a mobius transformation,which maps $H$ conformally onto $D$.Suppose that $f(2i)=0$.Pick each correct statement from below. \begin{enumerate} \item $f$ has a simple pole at $z=-2i$ \item $f$ satisfies $f(i)\overline{f(i)}$=1 \item $f$ has an essential singularity at $Z=-2i$ \item $|f(2+2i)|=\frac{1}{\sqrt{5}}$ \end{enumerate} [M] % booklet-4C q no.-79 page no.12
  6. Let $A=\{z\in \mathbb{C}:|z|>1\}$,$B=\{z\in \mathbb{C}:z\neq 0\}$.Which of the following are true? \begin{enumerate} \item There is a continuous onto function $f:A\rightarrow B$ \item There is a continuous one to one function $f:B\rightarrow A$ \item There is a nonconstant analytic function $f:B\rightarrow A$ \item There is a nonconstant analytic function $f:A\rightarrow B$ \end{enumerate} [M] % booklet-4C q no.-86 page no.13
  7. Let $a,b,c,d $ be four functions defines on $\mathbb{R}^2 $. Then the partial differential equation $$\left(a(x,y)\frac{\partial}{\partial x}+b(x,y)\frac{\partial}{\partial y}\right)\left(c(x,y)\frac{\partial}{\partial x}+d(x,y)\frac{\partial}{\partial y}\right)u=0$$ is \begin{enumerate} \item always hyperbolic. \item always parabolic. \item never parabolic. \item never elliptic. \end{enumerate}
  8. For the Cauchy problem $$u_t-uu_x=0,\quad x\in \mathbb{R} ,t>0,u(x,0)=x,x\in \mathbb{R}$$ which of the following statements is true? \begin{enumerate} \item The solution $u$ exits for all $t>0$. \item The solution $u$ exists for $t<\frac{1}{2}$ and breaks down at $t=\frac{1}{2}.$ \item The solution $u$ exists for $t<1$ and breaks down at $t=1$ \item The solution $u$ exists for $t<2$ and breaks down at $t=2$. \end{enumerate}
  9. Let $u:\mathbb{R}\times [0,\infty)\to \mathbb{R}$ be a solution of the initial value problem $$u_{tt}-u_{xx}=0,\text{ for }(x,t)\in \mathbb{R}\times [0,\infty) $$ $u(x,0)=f(x),x\in \mathbb{R},u_t(x,0)=g(x),x\in \mathbb{R}$. Suppose $f(x)=g(x)=0$ for $x\notin [0,1]$ then we always have \begin{enumerate} \item $u(x,t)=0$ for all $(x,t) \in (-\infty,0)\times (0,\infty)$. \item $u(x,t)=0$ for all $(x,t) \in (1,\infty)\times (0,\infty)$. \item $u(x,t)=0$ for all $(x,t)$ satisfying $x+t<0$ \item $u(x,t)=0$ for all $(x,t)$ satisfying $x-t>1$ \end{enumerate} [M]
  10. Consider the Cauchy problem for the Eikonal equation $$p^2+q^2=1;\quad p\equiv \frac{\partial u}{\partial x} ,q\equiv \frac{\partial u}{\partial y},u(x,y)=0 \text{ on } x+y=1,$$ $(x,y)\in \mathbb{R}^2.$ Then \begin{enumerate} \item The Charpit's equations for the differential equation are $\frac{dx}{dt}=2p;\frac{dy}{dt}=2q ; \frac{du}{dt}=2; \frac{dp}{dt}=-p;\frac{dq}{dt}=-q$ \item The Charpit's equations for the differential equation are $\frac{dx}{dt}=2p;\frac{dy}{dt}=2q ; \frac{du}{dt}=2; \frac{dp}{dt}=0;\frac{dq}{dt}=0$ \item $u(1,\sqrt{2})=\sqrt{2}$ \item $u(1,\sqrt{2})=1$ \end{enumerate} [M]
  11. Let $u$ be the solution of the boundary value problem $u_{xx}+u_{yy}=o $ for $0<x,y<\pi,u(x,0)=0=u(x,\pi) $ for $0\le x \le \pi, u(0,y)=0,u(\pi,y)=\sin{y}+\sin{2y}$ for $0\le y\le\pi$. Then \begin{enumerate} \item $u\left(1,\frac{\pi}{2}\right)= (\sinh{(\pi)})^{-1}\sinh(1)$ \item $u\left(1,\frac{\pi}{2}\right)= (\sinh{(1)})^{-1}\sinh(\pi)$ \item $u\left(1,\frac{\pi}{4}\right)= (\sinh{(\pi)})^{-1}(\sinh(1))\frac{1}{\sqrt{2}}+$\\$(\sinh{(2\pi)})^{-1}(\sinh(2))$ \item $u\left(1,\frac{\pi}{4}\right)= (\sinh{(1)})^{-1}(\sinh(\pi))\frac{1}{\sqrt{2}}+$\\ $(\sinh{(2)})^{-1}(\sinh(2\pi))$ \end{enumerate} [M]
  12. Which of the followings is/are true? \begin{enumerate} \item(0,1) with the usual topology admits a metric which is complete \item (0,1) with the usual topology admits a metric which is not complete \item [0,1] with the usual topology admits a metric which s not complete \item [0,1] with the usual topology admits a metric which is complete \end{enumerate}
  13. Let A be any set. Let $\mathbb{P}(A) $ be the power set of A , that is ,the set of all subsets of A: $\mathbb{P}(A)=\{B:b\subseteq A\} $. Then which of the following is/are true about the set $\mathbb{P}(A) $? \begin{enumerate} \item $\mathbb{P}(A)=\phi $ for some A \item $\mathbb{P}(A) $ is a finite set for some A. \item $\mathbb{P}(A) $ is countable for some A. \item $\mathbb{P} $ is uncountable for some A \end{enumerate}
  14. Let V be the span of (1,1,1) and $(0,1,1)\in \mathbb{R}^2 $.Let $u_1=(0,0,1),u_2=(1,1,0)$ and $u_3=(1,0,1) $. Which of the following are correct? \begin{enumerate} \item $(\mathbb{R}^3\setminus V)\cup \{)0,0,0)\} $ is not connected \item $(\mathbb{R}^3\setminus V)\cup \{tu_1+(1-t)u_3:0\leq t\leq 1\} $ is connected \item $(\mathbb{R}^3\setminus V)\cup \{tu_1+(1-t)u_2:0\leq t \leq 1\} $ is connected \item $(\mathbb{R}^3\setminus V)\cup \{(t,2t,3t);t\in \mathbb{R}\} $ is connected \end{enumerate}
  15. Consider the real vector V of polynomials of degree less than or equal to d.For $p\in V$ define $$ ||p||_k=max\{|p(0)|,|p^{(1)}(0)|,...,|p^{(k)}(0)|\} $$, where $p^{(i)}(0) $ is the $i^{th} $ derivative of p evaluated at 0. Then $||p||_k $ defines a norm on V if and only if \begin{enumerate} \item $ k\geq d-1 $ \item $ k<d $ \item $ k\geq d $ \item $ k<d-1 $ \end{enumerate}
  16. Suppose $\{v_1,v_2,...,v_n\} $ are unit vectors in $\mathbb{R}^n $ such that $$ ||v||^2=\Sigma _{i=1}^n |\langle v_i,v \rangle |^2,\forall v \in \mathbb{R}^n $$.Then decide the correct statement in the following. \begin{enumerate} \item $v_1,v_2,...,v_n $ are mutually orthogonal \item $\{v_1,v_2,...,v_n \} $ is a basis of $\mathbb{R}^n $ \item $v_1,v_2,..,v_n $ are not mutually orthogonal \item Atmost n-1 of the elements in the set $\{v_1,v_2,..v_n\} $ can be orthogonal \end{enumerate}
  17. Consider the smallest topology $\tau $ on $\mathbb{C} $ in which all the singleton sets are closed. Pick each correct statement from the below: \begin{enumerate} \item $(\mathbb{C},\tau )$ is Housdroff \item $(\mathbb{C},\tau) $ is compact \item $(\mathbb{C},\tau )$ is connected \item $ \mathbb{Z} $ is dense in $\mathbb{C},\tau)$. \end{enumerate}
  18. Let $\{x|_{\alpha \in I} $ be discrete topological spaces and let $X=\prod _{\alpha \in I} X_\alpha $ . From the statements given below, pich the statement that implies that the product topology on X equals the discrete topology on X. \begin{enumerate} \item I is finite \item I is countably infinite and $X_\alpha $ are singleton for all but finitely many $\alpha $ \item I is uncountably infinite and $X_\alpha $ are singleton for all but finitely many $\alpha $ \item I is infinite and $X_\alpha $ are infinite for all $X_\alpha $ \end{enumerate} question number 71 2016-I
