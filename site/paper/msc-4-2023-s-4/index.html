MME-41

Applied Stream
M.Sc. Mathematics · Semester IV2023
  1. 1(a) State Coulomb's law in electrostatics. Using Gauss' law in electrostatics, calculate the electric field outside a uniformly charged sphere of radius $R$ and the total charge $Q$. [[1+3]]
  2. 1(b) For a point charge configuration in a spatially uniform electric field, define an electric dipole and torque. Calculate the potential energy of an electric dipole placed in an external electric field. Hence calculate the net force acting on the dipole. [[2+3+1]]
  3. 2(a) Derive the equation of continuity for a steady state current of electric charges. What is Ohm's law? Use it to show that for a steady state current, the continuity equation reduces to the Laplace equation for the electrostatic potential. [[2+2+1]]
  4. 2(b) Define the magnetic force acting on a charged particle of charge $q$. State and explain the Amp\`ere's circuital law. What are the shortcomings of this law? [[1+2+2]]
  5. 3(a) Explain the phenomenon of electromagnetic induction and hence establish the differential form of Faraday's law. [[2+3]]
  6. 3(b) State and prove the Poynting's theorem. What is Poynting's vector? [[1+3+1]]
  7. 1 Choose the correct alternative (\emph{any five}).
  8. 1(a) What does MATLAB stand for? (i) Math Laboratory (ii) Matrix Laboratory (iii) Mathworks (iv) Mathematics Lab. [[2]]
  9. 1(b) Which of the following is not a predefined variable in MATLAB? (i) pi (ii) inf (iii) i (iv) gravity. [[2]]
  10. 1(c) In MATLAB $--$ command is used to add text label to $x$-axis. (i) XAxis (ii) xaxis (iii) Xlabel (iv) xlabel. [[2]]
  11. 1(d) Which type of analysis is not done by MATLAB software? (i) Numerical computing (ii) Algebraic solutions (iii) Plant planning analysis (iv) Dynamic system simulations. [[2]]
  12. 1(e) Which of the following is not a valid plotting command in MATLAB? (i) Figure (ii) Prod (iii) Print (iv) Plot. [[2]]
  13. 1(f) Which of the following correctly defines $x$, $y$, and $z$ as symbols? (i) sym (x,y,z) (ii) syms x y z (iii) syms x, y, z (iv) sym x, y, z. [[2]]
  14. 1(g) Which of these is the way to access the first element in a vector named $v$ (assuming that there is at least one element in the vector)? (i) $v(0)$ (ii) $v(1)$ (iii) $v$ (iv) $v(:,0)$. [[2]]
  15. 1(h) To add a comment to an mfile, the MATLAB command is (i) \% (ii) \& (iii) comment (' ') (iv) \#. [[2]]
  16. 1(i) The output of Cat=[’Cat”Dog’] is (i) ’Cat’Dog’ (ii) Cat Dog (iii) CatDog (iv) Cat \& Dog. [[2]]
  17. 2(a) If $A=[1\ 3\ 5;2\ 4\ 6;7\ 8\ 9]$ is a matrix, then write the outputs of (i) $A(3,2)$, (ii) $A(2:3,3)$, (iii) $A(2,:)$, and (iv) $A(:,3)$. [[6]]
  18. 2(b) Write the Matlab command to find the roots of a polynomial equation $5x^5-x^2+7=0$. [[2]]
  19. 2(c) Write a MATLAB program to plot the function $f(x)=e^{-x}\sin x$, $-\pi\le x\le\pi$. [[2]]
  20. 3 Write a MATLAB program to solve the coupled nonlinear equations: $x=y+\cos(x+y)$, $y=x+\sin(xy)$. \fbox{\shortstack[l]{Use separate answer\\script for each unit}} [[10]]
