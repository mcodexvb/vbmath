  1. 1 In the Revised Simplex Method (RSM), which matrix is updated at each iteration to compute the current basic feasible solution, optimized costs, and the entering variable? Justify your answer. Use RSM to solve the following LPP: \[\begin{aligned}\text{Minimize}\quad& f(x_1,x_2)=-2x_1+3x_2\\\text{subject to}\quad&2x_1-5x_2\le7,\\&4x_1+x_2\le8,\\&7x_1+2x_2\le16,\\&x_1,x_2\ge0.\end{aligned}\] [[2+8]]
  2. 2 What is an integer linear programming problem (ILPP) and how does it differ from a standard linear programming problem (LPP)?\par Solve the following LPP by using Gomory's Cutting Plane Method or Branch and Bound Method: \[\begin{aligned}\text{Maximize}\quad& f(x_1,x_2)=x_1+5x_2\\\text{subject to}\quad&3x_1+4x_2\le6,\\&x_1+3x_2\ge3,\\&x_1,x_2\text{ are non-negative integers.}\end{aligned}\] [[2+8]]
  3. 3 What is the main purpose of conducting sensitivity analysis in an LPP?\par Consider the following LPP: \[\begin{aligned}\text{Maximize}\quad& f(x_1,x_2)=6x_1+8x_2\\\text{subject to}\quad&x_1+2x_2\le12,\\&x_1+x_2\le10,\\&x_1,x_2\ge0.\end{aligned}\] Suppose a new product has been added to the existing product mix. The profit per unit of the new product is Rs. 20. The processing requirements per unit for the new product are 6 and 5 hours, respectively.
  4. 3(a) Check whether the inclusion of the new product changes the optimality.
  5. 3(b) If it changes the optimality, find the revised optimal solution. Is the new optimal solution unique?
  6. 4(a) Solve the following nonlinear programming problem (NLPP) graphically: \[\begin{aligned}\text{Maximize}\quad& f(x_1,x_2)=x_1+2x_2\\\text{subject to}\quad&x_1-(x_2-3)^2\le3\\&x_2\le3,\\&x_1,x_2\ge0.\end{aligned}\]
  7. 4(b) Use the Kuhn-Tucker necessary and sufficient conditions to solve the following NLPP: \[\begin{aligned}\text{Maximize}\quad& f(x_1,x_2)=16x_1+20x_2-3x_1^2-x_2^2-(x_1+x_2)^2\\\text{subject to}\quad&x_1+x_2\le9\\&x_1,x_2\ge0.\end{aligned}\] [[5+5]]
