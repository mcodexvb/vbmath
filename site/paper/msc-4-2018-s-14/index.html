MMO-41(P9)

Advanced Real Analysis-II
M.Sc. Mathematics · Semester IV2018
  1. 1(a) Define limsup and liminf for a sequence of sets $\{E_n\}$. Show that $\inf E_n\subset\liminf E_n\subset\limsup E_n\subset\sup E_n.$ [3]
  2. 1(b) What is completely additive set function? If $\psi$ is completely additive set function defined on a $\sigma$-algebra $\mathcal A$ and $\{E_n\}$ be a monotone increasing sequence in $\mathcal A$, then show that $\psi(\bigcup E_n)=\sum\psi(E_n).$ [4]
  3. 1(c) What is premeasure and covering family. Show that outer measure can be constructed from a premeasure. [5]
  4. 2(a) What is regular outer measure? Suppose an outer measure $\mu^*$ is constructed from a premeasure and a covering family $\mathcal F$. If all members of $\mathcal F$ are $\mu^*$-measurable then show that $\mu^*$ is regular. [1+4]
  5. 2(b) What is metric outer measure? Let $\mu^*$ be an outer measure on a metric space $X$. Show that every Borel set in $X$ is measurable if and only if $\mu^*$ is a metric outer measure. [1+6]
  6. 3(a) Define Lebesgue-Stieltjes outer measure. Show that it is regular. [4]
  7. 3(b) For Lebesgue-Stieltjes outer measure $\mu^*_f$ show that $\mu^*_f\{a\}=f(a)-f(a-)$ and $\mu^*_f(a,b)=f(b-)-f(a).$ [3]
  8. 3(c) Show that every finite Borel measure $\mu$ is the Lebesgue-Stieltjes measure induced by the distribution function $F(x)=\mu(-\infty,x].$ [5]
  9. 4(a) What is signed measure. State and prove Hahn decomposition theorem for signed measure. [6]
  10. 4(b) Let $(X,\mathcal M,\mu)$ be a finite measure space and let $f$ be a measurable function defined on $X$. If $f$ is finite a.e, then show that for every $\varepsilon>0$ there is a bounded function $g_\varepsilon$ such that $\mu\{x:g(x)\ne f(x)\}<\varepsilon.$\par If moreover $X$ is a metric space then show that there exists a sequence $\{g_k\}$ of continuous bounded function for which $g_k\to f$ almost uniformly. [3+3]
  11. 5(a) Suppose $f$ is integrable over two sets $E$ and $F$ with $E\cap F=\Phi$. Show that $\displaystyle\int_{E\cup F}f\,d\mu=\int_Ef\,d\mu+\int_Ff\,d\mu.$ [4]
  12. 5(b) Let $(X,\mathcal M,\mu)$ be a measure space. Let $f$ be a nonnegative measurable function defined on $X$. Suppose $\nu(E)=\displaystyle\int_Ef\,d\mu$ for each $E\in\mathcal M$. Show that $\nu$ is a measure on $X$.\par If $g$ be any nonnegative measurable function on $X$ then show that $\displaystyle\int_Eg\,d\nu=\int_Egf\,d\mu.$ [3+3]
  13. 5(c) Let $X=\mathbb N,\ \mathcal M=\mathcal P(\mathbb N)$ and $\mu$ be counting measure on $X$. Show that any sequence $\{x_n\}$ is integrable if $\sum x_n$ converges absolutely. \par\hfill P.T.O. \begin{center}( 2 )\end{center} [2]
  14. 6 Answer any two.
  15. 6(a) Let $\{f_n\}$ be a sequence of nonnegative measurable functions on a measure space $X$. Then show that $\displaystyle\int_X\left(\sum f_n\right)d\mu=\sum\int_Xf_n\,d\mu.$
  16. 6(b) Show that Lebesgue measure is complete.
  17. 6(c) If $f$ is measurable and $\phi$ is continuous then show that $\phi_0f$ is measurable.
