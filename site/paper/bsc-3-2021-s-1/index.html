CCMA-5

B.Sc. Mathematics · Semester III2021
  1. 1(a) Examine whether the series \(\displaystyle\sum_{n=1}^\infty\frac{\sin n\alpha}{e^n}\ (\alpha>0)\) is convergent. [3]
  2. 1(b) Prove or disprove: If \(\sum a_n\) converges, then \(\sum a_{3n}\) converges too. [4]
  3. 1(c) Let \(\{a_n\}\) be a monotone decreasing sequence of non-negative real numbers such that \(na_n\to0\) as \(n\to0\). Discuss the convergence of the series \(\sum a_n\). [4]
  4. 2(a) Examine the convergence of the series \(1+\frac{2^2}{3^2}+\frac{2^2\cdot4^2}{3^2\cdot5^2}+\frac{2^2\cdot4^2\cdot6^2}{3^2\cdot5^2\cdot7^2}+\cdots\). [4]
  5. 2(b) Find all suitable values of \(b_n\ (n\ge1)\) such that \(\sum a_nb_n\) converges if and only if \(\sum a_n\) converges absolutely. [4]
  6. 2(c) Prove or disprove: If \(\sum a_n^2\) diverges, then \(\sum a_n\) also diverges. [2]
  7. 3(a) Let \(f:I\longrightarrow\mathbb R\) be a nonconstant function on an interval \(I\). Is \(f(I)\) necessarily an interval? Justify your answer. [4]
  8. 3(b) Construct a function \(f:\mathbb R\longrightarrow\mathbb R\) which is continuous on \(\mathbb R\setminus\{1,2,\ldots\}\). [3]
  9. 3(c) Show by examples that a real-valued continuous function on an interval may or may not be bounded. [3]
  10. 4(a) Discuss the difference of the continuity and uniform continuity of a function on some interval \([a,b]\). Determine whether the function \(f:[0,1]\longrightarrow\mathbb R\) defined by \(f(x)=\sqrt x\) is uniformly continuous on \([0,1]\).
  11. 4(b) If a function \(f:[a,b]\longrightarrow\mathbb R\) possesses the intermediate value property on \([a,b]\) and \(f(x)\ne f(y)\) for any two distinct points \(x,y\in[a,b]\), then show that \(f\) is uniformly continuous on \([a,b]\). [4]
  12. 5(a) What are the total variation and the variation function of a function of bounded variation on a closed and bounded interval? Show that the variation function \(V\) of a continuous function \(f:[a,b]\longrightarrow\mathbb R\) is continuous on \([a,b]\).
  13. 5(b) Let \(I=[a,b]\). Then prove or disprove: A uniformly continuous function on \(I\) is a function of bounded variation on \(I\). [4]
  14. 6(a) Let \(f:[a,b]\longrightarrow\mathbb R\) be a bounded function on \([a,b]\). Define the Riemann integral of \(f\) in two different approaches. [4]
  15. 6(b) If \(f:[a,b]\longrightarrow\mathbb R\) is a bounded function on \([a,b]\) such that \(f^2\) is Riemann integrable on \([a,b]\), then is \(f\) necessarily Riemann integrable on \([a,b]\)? Justify. [3]
  16. 6(c) Examine whether the function \(f:[0,1]\longrightarrow\mathbb R\) defined by \[ f(x)=\begin{cases}3n+2&\text{for }x=1/n\quad\text{(where }n=1,2,\ldots\text{)}\\0&\text{otherwise}\end{cases} \] is Riemann integrable on \([0,1]\). [3]
  17. 7(a) If \(f:[a,b]\longrightarrow\mathbb R\) be Riemann integrable function on \([a,b]\), then show that the function \(g:[a,b]\longrightarrow\mathbb R\) defined by \(g(x)=\int_a^x f(t)\,dt\) is continuous on \([a,b]\). [4]
  18. 7(b) State the Fundamental Theorem of Integral Calculus. Examine whether we can apply it to evaluate the integral \(\int_1^3 f\,dx\) of the function \(f:[1,3]\longrightarrow\mathbb R\) defined by \[ f(x)=\begin{cases}3&\text{for }1\le x<2\\5&\text{for }2\le x\le3.\end{cases} \] \hfill
  19. 8(a) What do you mean by \lq \(f\in\mathcal R(\alpha)\) on \([a,b]\)\rq{} for suitable functions \(f\) and \(\alpha\)? If \(\alpha:[a,b]\longrightarrow\mathbb R\) is continuous on \([a,b]\) and \(f:[a,b]\longrightarrow\mathbb R\) is monotone increasing on \([a,b]\), then show that \(\int_a^b\alpha\,df=\alpha(c)[f(b)-f(a)]\) for some \(c\in[a,b]\).
  20. 8(b) Examine whether \(x-[x]\in\mathcal R(\sin x)\) on \([0,\frac{\pi}{2}]\) and evaluate \(\int_0^{\pi/2}(x-[x])\,d(\sin x)\), if it exists. [4]
