GEC-4

Linear Programming Problem and Numerical Methods
B.Sc. Mathematics · Semester IV2023
  1. 1 Prove that the set of all feasible solutions of an LPP is a convex set. Sketch the domain in $\mathbb R^2$ where points satisfy the following set of constraints \[\begin{aligned}7x_1+5x_2&\le35,\\5x_1+7x_2&\le35,\\4x_1+3x_2&\ge12,\\3x_1+x_2&\ge3,\\x_1,x_2&\ge0.\end{aligned}\] Find the vertices of the feasible region, if exists. Then obtain the optimal solution to the problem graphically if the objective function is given by $Z=6x_1+4x_2$. [2+2+1+1]
  2. 2 Given the linear system of equations \[\begin{aligned}2x_1-x_2+2x_3&=10,\\x_1+4x_2&=18\end{aligned}\] with the non-negative restriction $x_1,x_2,x_3\ge0$. Verify whether $(2,4,5)$ is a solution to this system of equations. Is this a basic feasible solution? Find the basic feasible solution of the equation if not. [1+2+3]
  3. 3 Use the simplex method to solve the given LPP: \[\begin{aligned}\text{Maximize}\quad Z&=5x_1+8x_2\\\text{subject to}\quad 3x_1+2x_2&\ge3,\\x_1+4x_2&\ge4,\\x_1+x_2&\le5,\\x_1,x_2&\ge0.\end{aligned}\] Verify your result by solving this problem using a graphical method. [4+2]
  4. 4 Prove that dual of the dual is primal. Justify this statement for the following LPP \[\begin{aligned}\text{Maximize}\quad Z&=2x_1+3x_2+x_3\\\text{subject to}\quad x_1-5x_2+3x_3&=7,\\2x_1-5x_2&\le3,\\3x_2-x_3&\ge5,\\x_1,x_2&\ge0\end{aligned}\] and $x_3$ is unrestricted in sign.
  5. 5 State and prove the fundamental theorem of duality. Use duality to obtain an optimal solution, if any, to the LPP: \[\begin{aligned}\text{Minimize}\quad Z&=4x_1+3x_2+6x_3\\\text{subject to}\quad x_1+x_3&\ge2,\\x_2+x_3&\ge5,\\x_1,x_2,x_3&\ge0.\end{aligned}\]
  6. 6 For the following transportation problem obtain the different starting solutions by adopting \[\begin{array}{c|rrr|r} & D_1&D_2&D_3&a_i\\\hline O_1&5&1&8&12\\O_2&2&4&0&14\\O_3&3&6&7&4\\\hline b_j&9&10&11& \end{array}\] the North-West corner rule and Vogel's approximation method. Furthermore, find out which solution is better or more profitable.
  7. 7 Five operators $A,B,C,D,E$ have to be assigned to five machines $I,II,III,IV,V$. The assignment costs are given below: \[\begin{array}{c|rrrrr} & I&II&III&IV&V\\\hline A&5&5&-&2&6\\B&7&4&2&3&4\\C&9&3&5&-&3\\D&7&2&6&7&2\\E&6&5&7&9&1 \end{array}\] Operator A cannot operate Machine III, and Operator C cannot operate Machine IV. Find the optimal assignment schedule.
  8. 8 Write the conditions for getting an optimal solution for traveling salesman problems. Solve the following traveling salesman problem: \[\begin{array}{c|rrrrr} &1&2&3&4&5\\\hline 1&\infty&2&5&7&1\\2&6&\infty&3&8&2\\3&8&7&\infty&4&7\\4&12&4&6&\infty&5\\5&1&3&2&8&\infty \end{array}\] [2+4]
  9. 1(a) Write down the approximate representation of $\frac23$ correct up to four significant figures and then find : absolute, relative and percentage errors. [3]
  10. 1(b) Find the number of significant figures in $V_A$ with respect to $V_T$ where $V_A=0.05411$, $V_T=0.05418$. [2]
  11. 1(c) Find the polynomial $f(x)$ satisfying the following data and hence find the value of $f(2.5)$. \[\begin{array}{c|rrrrrr}x&1&2&3&4&5&6\\\hline f(x)&3&24&99&288&675&1368\end{array}\] [4+1]
  12. 2(a) Establish Newton's backward interpolation formula without error term. [5]
  13. 2(b) From the following values of $x$ and $f(x)$ \[\begin{array}{c|rrrrrr}x&0.20&0.22&0.24&0.26&0.28&0.30\\\hline f(x)&1.6596&1.6698&1.6804&1.6912&1.7024&1.7139\end{array}\] calculate the value of $f(0.23)$ by using Newton's forward interpolation formula. [5]
  14. 3(a) Derive composite Trapizoidal rule for the numerical integration. [5]
  15. 3(b) Evaluate $\int_0^1\sqrt{1-x^3}\,dx$ using Simpson's One-third rule, taking six equal intervals, correct up to two decimal places. [5]
  16. 4(a) Find one root of $e^x-3x=0$, by Method of Bisection, lying between 1 and 2, correct up to two decimal places. [3]
  17. 4(b) Explain graphically, the condition of convergence of the Fixed-Point Iteration method. [5]
  18. 4(c) From the equation $x^5-a=0$, deduce Newtonian iterative procedure \[x_{n+1}=\frac15\left(4x_n+\frac{a}{x_n^4}\right)\] for $\sqrt[5]a$. [2]
  19. 5(a) Using Gauss-Seidel Iteration Method, solve the following system \[\begin{aligned}5x_1+3x_2+x_3&=2,\\4x_1+10x_2+4x_3&=-4,\\2x_1+3x_2+8x_3&=20\end{aligned}\] correct upto 3-significant figures. [5]
  20. 5(b) Solve the system \[\begin{aligned}3x_1+x_2+x_3&=7,\\2x_1+x_2+5x_3&=13,\\x_1+4x_2+x_3&=9.4\end{aligned}\] using Gauss-Jacobi Iteration Method, correct up to 2-significant figures. [5]
