SEC-1

B.Sc. Mathematics · Semester III2018
  1. 1(a) Show that the set of positive divisors of 21 forms a Boolean Algebra with respect to the compositions defined by you. Is the result true for the set of positive divisors of 63? [2+1]
  2. 1(b) In a Boolean Algebra \(B\), prove that for \(a,b,c\in B\), \(a\ge b,\ a\ge c\Rightarrow a\ge b+c\). [1]
  3. 1(c) Show that in a Boolean Algebra \(B\), \(a+a=a\ \forall a\in B\). [1]
  4. 2(a) Define Boolean ring. Let \((R,+,\cdot)\) be a Boolean ring. If the binary operations \(\vee,\wedge\) and the unary operation \( {}'\) are defined by \(a\vee b=a+b+a\cdot b,\ a\wedge b=a\cdot b,\ a'=1+a,\) 1 being the unit element in \(R\), then show that \((R,\vee,\wedge,1)\) is a Boolean Algebra. [3]
  5. 2(b) Let \(e\) be an atom and \(e\le x_1+x_2,\ x_1,x_2\in B\). Then show that \(e\) is a subelement of at least one of \(x_1\) and \(x_2\). [2]
  6. 3(a) Show that in a Boolean Algebra \(B\), (i) \(1'=0\) \quad (ii) \(a''=a\ \forall a\in B\). [2]
  7. 3(b) In a Boolean Algebra \(B\), show that \(a+a\cdot b=a\ \forall G,b\in B\). [1]
  8. 3(c) Show that in a finite Boolean Algebra every nonzero element is the sum of all the atoms dominated by it. [2]
  9. 4(a) Deduce that in a Boolean Algebra \(B\), \(a+b=0\Rightarrow a=0\). [1]
  10. 4(b) In a Boolean Algebra \(B\), prove that \(\forall a,b,c\in B\), \begin{enumerate} \renewcommand{\labelenumi}{(\roman{enumi})} \item \(a+b=a+c,\ a'+b=a'+c\Rightarrow b=c\). \hfill \(1+1\) \item \(a+b=a+c,\ a\cdot b=a\cdot c\Rightarrow b=c\). \end{enumerate}
  11. 4(c) Define atom of a Boolean Algebra. If \(X=\{1,2,3\}\). Find the atoms in the Boolean Algebra \((P(x),\vee,\wedge,1)\). [1+1]
  12. 5(a) Let \(f\) be a function of three Boolean variables \(x,y,z\) defined by \(f(x,y,z)=xy+y'\). Express \(f(x,y,z)\) in disjunctive normal form. [2]
  13. 5(b) Let a Boolean function \(f\) be defined by \(f(x,y,z)=xy+yz+zx\). Find the conjunctive normal form of \(f(x,y,z)\). [2]
  14. 5(c) Draw the circuit which realises the Boolean expression \(xy+yz+zx\). [1]
  15. 6(a) Show that NAND gate is universal gate. [2]
  16. 6(b) Draw the following in symbolic diagram \(F=A\overline B+AB+BC\). [2]
  17. 6(c) Find \((111)_2+(111)_2+(111)_2\), where \((111)_2\) is a binary number. [1]
