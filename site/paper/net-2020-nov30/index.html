  1. 21 Suppose that $A, B$ are two non-empty subsets of $\mathbb{R}$ and $C=A \cap B$. Which of the following conditions imply that $C$ is empty? \begin{enumerate}[label=(\alph*)] \item $A$ and $B$ are open and $C$ is compact \item $A$ and $B$ are open and $C$ is closed \item $A$ and $B$ are both dense in $\mathbb{R}$ \item $A$ is open and $B$ is compact \end{enumerate}
  2. 22 $\lim_{x \to \infty} \frac{(n+1)(n+2) \ldots (n+n))^{1 / n}}{n}$ \begin{enumerate}[label=(\alph*)] \item Is equal to $\frac{e}{4}$ \item Is equal to $\frac{4}{e}$ \item Is equal to $e$ \item Does not exist \end{enumerate}
  3. 23 Let $Y=\{1,2,3, \ldots, 100\}$ and let $h: Y \to Y$ be a strictly increasing function. The total number of functions $g: Y \to Y$ satisfying $g(h(j))=h(g(j)), \forall j \in Y$ is \begin{enumerate}[label=(\alph*)] \item 0 \item $100!$ \item $100^{100}$ \item $100^{108}$ \end{enumerate}
  4. 24 An infinite binary word $a$ is a string $\left(a_1 a_2 a_3 \ldots\right)$ where each $a_n \in \{0,1\}$. Fix a word $s=\left(s_1 s_2 s_3 \ldots\right)$, where $s_n=1$ if and only if $n$ is prime. Let $S=\left\{a=\left(a_1 a_2 s_3 \ldots\right) \mid \exists m \in \mathbb{N}\right.$ such that $a_n=s_n, \forall n \geq m \}$. What is the cardinality of $S$ ? \begin{enumerate}[label=(\alph*)] \item 1 \item Finite but more than 1 \item Countably infinite \item Uncountable \end{enumerate}
  5. 25 Let $f$ be a non-constant polynomial of degree $k$ and let $g: \mathbb{R} \to \mathbb{R}$ be a bounded continuous function. Which of the following statements is necessarily true? \begin{enumerate}[label=(\alph*)] \item There always exists $x_0 \in \mathbb{R}$ such that $f(x_0)=g(x_0)$ \item There is no $x_0 \in \mathbb{R}$ such that $f(x_0)=g(x_0)$ \item There is $x_0 \in \mathbb{R}$ such that $f(x_0)=g(x_0)$ if $k$ is even \item There is $x_0 \in \mathbb{R}$ such that $f(x_0)=g(x_0)$ if $k$ is odd \end{enumerate}
  6. 26 The sum of the finite series \[ S=\frac{1}{2}-\frac{1}{3 \times 1!} + \frac{1}{4 \times 2!} - \frac{1}{5 \times 3!} + \ldots \] is equal to \begin{enumerate}[label=(\alph*)] \item $2-\frac{1}{e}$ \item $1-\frac{2}{e}$ \item $\frac{2}{e}-1$ \item $\frac{1}{e}-2$ \end{enumerate}
  7. 27 Let $S=\{u_1, \ldots, u_k\}$ be a subset of non-zero vectors from $\mathbb{R}^n$. Now, consider the two statements given below: \begin{enumerate}[label=\Roman*.] \item If $S$ is linearly dependent in $\mathbb{R}^n$ then $u_k$ is a linear combination of $u_1, \ldots, u_{k-1}$. \item If $S$ is linearly independent set in $\mathbb{R}^n$ then $k<n$. \end{enumerate} Which of the following statements is true? \begin{enumerate}[label=(\alph*)] \item Statement I is FALSE and Statement II is TRUE \item Statement I is TRUE and Statement II is FALSE \item Both Statement I and Statement II are FALSE \item Both Statement I and Statement II are TRUE \end{enumerate}
  8. 28 Let $M$ be a $5 \times 5$ matrix with real entries such that $\operatorname{Rank}(M)=3$. Consider the linear system $M x=b$. Let the row-reduced echelon form of the augmented matrix $[M \, b]$ be $R$ and let $R[i, :]$ denote the $i^{\text{th}}$ row of $R$. Suppose that the linear system admits a solution. Which of the following statements is necessarily true? \begin{enumerate}[label=(\alph*)] \item $R[3, :] = [0 \, 1 \, 0 \, * \, * \, *]$ \item $R[5, :] = [0 \, 0 \, 1 \, 0 \, * \, *]$ \item $R[4, :] = [0 \, 0 \, 0 \, 0 \, 0 \, 0]$ \end{enumerate}
  9. 29 Let $A$ be an $n \times n$ matrix of rank 1. Let $\alpha=\operatorname{det}(I+A)$, where $I$ is the identity matrix and let $\beta=\operatorname{trace} A$. Which of the following is true? \begin{enumerate}[label=(\alph*)] \item $\beta-\alpha=1$ \item $\alpha-\beta=1$ \item $\alpha<\beta+1$ \item $\alpha>\beta+1$ \end{enumerate}
  10. 30 Let $a, b$ and $c$ be distinct integers. Let $A$ be the matrix $A=\begin{pmatrix} a^2 & b^2 & c^2 \\ a^5 & b^5 & c^5 \\ a^{11} & b^{11} & c^{11} \end{pmatrix}$. Which among the following is the set of all possible ranks of $A$ ? \begin{enumerate}[label=(\alph*)] \item $\{3\}$ \item $\{2,3\}$ \item $\{1,2,3\}$ \item $\{0,1,2,3\}$ \end{enumerate}
  11. 31 Which of the following is an inner product on the vector space of all real valued continuous functions on $[0,1]$ ? \begin{enumerate}[label=(\alph*)] \item $\langle f, g \rangle = \left| \int_0^1 f(t) g(t) \, dt \right|$ \item $\langle f, g \rangle = \int_0^1 |f(t) g(t)| \, dt$ \item $\langle f, g \rangle = f(0) g(0) + f(1) g(1)$ \item $\langle f, g \rangle = \int_0^1 f(t) g(t) \, dt$ \end{enumerate}
  12. 32 Let us define a matrix $A \in M_n(\mathbb{R})$ to be positive if for every column vector $v \in \mathbb{R}^n$ we have $\langle A v, v \rangle \geq 0$, where $\langle \cdot, \cdot \rangle$ is the standard inner product on $\mathbb{R}^n$. Let $A_{\alpha, \beta}=\begin{pmatrix} \alpha & 1 & 1 \\ 1 & 0 & 0 \\ 1 & 0 & \beta \end{pmatrix}$. Let $S=\{(\alpha, \beta) \in \mathbb{R}^2 : A_{\alpha, \beta} \text{ is positive}\}$. Which of the following statements is true? \begin{enumerate}[label=(\alph*)] \item $S$ is empty \item $(\alpha, \beta) \in S$ if and only if $\alpha \beta > 0$ \item $(\alpha, \beta) \in S$ if and only if $\alpha + \beta + 4 > 0$ \item $S = \mathbb{R}^2$ \end{enumerate}
  13. 33 A function $f: \mathbb{C} \to \mathbb{C}$ is said to be analytic at $\infty$, if the function $g$ defined by $g(w)=f\left(\frac{1}{w}\right)$ is analytic at 0 with an appropriate value given for $g(0)$. Which of the following statements is true? \begin{enumerate}[label=(\alph*)] \item Any non-constant polynomial is analytic at $\infty$ \item If $f$ is analytic at $\infty$ then $f$ is bounded \item For any $z_0$ in $\mathbb{C}$, the function $f(z)=e^{1 / (z - z_0)}$ is analytic at $\infty$ \item Any entire function can be extended to an analytic function at $\infty$ \end{enumerate}
  14. 34 Define $f: \mathbb{C} \to \mathbb{C}$ by $f(z)=|z|^2 - 1$. Which of the following statements is true? \begin{enumerate}[label=(\alph*)] \item $f$ is complex differentiable at all complex numbers except for $z \in \{0,1\}$ \item $f$ is complex differentiable only at $z=0$ \item $f$ is complex differentiable only at $z=1$ \item $f$ is complex differentiable only for $z \in \{0,1\}$ \end{enumerate}
  15. 35 Let $f, g$ be entire functions such that $\lim_{z \to \infty} \frac{f(z)}{z^2}=\lim_{z \to \infty} \frac{g(z)}{z^n}=1$ for some fixed positive integer $n$. Which of the following statements is true? \begin{enumerate}[label=(\alph*)] \item $f=g$ \item $f-g$ is necessarily a polynomial of degree at most $n-1$ \item There exist $f, g$ with these properties such that $f-g$ is a polynomial of degree $n$ \item There exist $f, g$ with these properties such that $f-g$ is not a polynomial \end{enumerate}
  16. 36 Let $f$ be a holomorphic function on the disc $\{z \in \mathbb{C} : |z|<2\}$. Assume that the only zero of $f$ in the closed unit disc $\{z \in \mathbb{C} : |z| \leq 1\}$ is a simple zero at the origin. Let $\gamma$ be the positively oriented circle $\{z \in \mathbb{C} : |z|=1\}$. The integral $\int_\gamma \frac{dz}{f(z)}$ equals \begin{enumerate}[label=(\alph*)] \item $2 \pi i f'(0)$ \item $2 \pi i f''(0)$ \item $2 \pi i / f'(0)$ \item $2 \pi i / f''(0)$ \end{enumerate}
  17. 37 The last two digits of $3^{2019}$ are \begin{enumerate}[label=(\alph*)] \item 27 \item 37 \item 57 \item 67 \end{enumerate}
  18. 38 Let $G$ be a group of order 2020. Which of the following statements is necessarily true? \begin{enumerate}[label=(\alph*)] \item $G$ is not a simple group \item $G$ has exactly four proper subgroups \item $G$ is a cyclic group \item $G$ is abelian \end{enumerate}
  19. 39 Which of the following statements is NOT true? \begin{enumerate}[label=(\alph*)] \item The polynomial ring $\mathbb{Z}[x]$ is a Principal Ideal Domain (PID) \item The polynomial ring $\mathbb{Z}[x]$ is a Principal Ideal Domain (PID) \item The polynomial ring $\mathbb{Z}[x]$ is a Unique Factorization Domain (UFD) \item The polynomial ring $\mathbb{Z}[x]$ is a Unique Factorization Domain (UFD) \end{enumerate}
  20. 40 Suppose $f: [0,1] \times [0,1] \to (0,1) \times (0,1)$ is a continuous non-constant function.   21. 41 Consider the ODE $t y' - 3 y = t^2 y^{1/2}$, $y(1)=1$. Find the value of $y(2)$ \begin{enumerate}[label=(\alph*)] \item 14 \item 16 \item 0 \item 8 \end{enumerate}
  22. 42 For $\lambda \in \mathbb{R}$, consider the system of differential equations \[ \begin{aligned} x_1' &= x_1 + 2 x_2 + 2 x_3, \\ x_2' &= 2 x_1 + x_3, \\ x_3' &= -x_3 + 2 x_2 + \lambda x_3. \end{aligned} \] If $\ddot{x}(t)=\ddot{a} t e^{\lambda t}$ (for some $\ddot{a}$) is a solution of the system then the value of $\lambda$ is equal to \begin{enumerate}[label=(\alph*)] \item 2 \item 4 \item 6 \item 1 \end{enumerate}
  23. 43 Which of the following is a solution to $u_x + x^2 u_y = 0$ with $u(x, 0)=e^x$ ? \begin{enumerate}[label=(\alph*)] \item $e^x$ \item $e^{\left(x^2 - y\right)^{1/3}}$ \item $e^{\left(x^2 - 3 y\right)^{1/3}}$ \item $\left(x^2 y + 1\right) e^x$ \end{enumerate}
  24. 44 Consider the differential equation \[ x^2 y'' - 2 x (x+1) y' + 2 (x+1) y = 0. \] If a polynomial is a solution then the degree of the polynomial is equal to \begin{enumerate}[label=(\alph*)] \item 1 \item 2 \item 3 \item 4 \end{enumerate}
  25. 45 Consider the Newton-Raphson method applied to approximate the square root of a positive number $\alpha$. A recursion relation for the error $e_n = x_n - \sqrt{\alpha}$ is given by \begin{enumerate}[label=(\alph*)] \item $e_{n+1} = \frac{1}{2} \left( e_n + \frac{\alpha}{e_n} \right)$ \item $e_{n+1} = \frac{1}{2} \left( e_n - \frac{\alpha}{e_n} \right)$ \item $e_{n+1} = \frac{1}{2} \frac{e_n^2}{e_n + \sqrt{\alpha}}$ \item $e_{n+1} = \frac{e_n^2}{e_n + 2 \sqrt{\alpha}}$ \end{enumerate}
  26. 46 The Euler equations satisfied by the extremals of the functional $J(y) = \int_0^5 \left[ y^2 + x^2 y' \right] \, dx$ define a solution curve in the $(x, y)$-plane which is \begin{enumerate}[label=(\alph*)] \item Linear \item Quadratic \item Cubic \item Trigonometric \end{enumerate}
  27. 47 Consider continuous solutions $f$ of the following integral equation in $[0,1]$. \[ f^2(t) = 1 + 2 \int_0^t f(s) \, ds, \quad \forall t \in [0,1]. \] Which of the following statements is true? \begin{enumerate}[label=(\alph*)] \item There is no solution \item There is exactly one solution \item There are exactly two solutions \item There are more than two solutions \end{enumerate}
  28. 48 A body moves freely in a uniform gravitational field.   29. 49 Let $X$ be a uniform $(0,1)$ random variable. Suppose that given $X$, the random variable $Y$ is uniform on $(0, X)$. Given $X$ and $Y$, the random variable $Z$ is uniform on $(Y, 1)$.   30. 50 Let $X_0=0$ and for $k \geq 1$ let $X_k$ be a random variable with Binomial $\left(k, \frac{1}{2}\right)$ distribution. Let $N$ be a Poisson random variable with mean 1.   31. 51 Let $\left(N_t^1\right)$ and $\left(N_t^2\right)$ be two independent Poisson processes with intensities $a, b$ respectively, with $a>b$. Then which of the following is true? \begin{enumerate}[label=(\alph*)] \item $X$ is a Poisson process with intensity $a-b$ \item $X$ is a birth-and-death process with birth-rate $a$ and death-rate $b$ \item $M$ is a Poisson process with intensity $\max(a, b)$ \item $M$ is a pure birth process with birth rate $a+b$ \end{enumerate}
  32. 52 Let $X_1, X_2, \ldots$ be i.i.d. Normal random variables with mean 2 and variance 3.   33. 53 Let $X_1, X_2, \ldots, X_n$ be i.i.d. $N(\theta, \sigma^2)$ random variables where $\sigma^2$ is known. Let $\bar{X}=\frac{\sum_{i=1}^n X_i}{n}$. The Minimum Variance Unbiased Estimator of $e^{2 \theta}$ is given by \begin{enumerate}[label=(\alph*)] \item $\exp \left( 2 \bar{X} - \frac{\sigma^2}{n} \right)$ \item $\exp \left( 2 \bar{X} - \frac{4 \sigma^2}{n} \right)$ \item $\exp \left( 2 \bar{X} - \frac{2 \sigma^2}{n} \right)$ \item $\exp \left( 2 n \bar{X} - \frac{2 \sigma^2}{n} \right)$ \end{enumerate}
  34. 54 Suppose that $X$ follows a distribution with probability density function $f_\theta(x) \propto x^{\theta-1} (1-x)^{\theta-1}$, $0<x<1$, $\theta>0$. The uniformly most powerful critical region for testing $H_0: \theta=1$ against $H_1: \theta>1$ based on a single observation is of the form \begin{enumerate}[label=(\alph*)] \item $(1-\alpha, 1]$ \item $[0, \alpha)$ \item $\left( \frac{1-\alpha}{2}, \frac{1+\alpha}{2} \right)$ \item $\left[ 0, \frac{\alpha}{2} \right) \cup \left( 1-\frac{\alpha}{2}, 1 \right]$ \end{enumerate}
  35. 55 Let $X_1, X_2, \ldots, X_n$ be i.i.d $N(\theta, 1)$ random variables. Suppose the prior distribution of $\theta$ is $N(0, \sigma^2)$. Suppose we have squared error loss function. Then, the Bayes estimator of $\theta$ is \begin{enumerate}[label=(\alph*)] \item $\frac{\bar{X}}{1+\sigma^2}$ \item $\bar{X}$ \item $\frac{n \bar{X} \sigma^2}{1+n \sigma^2}$ \item $\frac{n (\bar{X} + \sigma^2)}{1+n \sigma^2}$ \end{enumerate}
  36. 56 Let $X$ be a $p \times p$ matrix valued random variable having the Wishart distribution with parameters $\Sigma$ (variance matrix) and $m$ (degrees of freedom). Also, let $S_{xx} = \sum_{i=1}^n (X_i - \bar{X})^2$, $S_{yy} = \sum_{i=1}^n (Y_i - \bar{Y})^2$, $S_{xy} = \sum_{i=1}^n (X_i - \bar{X})(Y_i - \bar{Y})$. Which of the following are maximum likelihood estimators of $\rho$ ? \begin{enumerate}[label=(\alph*)] \item $\frac{S_{xy}}{\sqrt{S_{xx} S_{yy}}}$ \item $\frac{\sum_{i=1}^n X_i Y_i}{\sqrt{\left( \sum_{i=1}^n X_i^2 \right) \left( \sum_{i=1}^n Y_i^2 \right)}}$ \item $\frac{2 S_{xy}}{S_{xx} + S_{yy}}$ \item $\frac{2 S_{xy}}{S_{xx} + S_{yy} - 2 S_{xy}}$ \end{enumerate}
  96. 116 Let $X_1, X_2, \ldots, X_n$ be a random sample from normal distribution with unknown mean $\mu$ and variance 1. Let $\bar{X}$ be the sample mean and $X_{[1]}=\min \{X_1, X_2, \ldots, X_n\}$. Which of the following are true? \begin{enumerate}[label=(\alph*)] \item $\bar{X}$ is complete sufficient for $\mu$ \item $\bar{X}$ is minimal sufficient for $\mu$ \item $\bar{X} - X_{[1]}$ is an ancillary statistic \item $\operatorname{Cov}(\bar{X}, \bar{X} - X_{[1]})=0$ \end{enumerate}
  97. 117 In a BIBD (Balanced Incomplete Block Design) with $v$ treatments, $b$ blocks, let $t_j$ denote the effect of $j^{\text{th}}$ treatment, $b_t$ denote the effect of $t^{\text{th}}$ block $1 \leq j \leq v, 1 \leq t \leq b$. Which of the following statements are necessarily true? \begin{enumerate}[label=(\alph*)] \item[(a)] $t_j$ is estimable for all $1 \leq j \leq v$ \item[(b)] $t_j - b_t$ is estimable for all $1 \leq j \leq v$, $1 \leq t \leq b$ \item[(c)] $t_j - t_i$ is estimable for all $1 \leq i < j \leq v$ \item[(d)] $t_j + t_i$ is estimable for all $1 \leq i < j \leq v$ \end{enumerate}
  98. 118 Suppose $X$ denotes the lifetime of a system and follows the distribution with cumulative distribution function \[ F(t) = 1 - e^{-rt}, \quad t > 0, \quad r > 0. \] Let $r(t)$ be the hazard (failure) rate of $X$. Which of the following are true? \begin{enumerate}[label=(\alph*)] \item[(a)] $r(t)$ is increasing in $t$ if $r > 1$ \item[(b)] $r(t)$ is decreasing in $t$ if $r > 1$ \item[(c)] $r(t)$ is constant in $t$ if $r = 1$ \item[(d)] $r(t)$ is decreasing in $t$ if $0 < r < 1$ \end{enumerate} \bigskip
  99. 119 Let $(X_n, n \geq 1)$ be i.i.d. random variables with mean zero and variance one. Which of the following are true as $n \to \infty$? \begin{enumerate}[label=(\alph*)] \item[(a)] $\dfrac{X_1 + X_2 + \ldots + X_n}{\sqrt{n + 1}}$ converges in distribution to standard normal \item[(b)] $\dfrac{X_1 - X_2 + \ldots + (-1)^{n+1}X_n}{\sqrt{n}}$ converges in distribution to standard normal \item[(c)] $\dfrac{X_1 + X_2 + \ldots + X_n}{n + 1}$ converges to zero in probability \item[(d)] $\dfrac{X_1 + X_2 + \ldots + X_n}{\sqrt{n}}$ converges to zero in probability \end{enumerate}
  100. 120 Consider a M/M/1 queue at the steady state with traffic intensity $\rho \in (0,1)$. Let $f(\rho)$ be the expected waiting time of a customer in the queue. Then \begin{enumerate}[label=(\alph*)] \item[(a)] $f$ is increasing in $\rho$ \item[(b)] $f$ is decreasing in $\rho$ \item[(c)] $f$ attains its maximum at $\rho = \dfrac{1}{2}$ \item[(d)] $f$ is a smooth function in $(0,1)$ \end{enumerate}
