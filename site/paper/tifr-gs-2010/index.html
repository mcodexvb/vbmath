TIFR Graduate School · GS 2010 · Mathematics

  1. 1 A cyclic group of order $60$ has \begin{enumerate}[label=(\alph*)] \item $12$ generators. \item $15$ generators. \item $16$ generators. \item $20$ generators. \end{enumerate}
  2. 2 Which of the following is false? \begin{enumerate}[label=(\alph*)] \item Any abelian group of order $27$ is cyclic. \item Any abelian group of order $14$ is cyclic. \item Any abelian group of order $21$ is cyclic. \item Any abelian group of order $30$ is cyclic. \end{enumerate}
  3. 3 The last digit of $2^{80}$ is \begin{enumerate}[label=(\alph*)] \item $2$ \item $4$ \item $6$ \item $8$ \end{enumerate}
  4. 4 The sum of the series $\displaystyle \frac{1}{1 \cdot 2} + \frac{1}{2 \cdot 3} + \frac{1}{3 \cdot 4} + \dots + \frac{1}{100 \cdot 101}$ is \begin{enumerate}[label=(\alph*)] \item $\frac{99}{101}$ \item $\frac{98}{101}$ \item $\frac{99}{100}$ \item None of the above. \end{enumerate}
  5. 5 Let $f$ be a one to one function from the closed interval $[0, 1]$ to the set of real numbers $\mathbb{R}$, then \begin{enumerate}[label=(\alph*)] \item $f$ must be onto. \item range of $f$ must contain a rational number. \item range of $f$ must contain an irrational number. \item range of $f$ must contain both rational and irrational numbers. \end{enumerate}
  6. 6 The maximum value of $f(x) = x^n(1 - x)^n$ for a natural number $n \ge 1$ and $0 \le x \le 1$ is \begin{enumerate}[label=(\alph*)] \item $\frac{1}{2^n}$ \item $\frac{1}{3^n}$ \item $\frac{1}{5^n}$ \item $\frac{1}{4^n}$ \end{enumerate}
  7. 7 The sequence $\sqrt{7}, \sqrt{7 + \sqrt{7}}, \sqrt{7 + \sqrt{7 + \sqrt{7}}}, \dots$ converges to \begin{enumerate}[label=(\alph*)] \item $\frac{1 + \sqrt{33}}{2}$ \item $\frac{1 + \sqrt{32}}{2}$ \item $\frac{1 + \sqrt{30}}{2}$ \item $\frac{1 + \sqrt{29}}{2}$ \end{enumerate}
  8. 8 Let $f(x) = |x|^{3/2}$, $x \in \mathbb{R}$. Then \begin{enumerate}[label=(\alph*)] \item $f$ is uniformly continuous. \item $f$ is continuous, but not differentiable at $x = 0$. \item $f$ is differentiable and $f'$ is continuous. \item $f$ is differentiable, but $f'$ is discontinuous at $x = 0$. \end{enumerate}
  9. 9 The total number of subsets of a set of $6$ elements is \begin{enumerate}[label=(\alph*)] \item $720$ \item $6^6$ \item $21$ \item None of the above. \end{enumerate}
  10. 10 Let $M_n(\mathbb{R})$ be the set of $n \times n$-matrices with real entries. Which of the following statements is true? \begin{enumerate}[label=(\alph*)] \item Any matrix $A \in M_4(\mathbb{R})$ has a real eigenvalue. \item Any matrix $A \in M_5(\mathbb{R})$ has a real eigenvalue. \item Any matrix $A \in M_2(\mathbb{R})$ has a real eigenvalue. \item None of the above. \end{enumerate}
  11. 11 The series $\displaystyle \sum_{n=1}^\infty \frac{(-1)^{n+1}}{\sqrt{n}}$ \begin{enumerate}[label=(\alph*)] \item converges but not absolutely. \item converges absolutely. \item diverges. \item none of the above. \end{enumerate}
  12. 12 The sum of the roots of the equation $x^5 + 3x^2 + 7 = 0$ is \begin{enumerate}[label=(\alph*)] \item $-3$ \item $\frac{3}{7}$ \item $\frac{-1}{7}$ \item $0$ \end{enumerate}
  13. 13 $\displaystyle \lim_{x \to 0} x \sin\left(\frac{1}{x}\right)$ is \begin{enumerate}[label=(\alph*)] \item $1$ \item $0$ \item $\frac{1}{2}$ \item does not exist. \end{enumerate}
  14. 14 The solution of the ordinary differential equation $\displaystyle \frac{dy}{dx} = y$, $y(0) = 0$ \begin{enumerate}[label=(\alph*)] \item {[obscured in source]} \item {[obscured in source]} \item {[obscured in source]} \item is zero. \end{enumerate}
  15. 15 Let $G$ be the set of all $2 \times 2$ symmetric, invertible matrices with real entries. Then with matrix multiplication, $G$ is \begin{enumerate}[label=(\alph*)] \item an infinite group. \item a finite group. \item not a group. \item an abelian group. \end{enumerate}
  16. 16 Let $u_n = \sin\left(\frac{\pi}{n}\right)$ and consider the series $\sum u_n$. Which of the following statements is false? \begin{enumerate}[label=(\alph*)] \item $\sum u_n$ is convergent. \item $u_n \to 0$ as $n \to \infty$. \item $\sum u_n$ is divergent. \item $\sum u_n$ is absolutely convergent. \end{enumerate}
  17. 17 If $V$ is a vector space over the field $\mathbb{Z}/5\mathbb{Z}$ and $\dim_{\mathbb{Z}/5\mathbb{Z}}(V) = 3$, then $V$ has \begin{enumerate}[label=(\alph*)] \item $125$ elements. \item $15$ elements. \item $243$ elements. \item None of the above. \end{enumerate}
  18. 18 If $f, g: \mathbb{R} \to \mathbb{R}$ are uniformly continuous functions, then their composition $g \circ f$ is \begin{enumerate}[label=(\alph*)] \item uniformly continuous. \item continuous but not uniformly continuous. \item continuous and bounded. \item None of the above. \end{enumerate}
  19. 19 Which of the following statements is false? \begin{enumerate}[label=(\alph*)] \item There exists a natural number which when divided by $3$ leaves remainder $1$ and which when divided by $4$ leaves remainder $0$. \item There exists a natural number which when divided by $6$ leaves remainder $2$ and when divided by $9$ leaves remainder $1$. \item There exists a natural number which when divided by $7$ leaves remainder $1$ and when divided by $11$ leaves remainder $3$. \item There exists a natural number which when divided by $12$ leaves remainder $7$ and when divided by $8$ leaves remainder $3$. \end{enumerate}
  20. 20 If $f_n(x)$ are continuous functions from $[0, 1]$ to $[0, 1]$, and $f_n(x) \to f(x)$ as $n \to \infty$, then which of the following statements is true? \begin{enumerate}[label=(\alph*)] \item $f_n(x)$ converges to $f(x)$ uniformly on $[0, 1]$. \item $f_n(x)$ converges to $f(x)$ uniformly on $(0, 1)$. \item $f(x)$ is continuous on $[0, 1]$. \item None of the above. \end{enumerate}
  21. 21 Let $A, B$ be subsets of $\mathbb{R}$. Define $A + B$ to be the set of all sums $x + y$ with $x \in A$ and $y \in B$. Which of the following statements is false? \begin{enumerate}[label=(\alph*)] \item If $A$ and $B$ are bounded, then $A + B$ is bounded. \item If $A$ and $B$ are open, then $A + B$ is open. \item If $A$ and $B$ are closed, then $A + B$ is closed. \item If $A$ and $B$ are connected, then $A + B$ is connected. \end{enumerate}
  22. 22 Number of solutions of the ordinary differential equation $\displaystyle \frac{d^2 y}{dx^2} - y = 0$; $y(0) = 0$, $y(\pi) = 1$ \begin{enumerate}[label=(\alph*)] \item is $0$. \item is $1$. \item is $2$. \item None of the above. \end{enumerate}
  23. 23 The function $f(x)$ defined by \[ f(x) = \begin{cases} 0 & \text{if } x \text{ is rational,} \\ x & \text{if } x \text{ is irrational} \end{cases} \] \begin{enumerate}[label=(\alph*)] \item is not continuous at any point. \item is continuous at every point. \item is continuous at every rational number. \item is continuous at $x = 0$. \end{enumerate}
  24. 24 Let $G = \{z \in \mathbb{C} \mid z^n = 1 \text{ for some positive integer } n\}$. Then under multiplication of complex numbers, \begin{enumerate}[label=(\alph*)] \item $G$ is a group of finite order. \item $G$ is a group of infinite order, but every element of $G$ has finite order. \item $G$ is a cyclic group. \item None of the above. \end{enumerate}
  25. 25 Let $x$ and $y$ in $\mathbb{R}^n$ be non-zero column vectors. Form the matrix $A = x y^t$ where $y^t$ is the transpose of $y$. Then the rank of $A$ is \begin{enumerate}[label=(\alph*)] \item $2$ \item $0$ \item at least $n/2$. \item None of the above. \end{enumerate}
  26. 26 Which of the following is true? \begin{enumerate}[label=(\alph*)] \item The matrix $\begin{pmatrix} 1 & 0 \\ 1 & 2 \end{pmatrix}$ is not diagonalisable. \item The matrix $\begin{pmatrix} 1 & 5 \\ 0 & 2 \end{pmatrix}$ is diagonalisable. \item The matrix $\begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$ is diagonalisable. \item None of the above. \end{enumerate}
  27. 27 If $n$ and $m$ are positive integers and $n^9 = 19m + r$, then the possible values for $r$ modulo $19$ are \begin{enumerate}[label=(\alph*)] \item only $0$. \item only $0, \pm 1$. \item only $\pm 1$. \item None of the above. \end{enumerate}
  28. 28 Define $\{x_n\}$ as $x_1 = 0.1$, $x_2 = 0.101$, $x_3 = 0.101001, \dots$. Then the sequence $\{x_n\}$ \begin{enumerate}[label=(\alph*)] \item converges to a rational number. \item converges to an irrational number. \item does not converge. \item oscillates. \end{enumerate}
  29. 29 The equations \begin{align*} x_1 + 2x_2 + 3x_3 &= 1 \\ x_1 + 4x_2 + 9x_3 &= 1 \\ x_1 + 8x_2 + 27x_3 &= 1 \end{align*} have \begin{enumerate}[label=(\alph*)] \item only one solution. \item two solutions. \item infinitely many solutions. \item no solution. \end{enumerate}
  30. 30 Which of the following statements is false? \begin{enumerate}[label=(\alph*)] \item The polynomial $x^2 + x + 1$ is irreducible in $\mathbb{Z}/2\mathbb{Z}[x]$. \item The polynomial $x^2 - 2$ is irreducible in $\mathbb{Q}[x]$. \item The polynomial $x^2 + 1$ is reducible in $\mathbb{Z}/5\mathbb{Z}[x]$. \item The polynomial $x^2 + 1$ is reducible in $\mathbb{Z}/7\mathbb{Z}[x]$. \end{enumerate}
