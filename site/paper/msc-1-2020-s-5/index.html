MMC-15

Partial Differential Equations
M.Sc. Mathematics · Semester I2020
  1. 1(a) Show that the Cauchy problem $yu_x-xu_y=0$, $u=f$ on $\Gamma$ has a unique solution in a neighbourhood of $\Gamma$ for every differentiable function $f:\Gamma\to\mathbb R$, where $\Gamma=\{(x,y):x+y=1,x>1\}$.
  2. 1(b) In what region is the following PDE parabolic, elliptic or hyperbolic? \[ \begin{aligned} \frac{(x-y)^2}{4}u_{xx}+(x-y)\cos(x^2+y^2)u_{xy}+\sin^2(x^2+y^2)u_{yy} \\{}+(x-y)u_x+\cos^2(x^2+y^2)u_y+u=0 \end{aligned} \]
  3. 1(c) Find, by the method of characteristics, the integral surface of the following PDE: \[ \frac{\partial u}{\partial y}+\left(\frac{\partial u}{\partial x}\right)^2=1,\quad x\in\mathbb R,\ y>0,\ u(x,0)=-x^2. \] [2+3+5]
  4. 2(a) Find the complete integral of the PDE \[ u_{xx}-u_{xy}-2u_{yy}+2u_x+2u_y=xy+\sin(x+2y). \]
  5. 2(b) Solve the following PDE by Monge's method: \[ y^2\frac{\partial^2u}{\partial x^2}-2y\frac{\partial^2u}{\partial x\partial y} +\frac{\partial^2u}{\partial y^2}=u_x+6y. \] [4+6]
  6. 3(a) Find the expression of the Monge cone of the PDE $u_x^2+u_y^2=2021$ at $(1,1,1)$.
  7. 3(b) Find the number of real characteristic curves of the PDE \[ \left[a(x,y)\frac{\partial}{\partial x}+b(x,y)\frac{\partial}{\partial y}\right] \left[c(x,y)\frac{\partial}{\partial x}+d(x,y)\frac{\partial}{\partial y}\right]u=0,\quad ad-bc=0, \] where $a,b,c,d$ be four differentiable functions defined on $\mathbb R^2$.
  8. 3(c) Find the two families of characteristics of \[ 2x^2u_{xx}-5xyu_{xy}+2y^2u_{yy}+2xu_x+2yu_y=0. \] Convert the equation to canonical form and hence find $u(x,y)$, given that $u=2x^2-6$ and $u_y=3-x^2$ on $y=1$. [2+2+6]
  9. 4(a) Using appropriate integral transform method, solve the initial boundary value problem (IBVP) described as \[ \frac{\partial^2u}{\partial x^2}=\frac1{c^2}\frac{\partial^2u}{\partial t^2}-\cos(2t), \quad 0\leq x<\infty,\ 0\leq t<\infty, \] BC's: $u(0,t)=0$, $u(x,t)$ is bounded as $x\to\infty$, IC's: $u(x,0)=0,\ u_t(x,0)=0$.
  10. 4(b) Using appropriate integral transform method, find the temperature $u(x,t)$ in a semi-infinite rod $0\leq x<\infty$, determined by the PDE \[ \frac{\partial u}{\partial t}=k\frac{\partial^2u}{\partial x^2},\quad x\in(0,\infty),\ t>0, \] subject to IC: $u(x,0)=0,\ 0\leq x<\infty$, BC's: $u_x(0,t)=-u_0$ (a constant) when $x=0$ and $t>0$; $u,\ \dfrac{\partial u}{\partial x}$ both tend to zero as $x\to\infty$. [5+5]
  11. 5(a) State maximum-minimum principle for a function $u(x,y)$ which is continuous in a closed region $\overline{\mathbb R}$ and satisfies the Laplace equation $\nabla^2u=0$ in the interior of $\mathbb R$.
  12. 5(b) Let $u(x,t)$ satisfies the initial boundary value problem (IBVP) \[ \frac{\partial u}{\partial t}=9\frac{\partial^2u}{\partial x^2},\quad x\in(0,1),\ t>0, \] BC's: $u(0,t)=u(1,t)=0$, IC: $u(x,0)=\sin^2(\pi x),\ x\in[0,1]$. Then, for $x\in(0,1)$ find the value of $u(x,\frac1{2\pi^2})$.
  13. 5(c) With the help of separation of variables method, obtain the solution of the following initial boundary value problem (IBVP) for the wave equation: \[ \frac{\partial^2u}{\partial t^2}=\frac{\partial^2u}{\partial x^2},\quad x\in(0,\pi),\ t>0, \] BC's: $u(0,t)=u(\pi,t)=0$, IC's: $u(x,0)=0,\ u_t(x,0)=2\cos(x)-3\cos(2x)$. [2+3+5]
  14. 6(a) State Cauchy-Kowalevski theorem for a second order linear PDE.
  15. 6(b) Solve the following interior Dirichlet problem for a circle: PDE: $\nabla^2u=0,\ 0\leq r<a,\ 0\leq\theta<2\pi$ BC: $u(a,\theta)=f(\theta),\ 0\leq\theta<2\pi$ where $f(\theta)$ is a continuous function on $\partial\mathbb R$. Hence deduce Poisson's integral formula of the form \[ u(r,\theta)=\frac1{2\pi}\int_{\phi=0}^{2\pi} \frac{(a^2-r^2)f(\phi)}{a^2-2ar\cos(\phi-\theta)+r^2}\,d\phi. \] [2+8]
