MMC-11

Real Analysis
M.Sc. Mathematics · Semester I2025
  1. 1(a) Define Lebesgue measurable sets. Prove that the collection of all measurable sets in $\mathbb R$ is a $\sigma$-algebra. [1+4]
  2. 1(b) Is Cantor set measurable? Justify your answer. [2]
  3. 1(c) Prove or disprove: There exists an open set $E$ contained in the Cantor set $C$. [3]
  4. 2(a) Let $A$ be a measurable subset of $\mathbb R$. Show that for each $\delta>0$, there exists an open set $B$ containing $A$ such that $m^*(B\setminus A)<\delta$. [4]
  5. 2(b) Find the outer measure of the sets\par (i) $\{x^2:x\in\mathbb Z\}$, (ii) $\{x\in\mathbb R:\sin^2x+\cos^2x=1\}$, (iii) $\{x\in\mathbb R:e^{\frac1x}=1\}$. [2+2+2]
  6. 3(a) When is a function $f:A\longrightarrow\mathbb R\cup\{\pm\infty\}$ said to be (Lebesgue) measurable? Examine if a monotone function defined on an interval is measurable. [1+4]
  7. 3(b) Show by an example that the composition of two measurable functions may not be measurable. [5]
  8. 4(a) Let $f:[1,9]\longrightarrow\mathbb R$ be defined by $f(x)=\begin{cases}7&\text{if }1\le x<3\\1&\text{if }3\le x<7\\26&\text{if }7\le x\le9.\end{cases}$ Compute the Lebesgue integral, if it exists, of $f$ over $[1,9]$ with proper justification. [5]
  9. 4(b) Establish the linearity and monotonicity of integration for bounded measurable functions. [5]
  10. 5(a) State and prove Monotone Convergence Theorem. Does it hold for every monotone sequence of functions? Provide justification. [4+3]
  11. 5(b) Let $f\equiv\infty$ on a set $A\subset\mathbb R$ with $m(A)=0$. Show that $\displaystyle\int_Af=0$. [3]
  12. 6(a) Describe the notion of convergence in measure. If a sequence $\{f_n\}$ of measurable functions on a set $E$ converges in measure to a measurable function $f$ on $E$ and each $f_n$ and $f$ are finite a.e. on $E$, show that there exists a subsequence $\{f_{n_k}\}$ which converges to $f$ pointwise a.e. on $E$. [2+4]
  13. 6(b) When is a non-negative measurable function $f$ called integrable over a set $B$? Show that such a function $f$ is finite a.e. on $B$. [1+3]
