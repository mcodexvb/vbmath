MMC-11

Real Analysis
M.Sc. Mathematics · Semester I2024
  1. 1(a) What do you mean by the outer measure $m^*(A)$ of a set $A\subset\mathbb R$? Give example. Show that $m^*$ is countably sub-additive. [2+4]
  2. 1(b) Prove or disprove: All intervals are measurable. [4]
  3. 2(a) If $E_1,E_2,\ldots$ are measurable subsets of $\mathbb R$ such that $E_1\subseteq E_2\subseteq\cdots$, then show that \[ m\left(\bigcup_{n=1}^\infty E_n\right)=\lim_{n\to\infty}m(E_n). \] [4]
  4. 2(b) When is a property said to hold a.e.\ on a measurable set $A$? Explain with example. If $A\subseteq\mathbb R$ is a measurable set and $\phi$ is an extended measurable function on $A$ and $\phi=\psi$ a.e.\ on $A$, show that $\psi$ is measurable on $A$. [2+4]
  5. 3(a) Construct the Canor-Lebesgue function $\phi$ on $[0,1]$ Show that the function $\psi:[0,1]\longrightarrow\mathbb R$ defined by $\psi(x)=\phi(x)+x$ maps a measurable set onto a non-measurable set. [3+4]
  6. 3(b) Let $f:A\longrightarrow [0,\infty)$ be ameasurable function on $A\subseteq\mathbb R$ such that $\displaystyle\int_A f=0$. Prove that $f=0$ a.e.\ on $A$. [3]
  7. 4(a) State and prove Fatou's Lemma. Show by an example that it does not hold good unless you take a sequence of non-negative measurable functions. [4+3]
  8. 4(b) If $\{f_n\}$ is a sequence of measurable functions on a set $A$ of finite measure such that $f_n\longrightarrow f$ pointwise a.e.\ on $A$ and $f$ is finite a.e.\ on $A$, show that $f_n\longrightarrow f$ in measure on $A$. [3]
  9. 5(a) Let $f$ be bounded function on a closed and bounded interval $[a,b]$. If $f$ is continuous a.e.\ on $[a,b]$, show that $f$ is Riemann integrable over $[a,b]$. [5]
  10. 5(b) State Monotone Convergence Theorem and use it to evaluate the Lebesgue integral of the function $f:[0,1]\longrightarrow\mathbb R$ defined by \[ f(x)=\begin{cases}0&\text{if }x=0\\\frac1{x^{1/3}}&\text{if }0<x\leq1.\end{cases} \] [1+4]
  11. 6(a) Let $\{f_n\}$ be a sequence of bounded measurable functions on a set $E$ of finite measure. If $f_n\longrightarrow f$ uniformly on $E$, show that $\displaystyle\lim_{n\to\infty}\int_E f_n=\int_E f$. Does the conclusion hold if $f_n\longrightarrow f$ pointwise only on $E$? Justify your answer. [4+2]
  12. 6(b) Let a function $f:X=[1,\infty)\longrightarrow\mathbb R$ be given by $f(x)=\frac1{2^n}$ if $n\leq x<n+1$. Show that $\displaystyle\int_X f=1$. [4]
