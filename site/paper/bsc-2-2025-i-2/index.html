Internal test

B.Sc. Mathematics · Semester II2025
  1. 1(a) Write the law of transformation for the tensor $A^{ij}_k$.
  2. 1(b) Using summation convention write $B^{121}_{11}+B^{122}_{12}+B^{221}_{21}+B^{222}_{22}$ in compact form, if admissible.
  3. 1(c) How many components does a $(2,1)$- tensor have in a space of $2$-dimensions?
  4. 2(a) Show that $\delta_{jk}=\begin{cases}1&j=k\\0&j\ne k\end{cases}$ is not a tensor as the notation might indicate.
  5. 2(b) If $A^{pq}_r$ is a $(2,1)$-tensor, verify whether $A^{pq}_q$ is a tensor. Find its rank, if yes.
  6. 2(c) Find the value of $A_{ij}x^ix^j$ if $A_{ij}$ is a skew symmetric tensor.
  7. 3(a) Write down the rule of correspondence among Cartesian and spherical polar coordinates in three dimensions.
  8. 3(b) Find the contravariant- and covariant components in spherical polar coordinates whenever contravariant components in Cartesian coordinates are given by $y,x,2$.
  9. 3(c) State whether the contravariant- and covariant components in 3.b) are same?
  10. 4(a) How do you describe a curve on a surface in terms of parameters. Write down the expression for infinitesimal arc length of a curve on a surface in curvilinear coordinates.
  11. 4(b) Define metric tensor. Determine its order and rank.
  12. 4(c) Determine all components of metric tensor in cylindrical polar coordinates.
  13. 5(a) Verify which of $v^k=\frac{dx^k}{dt}$ and $\frac{dv^k}{dt}$ is a tensor?
  14. 5(b) Define Christoffel's symbols of first and second kinds.
  15. 5(c) Find the expressions of Christoffel's symbols in polar coordinate (in two dimensions).
  16. 6(a) Verify whether the partial derivative of $A^i$ with respect to $x^r$ is a tensor?.
  17. 6(b) Define covariant derivative of $A^{ij}_{pq}$ with respect to $x^r$. Is it a tensor? Give its order and rank, if yes.
  18. 6(c) If $A_{p,q}$ represents the covariant derivative of $A_p$ with respect to $x^q$, state whether $A_{p,q}-A_{q,p}$ is a tensor. Check whether this is symmetric or not, if yes.
