MMC-31

Discrete Mathematics
M.Sc. Mathematics · Semester III2019
  1. 1 Examine the validity of the argument forms:\par
  2. 1(a) \hspace*{1em}$P\equiv(Q\equiv\sim R)$\par \hspace*{2.2em}$Q\to(\sim R\vee\sim S)$\par \hspace*{2.2em}$[R\to(Q\vee\sim T)]\wedge(P\to Q)$\par \hspace*{2.2em}$[U\to(S\wedge T)]\wedge(T\to\sim V)$\par \hspace*{2.2em}$[(Q\wedge R)\to\sim U]\wedge[U\to(Q\vee R)]$\par \hspace*{2.2em}$(Q\vee V)\wedge\sim V$\par \hspace*{2.2em}$\therefore\ \sim U\wedge\sim V$ [4]
  3. 1(b) \hspace*{1em}$A\to(B\to C)$\par \hspace*{2.2em}$B\to(C\to D)$\par \hspace*{2.2em}$\therefore\ A\to(B\to D)$ [2]
  4. 1(c) \hspace*{1em}$A\to(B\wedge C)$\par \hspace*{2.2em}$(B\vee D)\to E$\par \hspace*{2.2em}$D\vee A$\par \hspace*{2.2em}$\therefore\ E$ [2]
  5. 1(d) \hspace*{1em}$(K\to L)\wedge(M\to N)$\par \hspace*{2.2em}$(L\vee N)\to\left[\{O\to O\vee P\}\to(K\wedge M)\right]$\par \hspace*{2.2em}$\therefore\ K\equiv M$ [2]
  6. 2(a) Construct a formal proof of validity for the argument forms:\par \hspace*{1em}i) No sane witness would lie if his lying would implicate him in a crime. Therefore, if any witness implicated himself in a crime, then if all witnesses were sane, that witness did not lie. \par \hspace*{1em}ii) There is a professor who is liked by every student who likes at least one professor. Every student likes some professor or other. Therefore, there is a professor who is liked by all students. [3]
  7. 2(b) Show that the argument\par \hspace*{2em}$(\forall x)(\exists y)(F(x)\equiv G(y))$\par \hspace*{2em}$\therefore\ (\exists y)(\forall x)(F(x)\equiv G(y))$\par is invalid. \par\hfill P.T.O. [3]
  8. 3(a) Define a Euler graph. Show that if a connected graph $G$ is Eulerian, then every vertex of $G$ has even degree. [1+3]
  9. 3(b) Show that every graph $G$, for which $\delta(G)\ge2$, contains a path of length $\delta(G)$ and a cycle of length at least $\delta(G)+1$. [2]
  10. 3(c) Define a spanning tree for a graph $G$. Write an algorithm for the construction of a spanning tree for a connected graph $G$, using BFS method. Illustrate the same with an example. [4]
  11. 4(a) Show that a connected graph with $n$ vertices has exactly one cycle if and only if it has exactly $n$ edges. Show also that any two longest paths have a vertex in common.
  12. 4(b) i) If $G$ is a planar graph, then show that $G$ has a node of degree less than 6. \par \hspace*{1em}ii) What is meant by edge colouring of a graph $G$? Define chromatic number $\chi(G)$. \par \hspace*{1em}Show that $\chi(G)=\max\{\chi(C),C$ is a connected component of $G\}$. [2]
  13. 5(a) Count the number of $n$-digit quaternary sequences that have an even number of 1's. [5]
  14. 5(b) State pigeon-hole principle. Use it to show that in any sequence of $(mn+1)$ different numbers, there is always an increasing subsequence of at least $(m+1)$ numbers or a decreasing subsequence of at least $(n+1)$ numbers. [1+4]
  15. 6(a) State the inclusion-exclusion principle. Use it to count the number of derangements of $\{1,2,3,\ldots,n\}$. [1+4]
  16. 6(b) State Burnside's theorem on counting. Use it to count the number of different arrangements to colour the sides of a square by either red or blue colours if a colouring that can be obtained from another by rotation is considered identical.
