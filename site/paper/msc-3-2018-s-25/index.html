MMO-31(P11/A13)

M.Sc. Mathematics · Semester III2018
  1. 1(a) Define Prenex Normal Form of a formula. Obtain the same for the form\par \[(\forall x)(\forall y)\left[(\exists z)\left(P(x,z)\wedge P(y,z)\right)\to(\exists u)Q(x,y,u)\right].\]
  2. 1(b) Define Skolem standard form of a formula. Let $S$ be the set of clauses representing the standard form of a formula $F$. Show that $F$ is inconsistent if and only if $S$ is inconsistent.
  3. 1(c) Define Herbrand universe, Herbrand base and interpretation over Herbrand universe. For the formula\par \[S=\{P(x)\vee Q(x),\ R(f(y))\}\] write a $H$-interpretation $I$.
  4. 2(a) State and prove Davis and Putnam's Pure-literal rule.
  5. 2(b) Show that a set $S$ of clauses is unsatisfiable if and only if there is a finite unsatisfiable set $S'$ of ground instances of clauses of $S$. [5]
  6. 2(c) For the set $S=\{P(x),\ Q(x,f(x))\vee\sim P(x),\ \sim Q(g(y),z)\}$\par find an unsatisfiable set $S'$ of ground instances of clauses in $S$. [2]
  7. 3(a) State the Resolution principle. Show, by resolution, that a set $S$ of clauses is unsatisfiable if and only if there is a resolution -- deduction of the empty clause from $S$.
  8. 3(b) Use resolution to show the validity of the following argument: \par Custom officials searched everyone who entered this country who was not a V.I.P. Some of the drug-pushers entered this country and they were only searched by drug-pushers. No drug-pusher was a V.I.P. Therefore, some officials were drug-pushers. [5]
  9. 4(a) Define a sequential machine $S$ without output. Show that for a $n$-state machine (finite) $S$\par \[(\forall s)_{S^c}\,(\exists x)_{\Sigma_k^*}\,\left(s=rp_S(x)\wedge lg(x)<n\right)\] where $S^c$ is the connected submachine of $S$.
  10. 4(b) Let $S$ be a finite state sequential machine without output and $R$ be a congruence relation on the set $S$. Define the quotient machine $S/R$ and show that it is well defined. \par\hfill P.T.O.
  11. 4(c) Let $\phi$ be a homomorphism from a machine $S$ into a machine $T$. Show that it is possible to define a congruence relation $R$ on $S$ so that $T$ is isomorphic to $S/R$. [4]
  12. 5(a) Define $T(R,\beta)$, the quotient sequential machine with output modulo-$R$ and parameter $\beta$. $R_1,R_2$ are two right congruence relations on $\Sigma_k^*$ which respectively refines $\beta_1$ and $\beta_2\subseteq\Sigma_k^*$. Show that there exists a homomorphism from\par \hspace*{2em}$T(R_1,\beta_1)$ to $T(R_2,\beta_2)$\par if and only if\par \hspace*{2em}$R_1\subseteq R_2$ and $\beta_1\subseteq\beta_2$.
  13. 5(b) Define equi-response relation $\perp(S)$ of a sequential machine $S$ without output. Show that it is a right congruence relation on $S$. Show also that for any connected machine $S$,\par \hspace*{2em}$T(\perp(S))$ is isomorphic to $S$.
  14. 6(a) Define $R_F$, the equivalence relation for states of a single machine $S=\langle S,\Sigma_k^*,M,a,F\rangle$. Show that $R_F$ is a right congruence relation on $S$ which refines $F$. Show also that $R_F$ is the largest congruence relation which refines $F$.
  15. 6(b) Let $S$ and $T$ be two connected machines. $S\equiv T$ if and only if\par \hspace*{2em}$S^M$ and $T^M$ are isomorphic. [5]
