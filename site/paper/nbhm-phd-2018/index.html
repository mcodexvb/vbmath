NBHM · 2018 · Doctoral scholarship

  1. 1.1 Find the number of elements conjugate to $(1\ 2\ 3\ 4\ 5\ 6\ 7)$ in $S_7$.
  2. 1.2 What is the order of a $2$-Sylow subgroup in $GL_3(\mathbb{F}_5)$?
  3. 1.3 Let $H$ be the subgroup generated by $(1\ 2)$ in $S_3$. Compute the normalizer, $N(H)$, of $H$.
  4. 1.4 Let $G$ be a group. Which of the following statements are true? \begin{enumerate}[label=\alph*.] \item The normalizer of a subgroup of $G$ is a normal subgroup of $G$. \item The centre of $G$ is a normal subgroup of $G$. \item If $H$ is a normal subgroup of $G$ and is of order $2$, then $H$ is contained in the centre of $G$. \end{enumerate}
  5. 1.5 Which of the following are prime ideals in the ring $\mathcal{C}[0, 1]$? \begin{enumerate}[label=\alph*.] \item $J = \{f \in \mathcal{C}[0, 1] \mid f(x) = 0 \text{ for all } \frac{1}{3} \le x \le \frac{2}{3}\}$. \item $J = \{f \in \mathcal{C}[0, 1] \mid f(\frac{1}{3}) = f(\frac{2}{3}) = 0\}$. \item $J = \{f \in \mathcal{C}[0, 1] \mid f(\frac{1}{3}) = 0\}$. \end{enumerate}
  6. 1.6 Let $W = \left\{A \in \mathbb{M}_3(\mathbb{R}) \;\middle|\; A^T = -A \text{ and } \sum_{j=1}^{3} a_{1j} = 0\right\}$. Write down a basis for $W$.
  7. 1.7 Let $A \in \mathbb{M}_5(\mathbb{C})$ be such that $(A^2 - I)^2 = 0$. Assume that $A$ is not a diagonal matrix. Which of the following statements are true?\\ a.\ $A$ is diagonalizable. \qquad b.\ $A$ is not diagonalizable. \qquad c.\ No conclusion can be drawn about the diagonalizability of $A$.
  8. 1.8 Which of the following statements are true? \begin{enumerate}[label=\alph*.] \item If $A \in \mathbb{M}_n(\mathbb{R})$ is such that $(Ax, x) = 0$ for all $x \in \mathbb{R}^n$, then $A = 0$. \item If $A \in \mathbb{M}_n(\mathbb{C})$ is such that $(Ax, x) = 0$ for all $x \in \mathbb{C}^n$, then $A = 0$. \item If $A \in \mathbb{M}_n(\mathbb{C})$ is such that $(Ax, x) \ge 0$ for all $x \in \mathbb{C}^n$, then $A = A^*$. \end{enumerate}
  9. 1.9 Let $A = \begin{bmatrix} 1 & 1 & 1 \\ 0 & 2 & 1 \\ 0 & 0 & 2 \end{bmatrix}$. Let $W = \{x \in \mathbb{R}^3 \mid Ax = 2x\}$. Construct a linear functional $\varphi$ on $\mathbb{R}^3$ such that $\varphi(x_0) = 1$, where $x_0^T = (1, 2, 3)$, and $\varphi(x) = 0$ for all $x \in W$.
  10. 1.10 Let $V$ be a finite dimensional vector space over $\mathbb{R}$ and let $f$ and $g$ be two non-zero linear functionals on $V$ such that whenever $f(x) \ge 0$, we also have that $g(x) \ge 0$. Which of the following statements are true?\\ a.\ $\ker(f) \subset \ker(g)$. \qquad b.\ $\ker(f) = \ker(g)$. \qquad c.\ $f = \alpha g$ for some $\alpha > 0$.
  11. 2.1 Let $\{a_n\}_{n=1}^{\infty}$ be a sequence of non-negative real numbers. Which of the following statements are true? \begin{enumerate}[label=\alph*.] \item If $\sum_{n=1}^{\infty} a_n < +\infty$, then $\sum_{n=1}^{\infty} a_n^5 < +\infty$. \item If $\sum_{n=1}^{\infty} a_n^5 < +\infty$, then $\sum_{n=1}^{\infty} a_n < +\infty$. \item If $\sum_{n=1}^{\infty} a_n^{\frac{3}{2}} < +\infty$, then $\sum_{n=1}^{\infty} \frac{a_n}{n} < +\infty$. \end{enumerate}
  12. 2.2 Which of the following functions are uniformly continuous on $\mathbb{R}$? \begin{enumerate}[label=\alph*.] \item $f(x) = |\sin^3 x|$. \item $f(x) = \tan^{-1} x$. \item $f(x) = \sum_{n=1}^{\infty} f_n(x)$, where $f_n(x) = \begin{cases} n(x - n + \frac{1}{n}), & \text{if } x \in [n - \frac{1}{n}, n], \\ n(n + \frac{1}{n} - x), & \text{if } x \in [n, n + \frac{1}{n}], \\ 0, & \text{otherwise.} \end{cases}$ \end{enumerate}
  13. 2.3 Let $f$ and $g$ be defined on $\mathbb{R}$ by \[ f(x) = \begin{cases} 1, & \text{if } x \text{ is rational,} \\ 0, & \text{if } x \text{ is irrational,} \end{cases} \quad\text{and}\quad g(x) = \begin{cases} 1, & \text{if } x \ge 0, \\ 0, & \text{if } x < 0. \end{cases} \] Which of the following statements are true? \begin{enumerate}[label=\alph*.] \item The function $f$ is continuous almost everywhere. \item The function $f$ is equal to a continuous function almost everywhere. \item The function $g$ is equal to a continuous function almost everywhere. \end{enumerate}
  14. 2.4 Let $\{f_n\}_{n=1}^{\infty}$ be a sequence of continuous functions defined on $[0, 1]$. Assume that $f_n(x) \to f(x)$ for every $x \in [0, 1]$. Which of the following conditions imply that this convergence is uniform? \begin{enumerate}[label=\alph*.] \item The function $f$ is continuous. \item $f_n(x) \downarrow f(x)$ for every $x \in [0, 1]$. \item The function $f$ is continuous and $f_n(x) \downarrow f(x)$ for every $x \in [0, 1]$. \end{enumerate}
  15. 2.5 Let $\{f_n\}_{n=1}^{\infty}$ be a sequence of non-negative continuous functions defined on $[0, 1]$. Assume that $f_n(x) \to f(x)$ for every $x \in [0, 1]$. Which of the following conditions imply that $\lim_{n \to \infty} \int_0^1 f_n(x)\,dx = \int_0^1 f(x)\,dx$?\\ a.\ $f_n(x) \uparrow f(x)$ for every $x \in [0, 1]$. \qquad b.\ $f_n(x) \le f(x)$ for every $x \in [0, 1]$. \qquad c.\ $f$ is continuous.
  16. 2.6 Let $\{f_n\}_{n=1}^{\infty}$ and $f$ be integrable functions on $[0, 1]$ such that $\lim_{n \to \infty} \int_0^1 |f_n(x) - f(x)|\,dx = 0$. Which of the following statements are true? \begin{enumerate}[label=\alph*.] \item $f_n(x) \to f(x)$, as $n \to \infty$, for almost every $x \in [0, 1]$. \item $\int_0^1 f_n(x)\,dx \to \int_0^1 f(x)\,dx$, as $n \to \infty$. \item If $\{g_n\}_{n=1}^{\infty}$ is a uniformly bounded sequence of continuous functions converging pointwise to a function $g$, then $\int_0^1 |f_n(x)g_n(x) - f(x)g(x)|\,dx \to 0$ as $n \to \infty$. \end{enumerate}
  17. 2.7 Let $f : [-\pi, \pi] \to \mathbb{R}$ be a continuous $2\pi$-periodic function whose Fourier series is given by $\frac{a_0}{2} + \sum_{k=1}^{\infty} (a_k\cos kt + b_k\sin kt)$. Let, for each $n \in \mathbb{N}$, $f_n(t) = \frac{a_0}{2} + \sum_{k=1}^{n} (a_k\cos kt + b_k\sin kt)$, and let $f_0$ denote the constant function $a_0/2$. Which of the following statements are true? \begin{enumerate}[label=\alph*.] \item $f_n \to f$ uniformly on $[-\pi, \pi]$. \item If $\sigma_n = (f_0 + f_1 + \dots + f_n)/(n + 1)$, then $\sigma_n \to f$ uniformly on $[-\pi, \pi]$. \item $\int_{-\pi}^{\pi} |f_n(x) - f(x)|^2\,dx \to 0$, as $n \to \infty$. \end{enumerate}
  18. 2.8 Let $f \in \mathcal{C}^1[-\pi, \pi]$. Define, for $n \in \mathbb{N}$, $b_n = \int_{-\pi}^{\pi} f(t)\sin nt\,dt$. Which of the following statements are true?\\ a.\ $b_n \to 0$, as $n \to \infty$. \qquad b.\ $nb_n \to 0$, as $n \to \infty$. \qquad c.\ The series $\sum_{n=1}^{\infty} n^3 b_n^3$ is absolutely convergent.
  19. 2.9 Let $\Gamma$ denote the circle in the complex plane, centred at zero and of radius $2$, described in the counter-clockwise sense. Evaluate: $\displaystyle\int_\Gamma \frac{e^{-z}}{(z - 1)^2}\,dz$.
  20. 2.10 Which of the following statements are true? \begin{enumerate}[label=\alph*.] \item There exists an entire function defined on $\mathbb{C}$ such that $f(0) = 1$ and $|f(z)| \le |z|^{-2}$ for all $z \in \mathbb{C}$ such that $|z| \ge 10$. \item If $f : \mathbb{C} \to \mathbb{C}$ is a non-constant entire function, then its image is dense in $\mathbb{C}$. \item Let $\gamma : [0, 1] \to \{z \in \mathbb{C} \mid |z| \le 1\}$ be a non-constant continuous mapping such that $\gamma(0) = 0$. Let $f$ be an analytic function in the disc $\{z \in \mathbb{C} \mid |z| < 2\}$, such that $f(0) = 0$ and $f(1) = 1$. Then, there exists $\tau$ such that $0 < \tau < 1$ and such that for all $0 < t < \tau$, we have that $f(\gamma(t)) \neq 0$. \end{enumerate}
  21. 3.1 Let $(X, d)$ be a metric space and let $\{x_n\}_{n=1}^{\infty}$ be a sequence in $X$. Let $x \in X$. Define a sequence $\{y_n\}_{n=1}^{\infty}$ by $y_{2n-1} = x_n$ and $y_{2n} = x$, $n \in \mathbb{N}$. Which of the following statements are true? \begin{enumerate}[label=\alph*.] \item If $x_n \to x$ as $n \to \infty$, then the sequence $\{y_n\}$ is Cauchy. \item If the sequence $\{y_n\}$ is Cauchy, then $x_n \to x$ as $n \to \infty$. \item Let $f : X \to X$ be a mapping that maps Cauchy sequences to Cauchy sequences. Then $f$ is continuous. \end{enumerate}
  22. 3.2 Let $\{V_n\}_{n=1}^{\infty}$ be a sequence of open and dense subsets of $\mathbb{R}^N$. Set $V = \bigcap_{n=1}^{\infty} V_n$. Which of the following statements are true?\\ a.\ $V \neq \emptyset$. \qquad b.\ $V$ is an open set. \qquad c.\ $V$ is dense in $\mathbb{R}^N$.
  23. 3.3 Let $X$ be a topological space and let $U \subset X$. In which of the following cases is $U$ open? \begin{enumerate}[label=\alph*.] \item Let $U$ be the set of invertible upper triangular matrices in $\mathbb{M}_n(\mathbb{R})$, where $n \ge 2$, and $X = \mathbb{M}_n(\mathbb{R})$. \item Let $U$ be the set of all $2 \times 2$ matrices with real entries such that all their eigenvalues belong to $\mathbb{C} \setminus \mathbb{R}$, and $X = \mathbb{M}_2(\mathbb{R})$. \item Let $U$ be the set of all complex numbers $\lambda$ such that $A - \lambda I$ is invertible, where $A$ is a given $3 \times 3$ matrix with complex entries, and $X = \mathbb{C}$. \end{enumerate}
  24. 3.4 Let $X$ be an infinite set. Define a topology $\tau$ on $X$ as follows: $\tau = \{X, \emptyset\} \cup \{U \mid X \setminus U \text{ is a non-empty finite set}\}$. Which of the following statements are true?\\ a.\ $(X, \tau)$ is Hausdorff. \qquad b.\ $(X, \tau)$ is compact. \qquad c.\ $(X, \tau)$ is connected.
  25. 3.5 Which of the following sets are connected? \begin{enumerate}[label=\alph*.] \item The set of orthogonal matrices in $\mathbb{M}_n(\mathbb{R})$, where $n \ge 2$. \item The set $S = \left\{f \in \mathcal{C}[0, 1] \;\middle|\; \int_0^{\frac{1}{2}} f(t)\,dt - \int_{\frac{1}{2}}^{1} f(t)\,dt = 1\right\}$ in $\mathcal{C}[0, 1]$. \item The set of all points in $\mathbb{R}^2$ with at least one coordinate being a transcendental number. \end{enumerate}
  26. 3.6 Which of the following sets are nowhere dense? \begin{enumerate}[label=\alph*.] \item $S = \{A \in \mathbb{M}_n(\mathbb{R}) \mid \operatorname{tr}(A) = 0\}$ in $\mathbb{M}_n(\mathbb{R})$, where $n \ge 2$. \item $S = \{x \in \ell_2 \mid x = (x_n),\ x_n = 0 \text{ for infinitely many } n\}$ in $\ell_2$. \item The Cantor set in $[0, 1]$. \end{enumerate}
  27. 3.7 For $x = (x_n) \in \ell_2$, define $T(x) = (0, x_1, x_2, \dots)$ and $S(x) = (x_2, x_3, \dots)$. Which of the following statements are true? \begin{enumerate}[label=\alph*.] \item $\|T\| = \|S\| = 1$. \item If $A : \ell_2 \to \ell_2$ is a continuous linear operator such that $\|A - T\| < 1$, then $SA$ is invertible. \item If $A$ is as above, then $A$ is not invertible. \end{enumerate}
  28. 3.8 Let $V$ and $W$ be normed linear spaces and let $T : V \to W$ be a continuous linear operator. Let $B$ be the closed unit ball in $V$. In which of the following cases is $\overline{T(B)}$ compact? \begin{enumerate}[label=\alph*.] \item $V = \mathcal{C}^1[0, 1]$, $W = \mathcal{C}[0, 1]$ and $T(f) = f$. \item $V = W = \ell_2$ and $T(x) = (0, x_1, x_2, \dots)$, where $x = (x_n) \in \ell_2$. \item $V = W = \ell_2$ and $T(x) = (x_1, x_2, \dots, x_{10}, 0, \dots, 0, \dots)$, where $x = (x_n) \in \ell_2$. \end{enumerate}
  29. 3.9 Which of the following statements are true? \begin{enumerate}[label=\alph*.] \item The equation $x^5 + \cos^2 x = 0$ has a solution in $\mathbb{R}$. \item The equation $2x - \cos^2 x = 0$ has a solution in $[0, 1]$. \item The equation $x^3 - \cos^2 x = 0$ has a solution in $[-1, 0]$. \end{enumerate}
  30. 3.10 Let $D$ denote the closed unit disc and let $S^1$ denote the unit circle in $\mathbb{R}^2$. Let $E = \left\{(x, y) \in \mathbb{R}^2 \;\middle|\; \frac{x^2}{4} + \frac{y^2}{9} \le 1\right\}$. Which of the following statements are true? \begin{enumerate}[label=\alph*.] \item If $f : E \to E$ is continuous, then there exists $x \in E$ such that $f(x) = x$. \item If $f : D \to S^1$ is continuous, there exists $x \in S^1$ such that $f(x) = x$. \item If $f : S^1 \to S^1$ is continuous, there exists $x \in S^1$ such that $f(x) = x$. \end{enumerate}
  31. 4.1 Let $A = [0, 1] \times [0, 1] \subset \mathbb{R}^2$. Evaluate: $\displaystyle\iint_A \cos(\pi\max\{x, y\})\,dx\,dy$.
  32. 4.2 Let $S$ denote the unit sphere in $\mathbb{R}^3$. Evaluate: $\displaystyle\int_S (x^4 + y^4 + z^4)\,dS$.
  33. 4.3 If $\Gamma$ denotes the usual gamma function, evaluate $\Gamma(\frac{5}{2})$, given that $\Gamma(\frac{1}{2}) = \sqrt{\pi}$.
  34. 4.4 Find the general solution of the differential equation: $yy'' = (y')^2$.
  35. 4.5 A particle falling freely from rest under the influence of gravity suffers air resistance proportional to the square of its velocity at each instant. If $g$ stands for the acceleration due to gravity and if $c > 0$ is the constant of proportionality for the air resistance, write down the initial value problem satisfied by $y(t)$, the distance travelled by the particle at time $t$.
  36. 4.6 In the preceding problem, if $v(t)$ is the velocity at time $t$, evaluate: $\lim_{t \to +\infty} v(t)$.
  37. 4.7 Write down the following ordinary differential equation as a system of first order differential equations: $y''' = y'' - x^2(y')^2$.
  38. 4.8 Let $\Omega \subset \mathbb{R}^N$ be a bounded domain in $\mathbb{R}^N$, $N \ge 2$. Let $\Delta$ denote the Laplace operator in $\mathbb{R}^N$. Consider the eigenvalue problem: $-\Delta u = \lambda u$ in $\Omega$, $u = 0$ on $\partial\Omega$. If $(u_i, \lambda_i)$, $i = 1, 2$ are two solutions such that $\lambda_1 \neq \lambda_2$ and $\int_\Omega |u_1(x)|^2\,dx = \int_\Omega |u_2(x)|^2\,dx = 1$, evaluate $\int_\Omega u_1(x)u_2(x)\,dx$.
  39. 4.9 Let $\Omega$ denote the unit ball in $\mathbb{R}^3$. Let $\Delta$ denote the Laplace operator in $\mathbb{R}^3$. Let $u$ be such that $\Delta u = c$ in $\Omega$, $\frac{\partial u}{\partial \nu} = 1$ on $\partial\Omega$, where $\frac{\partial u}{\partial \nu}$ is the outer normal derivative of $u$ on $\partial\Omega$. Given that $c$ is a constant, find its value.
  40. 4.10 Let $u(x, t)$ be the solution of the following initial value problem: $\frac{\partial^2 u}{\partial t^2} = \frac{\partial^2 u}{\partial x^2}$, $t > 0,\ x \in \mathbb{R}$; $u(x, 0) = u_0(x)$, $x \in \mathbb{R}$; $\frac{\partial u}{\partial t}(x, 0) = 0$, $x \in \mathbb{R}$. If $u_0(x)$ vanishes outside the interval $[-1, 1]$, find the interval outside which $u(\cdot, t)$ vanishes, when $t > 1$.
  41. 5.1 Let $X$ be a non-empty set. Let $E$ and $F$ be subsets of $X$. Define $E\Delta F = (E \setminus F) \cup (F \setminus E)$. Simplify the following expressions: (a) $(E\Delta F)\Delta(E \cap F)$, and (b) $E\Delta(E\Delta F)$.
  42. 5.2 Let $X$ be a non-empty set and let $\{E_n\}_{n=1}^{\infty}$ be a sequence of subsets of $X$. Let $E \subset X$ be the set of all points in $X$ which lie in infinitely many of the $E_n$. Express $E$ in terms of the $E_n$ using the set theoretic operations of union and intersection.
  43. 5.3 Let $n \in \mathbb{N}$ be fixed. If $0 \le r \le n$, let $C_r = \binom{n}{r}$. Evaluate the sum up to $n$ terms of the series: $3C_1 + 7C_2 + 11C_3 + \cdots$
  44. 5.4 Eight different dolls are to be packed in eight different boxes. If two of the boxes are too small to hold five of the dolls, in how many ways can the dolls be packed?
  45. 5.5 Given six consonants and three vowels, five-letter words are formed. What is the probability that a randomly chosen word contains three consonants and two vowels?
  46. 5.6 Find the lengths of the semi-axes of the ellipse: $5x^2 - 8xy + 5y^2 = 1$.
  47. 5.7 Find the sum of the infinite series: $\dfrac{1}{5} + \dfrac{1}{3}\cdot\dfrac{1}{5^3} + \dfrac{1}{5}\cdot\dfrac{1}{5^5} + \cdots$
  48. 5.8 How many zero's are there at the end of $61!$?
  49. 5.9 Which of the following statements are true? \begin{enumerate}[label=\alph*.] \item The product of $r$ consecutive positive integers is always divisible by $r!$. \item If $n$ is a prime number and if $0 < r < n$, then $n$ divides $\binom{n}{r}$. \item If $n \in \mathbb{N}$, then $n(n + 1)(2n + 1)$ is divisible by $6$. \end{enumerate}
  50. 5.10 Let $a, b, c \in \mathbb{R}$. Find the maximum value of $ax + by + cz$ over the set $\{(x, y, z) \in \mathbb{R}^3 \mid |x|^3 + |y|^3 + |z|^3 = 1\}$.
