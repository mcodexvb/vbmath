MMC-11

New Old
M.Sc. Mathematics · Semester III2018
  1. 1(a) Show that the following sets are measurable and find their measures:\par \hspace*{1em}i) $\{\sin x:0<x<\pi\}$\par \hspace*{1em}ii) $\mathbb Q\cup\{x\in[0,\infty):e^x+\sin x>0\}$\par \hspace*{1em}iii) $\left\{\dfrac1n:n\in\mathbb N\right\}\cup\left\{\dfrac1x:x\in(1,\infty)\right\}$ [2+2+2]
  2. 1(b) Show that a set with outer measure zero is measurable. [2]
  3. 1(c) Let $E$ be a measurable set. Show that there is a measure zero set $F$ such that $E\cup F$ is a $G_\delta$-set. [4]
  4. 2(a) Prove that there exists a non-measurable set. [4]
  5. 2(b) State and prove Luzin theorem. [6]
  6. 2(c) If $f'$ exists on $[a,b]$ then show that $f'$ is measurable. [2]
  7. 3(a) If a sequence $\{f_n\}$ converges in measure to $f$ on a measurable set $E$ then show that there is a subsequence $\{f_{n_k}\}$ which converges almost everywhere to $f$ on $E$. [5]
  8. 3(b) Define a simple function. Is it measurable? Support your answer.\par If $f:E\to[0,\infty)$ be a measurable function then show that there exists a nondecreasing sequence $\{f_n\}$ of simple function converging to $f$ on $E$. [1+6]
  9. 4(a) If $f$ is a bonded and measurable function defined on $E$ then show that $f$ is $L$-integrable. [3]
  10. 4(b) Let $\{E_n\}$ be a sequence of disjoint measurable sets with $\bigcup E_n=E$. If $f$ is Lebesgue integrable on $E$ then show that\par \[\int_{\bigcup E_n}f\,d\mu=\sum_{n=1}^{\infty}\int_{E_n}f\,d\mu.\] [4]
  11. 4(b) State and prove Bounded convergent theorem.\par Does it hold for Reimann integrable functions. Support your answer. \par\hfill P.T.O.
  12. 5(a) Let $f:S\to[0,\infty]$ be measurable. Define for $M>0$.\par \[f_M(x)=\min\{f(x),M\},\ x\in S\cap[-M,M]\] \[\hphantom{f_M(x)}=0\qquad\qquad,\ x\in S-[-M,M]\] Then show that\par \[\int_S f\,d\mu=\lim_{M\to\infty}\int_S f_M\,d\mu.\] And hence find the value of $\displaystyle\int_0^{\infty}e^{-x}dx$. [4+1]
  13. 5(b) If $f$ and $g$ are non-negative measurable functions on $S$, then show that\par \hspace*{1em}i) for any $\alpha>0$, $\displaystyle\int_S(\alpha f)\,d\mu=\alpha\int_S f\,d\mu$ \par \hspace*{1em}ii) $\displaystyle\int_S(f+g)\,d\mu=\int_S f\,d\mu+\int_S g\,d\mu$ [2+4]
  14. 5(c) State Fatou's Lemma. [1]
  15. 6 Answer \textit{any two} of the following:
  16. 6(a) Find $\displaystyle\int_0^1 f(x)\,dx$ where\par \hspace*{2em}$f(x)=n$ if $x=\frac1n,\ n=1,2,\ldots$\par \hspace*{2em}$\phantom{f(x)}=x$ if $x$ is rationals in $[0,1]$ other than $\left\{\frac1n\right\}$\par \hspace*{2em}$\phantom{f(x)}=x^2$ if $x$ is rationals in $[0,1]$.
  17. 6(b) State Dominated convergence theorem. Show that Bounded convergence theorem can be deduced from it.
  18. 6(c) Give examples of $F_\sigma$ and $G_\delta$ sets which are not open or closed.
