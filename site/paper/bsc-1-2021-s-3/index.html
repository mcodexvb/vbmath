CCMA-2

Algebra I
B.Sc. Mathematics · Semester I2021
  1. 1(a) If $a_1,a_2,\dots,a_n$ be $n$ positive real numbers such that $a_1\le a_2\le\dots\le a_n$, then show that $a_1\le(a_1a_2\dots a_n)^{1/n}\le a_n$.
  2. 1(b) State the Cauchy-Schwarz inequality. If $a,b,c$ be three positive real numbers, not all equal, prove that $\frac{bc}{b+c}+\frac{ca}{c+a}+\frac{ab}{a+b}<\frac{a+b+c}2$.
  3. 1(c) If $n$ is a positive integer, prove that $\frac1{2\sqrt{n+1}}<\frac{1.3.5\dots(2n-1)}{2.4.6\dots2n}<\frac1{\sqrt{2n+1}}$.
  4. 2(a) Find $|z|$ and $amp\,z$ where $z=1+\cos2\theta+i\sin2\theta$, $\frac\pi2<\theta<\pi$.
  5. 2(b) State the De Moivre's theorem. Find the product of all the values of $(1+i)^{4/5}$.
  6. 2(c) State and prove the remainder theorem.
  7. 2(d) Find the remainder when $x^5+x^4-2x^3+3x^2+5x-5$ is divided by $(x-1)(x+2)$.
  8. 3(a) Solve the equation $x^4-6x^3+18x^2-24x+16=0$ given that the equation has two roots of the form $\alpha+i\alpha$ and $\beta+i\beta$.
  9. 3(b) State the Descarte's rule of signs. Apply Descarte's rule of signs to find the minimum number of complex roots of the equation $x^7-3x^3+x^2=0$.
  10. 3(c) Find the values of $k$ for which the equation $x^3-12x^2+45x+k=0$ may have multiple roots and solve the equation in each case.
  11. 4(a) When is a system of $m$ linear equations in $n$ variables called consistent? Determine whether the following system of linear equations is consistent: $y-4z=8$, $2x-3y+z=1$, $8x-5y+3z=1$.
  12. 4(b) Discuss the role of free variables in the uniqueness of solution of a consistent system of linear equations. Check whether the solution is unique for the following system: $3x-4y+2z=0$, $-9x+12y-6z=0$, $-6x+8y-4z=0$.
  13. 5(a) Can every vector $b\in\mathbb R^4$ be written as a linear combination of the columns of the matrix $A=\begin{pmatrix}1&3&0&3\\-1&-1&-1&1\\0&-4&2&-8\\2&0&3&-1\end{pmatrix}$? Discuss the consistency of the equation $Ax=b$, for each $b\in\mathbb R^4$.
  14. 5(b) Find the values of $c$ for which the vectors $\begin{pmatrix}1\\5\\-3\end{pmatrix},\begin{pmatrix}-2\\-9\\6\end{pmatrix},\begin{pmatrix}3\\c\\-9\end{pmatrix}$ are linearly dependent.
  15. 6(a) What is the null space $N$ of an $n\times n$ matrix $A$? Show that $N$ is a subspace of $\mathbb R^n$.
  16. 6(b) Define column space of a matrix. Find a basis for the null sapce and a basis for the column space of the matrix $A=\begin{pmatrix}1&4&8&-3&-7\\-1&2&7&3&4\\-2&2&9&5&5\\3&6&9&-5&-2\end{pmatrix}$. Also find the rank of $A$.
  17. 7(a) Let $T:\mathbb R^2\to\mathbb R^3$ be given by $T(u)=(x+3y,7x+5y,3x+y)$, for $u=(x,y)\in\mathbb R^2$. Determine whether $T$ is a linear transformation. Is $T$ one-one? Does $T$ map $\mathbb R^2$ onto $\mathbb R^3$?
  18. 7(b) What do you mean by the rank and nullity of a linear transformation? State Rank-Nullity theorem for a linear transformation $T:\mathbb R^n\to\mathbb R^m$.
  19. 8(a) When is a set $A=\{u_1,u_2,\dots,u_k\}$ of vectors in $\mathbb R^n$ called an orthogonal set? If $A$ is an orthogonal set, then show that $A$ is a basis for a certain subspace of $\mathbb R^n$.
  20. 8(b) Obtain an orthonormal basis for the column space of $A=\begin{pmatrix}3&-5&1\\1&1&1\\-1&5&-2\\3&-7&8\end{pmatrix}$.
  21. 9(a) Let $A$ be an $n\times n$ matrix with distinct eigenvalues $a_1,a_2,\dots,a_k$ $(1\le k\le n)$. If $\alpha_1,\alpha_2,\dots,\alpha_k$ are the corresponding eigenvectors, then show that the set $S=\{\alpha_1,\alpha_2,\dots,\alpha_k\}$ is linearly independent. If $a_1,a_2,\dots,a_k$ are not all distinct, then does $S$ still remain linearly independent? Justify.
  22. 9(b) Check whether the matrix $A=\begin{pmatrix}2&2&-1\\1&3&-1\\-1&-2&2\end{pmatrix}$ is diagonalizable and diagonalize $A$, if possible.
