NBHM · 2015 · Doctoral scholarship

  1. 1.1 Solve the following equation, given that its roots are in arithmetic progression: \[ x^3 - 9x^2 + 28x - 30 = 0. \]
  2. 1.2 Which of the following statements are true? \begin{enumerate}[a.] \item Every group of order $51$ is cyclic. \item Every group of order $151$ is cyclic. \item Every group of order $505$ is cyclic. \end{enumerate}
  3. 1.3 Let $G$ be the multiplicative group of non-zero complex numbers. Consider the group homomorphism $\varphi : G \to G$ given by $\varphi(z) = z^4$. \begin{enumerate}[a.] \item Identify $H$, the kernel of $\varphi$. \item Identify (up to isomorphism) the quotient space $G/H$. \end{enumerate}
  4. 1.4 How many elements of order $7$ are there in a group of order $28$?
  5. 1.5 Which of the following equations can occur as the class equation of a group of order $10$? \begin{enumerate}[a.] \item $10 = 1 + 1 + 1 + 2 + 5$ \item $10 = 1 + 2 + 3 + 4$ \item $10 = 1 + 1 + \dots + 1$ ($10$ times) \end{enumerate}
  6. 1.6 Let $W$ be the subspace of $\R^4$ spanned by the vectors $(1, 0, -1, 1)$ and $(2, 3, -1, 2)$. Write down a basis for $W^\perp$, the orthogonal complement of $W$ in $\R^4$ with respect to the usual euclidean inner-product.
  7. 1.7 Let $B$ be a $5 \times 3$ matrix and let $C$ be a $3 \times 5$ matrix, both with real entries. Set $A = BC$. What are the possible values of the rank of $A$ when\\ a.\ both $B$ and $C$ have rank $3$? \qquad b.\ both $B$ and $C$ have rank $2$?
  8. 1.8 Write down all the eigenvalues (along with their multiplicities) of the matrix $A = (a_{ij}) \in \M_n(\R)$ where $a_{ij} = 1$ for all $1 \le i, j \le n$.
  9. 1.9 Let $V = \M_n(\C)$ be equipped with the inner-product $(A, B) = \tr(B^* A)$, $A, B \in V$. Let $M \in \M_n(\C)$. Define $T : V \to V$ by $T(A) = MA$. What is $T^*(A)$, where $T^*$ denotes the adjoint of the mapping $T$?
  10. 1.10 Find a symmetric and positive definite matrix $B$ such that $B^2 = A$, where $A = \begin{bmatrix} 2 & -1 \\ -1 & 2 \end{bmatrix}$.
  11. 2.1 Find the radius of convergence of the series: $\displaystyle\sum_{n=1}^{\infty} \frac{n^3 z^n}{3^n}$.
  12. 2.2 Let $(X, d)$ be a metric space and let $\{x_n\}$ and $\{y_n\}$ be arbitrary sequences in $X$. Which of the following statements are true? \begin{enumerate}[a.] \item If both $\{x_n\}$ and $\{y_n\}$ are Cauchy sequences, then the sequence of real numbers $\{d(x_n, y_n)\}$ is a Cauchy sequence. \item If $d(x_n, x_{n+1}) < \frac{1}{n+1}$, then the sequence $\{x_n\}$ is a Cauchy sequence. \item If $d(x_n, x_{n+1}) < \frac{1}{2^n}$, then the sequence $\{x_n\}$ is a Cauchy sequence. \end{enumerate}
  13. 2.3 Let $\{a_n\}$ be a sequence of real numbers such that the series $\sum_{n=1}^{\infty} |a_n|^2$ is convergent. Which of the following statements are true? \begin{enumerate}[a.] \item The series $\sum_{n=1}^{\infty} \frac{a_n}{n}$ is convergent. \item The series $\sum_{n=1}^{\infty} |a_n|^p$ is convergent for all $2 < p < \infty$. \item The series $\sum_{n=1}^{\infty} |a_n|^p$ is convergent for all $1 < p < 2$. \end{enumerate}
  14. 2.4 Which of the following statements are true? \begin{enumerate}[a.] \item If $f(x) = |x|^3$ for all $x \in \R$, then $f$ is twice differentiable on $\R$. \item If $f : \R \to \R$ is such that $|f(x) - f(y)| \le |x - y|^{\sqrt{2}}$ for all $x$ and $y$ in $\R$, then $f$ is a constant. \item If $f : \R \to \R$ is differentiable on $\R$ and if $|f'(t)| \le M$ for all $t \in \R$, then there exists $\varepsilon_0 > 0$ such that for all $0 < \varepsilon \le \varepsilon_0$, the function $g(x) = x + \varepsilon f(x)$ is injective. \end{enumerate}
  15. 2.5 Let $f : [0, 1] \to \R$ be continuous. Define $F(x) = \int_0^x f(t)\,dt$, $x \in [0, 1]$. Which of the following statements are true? \begin{enumerate}[a.] \item The function $F$ is Lipschitz continuous on $[0, 1]$. \item The function $F$ is uniformly continuous on $[0, 1]$. \item The function $F$ is of bounded variation on $[0, 1]$. \end{enumerate}
  16. 2.6 Let $f_n(t) = t^n$ for $n \in \N$. Which of the following statements are true? \begin{enumerate}[a.] \item The sequence $\{f_n\}$ converges uniformly on $\left[\frac{1}{4}, \frac{1}{2}\right]$. \item The sequence $\{f_n\}$ converges uniformly on $[0, 1]$. \item The sequence $\{f_n\}$ converges uniformly on $]0, 1[$. \end{enumerate}
  17. 2.7 Let $f \in \mathcal{C}^1[-\pi, \pi]$ be such that $f(-\pi) = f(\pi)$. Define $a_n = \int_{-\pi}^{\pi} f(t)\cos nt\,dt$, $n \in \N$. Which of the following statements are true? \begin{enumerate}[a.] \item The sequence $\{a_n\}$ is bounded. \item The sequence $\{na_n\}$ converges to zero as $n \to \infty$. \item The series $\sum_{n=1}^{\infty} n^2 |a_n|^2$ is convergent. \end{enumerate}
  18. 2.8 Let $\Gamma$ be a simple closed curve in the complex plane (described in the positive sense) and let $z_0$ be a point in the interior of this curve. Evaluate: \[ \int_{\Gamma} \frac{z^3 + 2z}{(z - z_0)^3}\,dz. \]
  19. 2.9 Let $\Gamma$ stand for the unit circle $\{z = e^{i\theta} : -\pi \le \theta \le \pi\}$ in the complex plane. Let $k \in \R$ be a fixed constant. \begin{enumerate}[a.] \item When $\Gamma$ is described in the positive sense, evaluate the integral $\displaystyle\int_{\Gamma} \frac{e^{kz}}{z}\,dz$. \item Hence, or otherwise, evaluate the integral $\displaystyle\int_0^{\pi} e^{k\cos\theta}\cos(k\sin\theta)\,d\theta$. \end{enumerate}
  20. 2.10 Which of the following statements are true? \begin{enumerate}[a.] \item There exists a non-constant entire function which is bounded on the upper half-plane $H = \{z \in \C : \ImPart(z) > 0\}$. \item There exists a non-constant entire function which takes only real values on the imaginary axis. \item There exists a non-constant entire function which is bounded on the imaginary axis. \end{enumerate}
  21. 3.1 Let $S^1 = \{(x, y) \in \R^2 : x^2 + y^2 = 1\}$ and let $S = \{(x, y) \in \R^2 : ax^2 + 2hxy + by^2 = 1\}$. In which of the following cases is $S$ homeomorphic to $S^1$?\\ a.\ $a = 2, h = 1, b = 2$ \qquad b.\ $a = 1, h = 2, b = 1$ \qquad c.\ $a = 1, h = 2, b = 4$
  22. 3.2 Let $(X, d)$ be a compact metric space. Which of the following statements are true? \begin{enumerate}[a.] \item $X$ is complete. \item $X$ is separable. \item If $f : X \to \R$ is a continuous mapping, then it maps Cauchy sequences into Cauchy sequences. \end{enumerate}
  23. 3.3 Let $J$ be any indexing set and let $(X_j, \tau_j)$ be topological spaces for each $j \in J$. Let $X = \prod_{j \in J} X_j$ be the product space with the corresponding product topology, $\tau$. Let $p_j : X \to X_j$, $j \in J$ be the coordinate projection. Which of the following statements are true? \begin{enumerate}[a.] \item The product topology $\tau$ is the weakest (\emph{i.e.}\ smallest) topology on $X$ such that each coordinate projection $p_j$, $j \in J$ is continuous. \item For each $j \in J$, the mapping $p_j$ maps open sets in $X$ onto open sets in $X_j$. \item If $(X', \tau')$ is any topological space and if $f : X' \to X$ is a given mapping, then $f$ is continuous if, and only if, $p_j \circ f : X' \to X_j$ is continuous for each $j \in J$. \end{enumerate}
  24. 3.4 Let $X$ be the space of all polynomials in one variable, with real coefficients. If $p = a_0 + a_1 x + \dots + a_n x^n \in X$, define $\|p\| = |a_0| + |a_1| + \dots + |a_n|$, which gives the metric $d(p, q) = \|p - q\|$ on $X$. Which of the following statements are true? \begin{enumerate}[a.] \item The metric space $X$ is complete. \item Define $T : X \to X$ by $Tp = a_0 + a_1 x + \frac{a_2}{2}x^2 + \dots + \frac{a_n}{n}x^n$, where $p$ is as described earlier. Then $T$ is continuous. \item The mapping $T$ defined above is bijective and is a homeomorphism. \end{enumerate}
  25. 3.5 State whether each of the following subsets of $\M_2(\R)$ are open, closed or neither open nor closed. \begin{enumerate}[a.] \item The set of all matrices in $\M_2(\R)$ such that neither eigenvalue is real. \item The set of all matrices in $\M_2(\R)$ such that both eigenvalues are real. \end{enumerate}
  26. 3.6 Let $X = \R^2 \setminus \{(x, y) \in \R^2 : 3x + 5y + 1 = 0\}$. Which of the following points lie in the same connected component of $X$ as the origin?\\ a.\ $(-1, 2)$ \qquad b.\ $(2, -1)$ \qquad c.\ $(1, -2)$
  27. 3.7 Which of the following sets in $\M_n(\R)$ are connected? \begin{enumerate}[a.] \item $S = \{A \in \M_n(\R) : A^T A = AA^T = I\}$ \item $S = \{A \in \M_n(\R) : \tr(A) = 1\}$ \item $S = \{A \in \M_n(\R) : x^T A x \ge 0 \text{ for all } x \in \R^n\}$ \end{enumerate}
  28. 3.8 Which of the following sequences $\{f_n\}$ in $\mathcal{C}[0, 1]$ must contain a uniformly convergent subsequence? \begin{enumerate}[a.] \item When $|f_n(t)| \le 3$ for all $t \in [0, 1]$ and for all $n \in \N$. \item When $f_n \in \mathcal{C}^1[0, 1]$, $|f_n(t)| \le 3$ and $|f_n'(t)| \le 5$ for all $t \in [0, 1]$ and for all $n \in \N$. \item When $f_n \in \mathcal{C}^1[0, 1]$ and $\int_0^1 |f_n(t)|\,dt \le 1$ for all $n \in \N$. \end{enumerate}
  29. 3.9 Let $X = \{f \in \mathcal{C}[-5, 5] : f(-5) = f(5) = 0\}$. Which of the following statements are true? \begin{enumerate}[a.] \item There exists $f \in X$ such that $f \equiv 2$ on $[-1, 0]$ and $f \equiv 3$ on $[1, 2] \cup [3, 4]$. \item For every $f \in X$, there exist distinct points $x_1$ and $x_2$ in $]-5, 5[$ such that $f(x_1) = f(x_2)$. \item For every $f \in X$, there exists $x \in ]-5, 5[$ such that $f(x) = x$. \end{enumerate}
  30. 3.10 Let $A \in \M_n(\C)$ and let $\rho(A) = \max\{|\lambda| : \lambda \text{ is an eigenvalue of } A\}$ denote its spectral radius. Which of the following subsets of $\M_n(\C)$ are compact? \begin{enumerate}[a.] \item $S = \{A \in \M_n(\C) : \rho(A) \le 1\}$ \item $S = \{A \in \M_n(\C) : A = A^* \text{ and } \rho(A) \le 1\}$ \item $S = \{A \in \M_n(\C) : AA^* = A^* A = I\}$ \end{enumerate}
  31. 4.1 Find the outward unit normal to the curve $\Gamma$, given by the equation $x^2 + 4y^2 = 4$, at a point $P = (x, y)$ lying on it.
  32. 4.2 Write down the equation of the tangent to the curve $\Gamma$ given in the preceding problem at the point $P = (\sqrt{3}, \frac{1}{2})$ lying on it.
  33. 4.3 If $n = (n_1(x, y), n_2(x, y))$ is the outward unit normal at the point $P = (x, y)$ lying on the curve $\Gamma$ given in Problem 4.1, evaluate $\int_{\Gamma} (n_1(x, y)x + n_2(x, y)y)\,ds$.
  34. 4.4 Let $\varphi : \R \to \R$ be a continuous function. Let $f(x, y, z) = \varphi(r)$, where $r = \sqrt{x^2 + y^2 + z^2}$. Let $B$ be the ball in $\R^3$ with centre at the origin and of radius $a > 0$. Express the integral $\int_B f(x, y, z)\,dxdydz$ as an integral with respect to $r$.
  35. 4.5 Find the maximum area that a rectangle can have if its sides are parallel to the coordinate axes and if it is inscribed in the ellipse $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$.
  36. 4.6 Express the following iterated integral with the order of integration reversed: \[ \int_{-1}^{2}\int_{-x}^{2-x^2} f(x, y)\,dydx. \]
  37. 4.7 Find all the possible solutions $(\lambda, u)$, where $\lambda \in \R$ and $u \not\equiv 0$, to the boundary value problem: \[ u''(x) + \lambda u(x) = 0,\quad x \in ]0, 1[,\qquad u(0) = u(1) \text{ and } u'(0) = u'(1). \]
  38. 4.8 Using the change of the dependent variable $z = y^{-2}$, solve the differential equation: $xy' + y = x^4 y^3$.
  39. 4.9 Find the general solution of the linear system: $x'(t) = 4x(t) - y(t)$, $y'(t) = 2x(t) + y(t)$.
  40. 4.10 Find the extremal functions $y(x)$ of the integral: $\int_0^1 (y^2 - (y')^2)\,dx$.
  41. 5.1 Given that the equation $ax^2 + 2hxy + by^2 = 1$ represents an ellipse in the plane, what is its area?
  42. 5.2 Find the area of the circle formed by the intersection of the sphere $x^2 + y^2 + z^2 - 2x - 4y - 6z - 2 = 0$ with the plane $x + 2y + 2z - 20 = 0$.
  43. 5.3 For a positive integer $N$, let $\phi(N)$ denote the number of positive integers (including unity) which are less than $N$ and coprime to it. Which of the following statements are true? \begin{enumerate}[a.] \item If $N \neq M$, then $\phi(NM) = \phi(N)\phi(M)$. \item If $N > 2$, then $\phi(N)$ is always even. \item If $p$ is a prime and if $N = p^k$, $k \in \N$, then $\phi(N) = N\left(1 - \frac{1}{p}\right)$. \end{enumerate}
  44. 5.4 Let $N$ be a fixed positive integer and let $S$ be the set of all positive integers (including unity) which are less than $N$ and coprime to it. What is the sum of all the elements of $S$?
  45. 5.5 Which of the following statements are true? \begin{enumerate}[a.] \item For every $r \in \N$, there exist $r$ consecutive composite numbers in $\N$. \item For every $r \in \N$, the product of $r$ consecutive numbers in $\N$ is always divisible by $r!$. \item If $p$ is a prime and if $r \in \N$ is such that $0 < r < p$, then $p$ divides $\binom{p}{r}$. \end{enumerate}
  46. 5.6 Let $n \in \N$. Which of the following statements are true? \begin{enumerate}[a.] \item For every $n > 1$, $\left(\dfrac{1}{2}\dfrac{3}{4}\cdots\dfrac{2n-1}{2n}\right)^{\frac{1}{n}} > \dfrac{1}{2}$. \item For every $n \ge 1$, $\dfrac{1}{2}\dfrac{3}{4}\cdots\dfrac{2n-1}{2n} < \dfrac{1}{\sqrt{2n+1}}$. \item For every $n > 1$, $1\cdot 3\cdot 5\cdots(2n-1) < n^n$. \end{enumerate}
  47. 5.7 Let $u : \R^N \to \R$ be a given function. For $a \in \R$, define $a^+ = \max\{a, 0\}$. For a fixed $t \in \R$, set $v(x) = (u(x) - t)^+ + t$, $x \in \R^N$. Which of the following statements are true? \begin{enumerate}[a.] \item $\{x \in \R^N : v(x) = t\} = \{x \in \R^N : u(x) = t\}$. \item $\{x \in \R^N : v(x) > t\} = \{x \in \R^N : u(x) > t\}$. \item $\{x \in \R^N : v(x) > \tau\} = \{x \in \R^N : u(x) > \tau\}$ for all $\tau \ge t$. \end{enumerate}
  48. 5.8 Find the number of divisors of $N = 2520$ (excluding unity and $N$).
  49. 5.9 In how many ways can we rearrange the letters in the word \emph{INDIVISIBILITY} such that no two `I's are adjacent to each other? (Note: You are allowed to express the answer in terms of binomial coefficients, factorials etc., in which case you need not explicitly calculate this number.)
  50. 5.10 BCCI has shortlisted $n$ cricketers for a forthcoming tour. It has to select a team of $r$ players \textbf{and} name the captain of the team. This can be done in two ways: (Australian method) First choose the team and then select the captain from amongst the team members. (British method) First choose the captain and then select the remaining members of the team. Write down the combinatorial identity which expresses the fact that both methods yield the same number of outcomes.
