TIFR GS · TIFR GS Mathematics 2021

  1. 1 For each positive integer $n$, let \[ s_n = \frac{1}{\sqrt{4n^2 - 1^2}} + \frac{1}{\sqrt{4n^2 - 2^2}} + \dots + \frac{1}{\sqrt{4n^2 - n^2}}. \] Then $\lim_{n \to \infty} s_n$ equals \begin{enumerate}[label=(\alph*)] \item $\pi/2$ \item $\pi/6$ \item $1/2$ \item $\infty$ \end{enumerate}
  2. 2 The number of bijective maps $g: \mathbb{N} \to \mathbb{N}$ such that $\sum_{n=1}^\infty \frac{g(n)}{n^2} < \infty$ is \begin{enumerate}[label=(\alph*)] \item $0$ \item $1$ \item $2$ \item $\infty$ \end{enumerate}
  3. 3 The value of $\displaystyle \lim_{n \to \infty} \prod_{k=2}^n \left(1 - \frac{1}{k^2}\right)$ is \begin{enumerate}[label=(\alph*)] \item $1/2$ \item $1$ \item $1/4$ \item $0$ \end{enumerate}
  4. 4 The set $S = \{x \in \mathbb{R} \mid x > 0 \text{ and } (1 + x^2)\tan(2x) = x\}$ is \begin{enumerate}[label=(\alph*)] \item empty \item nonempty but finite \item countably infinite \item uncountable \end{enumerate}
  5. 5 The dimension of the real vector space \[ V = \{f: (-1, 1) \to \mathbb{R} \mid f \text{ is infinitely differentiable on } (-1, 1) \text{ and } f^{(n)}(0) = 0 \text{ for all } n \ge 0\} \] is \begin{enumerate}[label=(\alph*)] \item $0$ \item $1$ \item greater than one, but finite \item infinite \end{enumerate}
  6. 6 For a positive integer $n$, let $a_n$ denote the unique positive real root of $x^n + x^{n-1} + \dots + x - 1 = 0$. Then \begin{enumerate}[label=(\alph*)] \item the sequence $\{a_n\}_{n=1}^\infty$ is unbounded \item $\lim_{n \to \infty} a_n = 0$ \item $\lim_{n \to \infty} a_n = 1/2$ \item $\lim_{n \to \infty} a_n$ does not exist \end{enumerate}
  7. 7 Let $A$ be the set of all real numbers $\lambda \in [0,1]$ such that \[ \lim_{p \to 0} \frac{\log(\lambda 2^p + (1 - \lambda) 3^p)}{p} = \lambda \log 2 + (1 - \lambda) \log 3. \] Then \begin{enumerate}[label=(\alph*)] \item $A = \{0, 1\}$ \item $A = \{0, \frac{1}{2}, 1\}$ \item $A = \{0, \frac{1}{3}, \frac{1}{2}, \frac{2}{3}, 1\}$ \item $A = [0, 1]$ \end{enumerate}
  8. 8 Let $X \subseteq \mathbb{R}$ be a subset. Let $\{f_n\}_{n=1}^\infty$ be a sequence of functions $f_n: X \to \mathbb{R}$ that converges uniformly to a function $f: X \to \mathbb{R}$. For each positive integer $n$, let $D_n \subseteq X$ denote the set of points at which $f_n$ is not continuous. Let $D \subseteq X$ denote the set of points at which $f$ is not continuous. Which one of the following statements is correct? \begin{enumerate}[label=(\alph*)] \item If each $D_n$ is finite, then $D$ is finite. \item If each $D_n$ has at most $7$ elements, then $D$ has at most $7$ elements. \item If each $D_n$ is uncountable, then $D$ is uncountable. \item None of the other three statements is correct. \end{enumerate}
  9. 9 Let $f: \mathbb{R} \to \mathbb{R}$ be an arbitrary function. Consider the following assertions: \begin{enumerate}[label=(\Roman*)] \item $f$ is continuous. \item The set $\operatorname{Graph}(f) = \{(x, f(x)) \in \mathbb{R}^2 \mid x \in \mathbb{R}\}$ is a connected subset of $\mathbb{R}^2$. \end{enumerate} Which one of the following statements is correct? \begin{enumerate}[label=(\alph*)] \item (I) implies (II) but (II) does not imply (I). \item (II) implies (I) but (I) does not imply (II). \item (I) implies (II) and (II) implies (I). \item (I) does not imply (II), and (II) does not imply (I). \end{enumerate}
  10. 10 Let $\mathcal{C}$ denote the set of colorings of an $8 \times 8$ chessboard, where each square is colored either black or white. Let $\sim$ denote the equivalence relation on $\mathcal{C}$ defined as follows: two colorings are equivalent if and only if one of them can be obtained from the other by a rotation of the chessboard. The cardinality of the set $\mathcal{C}/\sim$ of equivalence classes of elements of $\mathcal{C}$ under $\sim$ is \begin{enumerate}[label=(\alph*)] \item $2^{62}$ \item $2^{62} + 2^{30} + 2^{15}$ \item $2^{64} - 2^{32} + 2^{16}$ \item $2^{63} - 2^{31} + 2^{15}$ \end{enumerate}
  11. 11 What is the number of surjective maps from the set $\{1, \dots, 10\}$ to the set $\{1, 2\}$? \begin{enumerate}[label=(\alph*)] \item $90$ \item $1022$ \item $98$ \item $1024$ \end{enumerate}
  12. 12 Let $V$ be a vector space over a field $F$. Consider the following assertions: \begin{enumerate}[label=(\Roman*)] \item $V$ is finite dimensional. \item For every linear transformation $T: V \to V$ there exists a nonzero polynomial $p(x) \in F[x]$ such that $p(T): V \to V$ is the zero map. \end{enumerate} Which one of the following statements is correct? \begin{enumerate}[label=(\alph*)] \item (I) implies (II) but (II) does not imply (I). \item (II) implies (I) but (I) does not imply (II). \item (I) implies (II) and (II) implies (I). \item (I) does not imply (II), and (II) does not imply (I). \end{enumerate}
  13. 13 Let $T: \mathbb{C}[x] \to \mathbb{C}[x]$ be the $\mathbb{C}$-linear transformation defined on the complex vector space $\mathbb{C}[x]$ of one variable complex polynomials by $Tf(x) = f(x+1)$. How many eigenvalues does $T$ have? \begin{enumerate}[label=(\alph*)] \item $1$ \item finite but more than $1$ \item countably infinite \item uncountable \end{enumerate}
  14. 14 Let $\mathbb{R}^{\mathbb{N}}$ denote the real vector space of sequences $(x_0, x_1, x_2, \dots)$ of real numbers. Define a linear transformation $T: \mathbb{R}^{\mathbb{N}} \to \mathbb{R}^{\mathbb{N}}$ by $(x_0, x_1, \dots) \mapsto (x_0 + x_1, x_1 + x_2, \dots)$. Which one of the following statements is correct? \begin{enumerate}[label=(\alph*)] \item The kernel of $T$ is infinite dimensional. \item The image of $T$ is infinite dimensional. \item The quotient vector space $\mathbb{R}^{\mathbb{N}}/T(\mathbb{R}^{\mathbb{N}})$ is infinite dimensional. \item None of the other three statements is correct. \end{enumerate}
  15. 15 Which one of the following statements is correct? \begin{enumerate}[label=(\alph*)] \item There exists a $\mathbb{C}$-linear isomorphism $\mathbb{C}^2 \to \mathbb{C}$. \item There exists no $\mathbb{C}$-linear isomorphism $\mathbb{C}^2 \to \mathbb{C}$, but there exists an $\mathbb{R}$-linear isomorphism $\mathbb{C}^2 \to \mathbb{C}$. \item There exists no $\mathbb{R}$-linear isomorphism $\mathbb{C}^2 \to \mathbb{C}$, but there exists a $\mathbb{Q}$-linear isomorphism $\mathbb{C}^2 \to \mathbb{C}$. \item None of the other three statements is correct. \end{enumerate}
  16. 16 The matrix \[ \begin{pmatrix} 4 & -3 & -3 \\ 3 & -2 & -3 \\ -1 & 1 & 2 \end{pmatrix} \] is \begin{enumerate}[label=(\alph*)] \item diagonalizable \item nilpotent \item idempotent \item none of the other three options \end{enumerate}
  17. 17 Which of the following is a necessary and sufficient condition for two real $3 \times 3$ matrices $A$ and $B$ to be similar (i.e., $PAP^{-1} = B$ for an invertible real $3 \times 3$ matrix $P$)? \begin{enumerate}[label=(\alph*)] \item They have the same characteristic polynomial. \item They have the same minimal polynomial. \item They have the same minimal and characteristic polynomials. \item None of the other three conditions. \end{enumerate}
  18. 18 Consider the following two subgroups $A, B$ of the group $\mathbb{Q}[x]$ of one variable rational polynomials under addition: \begin{align*} A &= \{p(x) \in \mathbb{Z}[x] \mid p \text{ has degree at most } 2\}, \text{ and} \\ B &= \{p(x) \in \mathbb{Q}[x] \mid p \text{ has degree at most } 2, \text{ and } p(\mathbb{Z}) \subseteq \mathbb{Z}\}. \end{align*} Then the index $[B : A]$ of $A$ in $B$ equals \begin{enumerate}[label=(\alph*)] \item $1$ \item $2$ \item $4$ \item none of the other three options \end{enumerate}
  19. 19 Let $G$ be any finite group of order $2021$. For which of the following positive integers $m$ is the map $G \to G$, given by $g \mapsto g^m$, a bijection? \begin{enumerate}[label=(\alph*)] \item $43$ \item $45$ \item $47$ \item none of the other three options \end{enumerate}
  20. 20 How many subgroups does $(\mathbb{Z}/13\mathbb{Z}) \times (\mathbb{Z}/13\mathbb{Z})$ have? \begin{enumerate}[label=(\alph*)] \item $13$ \item $16$ \item $4$ \item $25$ \end{enumerate}
  21. 21 Let $f_n: [0,1] \to \mathbb{R}$ be a continuous function for each positive integer $n$. If $\lim_{n \to \infty} \int_0^1 f_n(x)^2\,dx = 0$, then $\lim_{n \to \infty} f_n\left(\frac{1}{2}\right) = 0$.
  22. 22 Let $(X, d)$ be an infinite compact metric space. Then there exists no function $f: X \to X$, continuous or otherwise, with the property that $d(f(x), f(y)) > d(x, y)$ for all $x \ne y$.
  23. 23 Every infinite closed subset of $\mathbb{R}^n$ is the closure of a countable set.
  24. 24 If $X$ is a compact metric space, there exists a surjective (not necessarily continuous) function $\mathbb{R} \to X$.
  25. 25 If $X$ is a compact metric space, then every isometry $f: X \to X$ is surjective.
  26. 26 Define a metric on the set of finite subsets of $\mathbb{Z}$ as follows: $d(A, B) = \text{the cardinality of } (A \cup B) \setminus (A \cap B)$. The resulting metric space admits an isometry into $\mathbb{R}^n$, for some positive integer $n$.
  27. 27 There exists a continuous function $f: [0,1] \to \{A \in M_2(\mathbb{R}) \mid A^2 = A\}$ such that $f(0) = 0$ and $f(1) = \operatorname{Id}$.
  28. 28 Let $f: [0,1] \to \mathbb{R}$ be a monotone increasing (not necessarily continuous) function such that $f(0) > 0$ and $f(1) < 1$. Then there exists $x \in [0,1]$ such that $f(x) = x$.
  29. 29 The set $\{(x, y) \in \mathbb{N} \times \mathbb{N} \mid x \text{ divides } y^x, \, x \ne y, \, xy \ne 0, \, x \ne 1\}$ is finite.
  30. 30 Suppose a line segment of a fixed length $L$ is given. It is possible to construct a triangle of perimeter $L$, whose angles are $105^\circ$, $45^\circ$ and $30^\circ$, using only a straight edge and a compass.
  31. 31 The real vector space $M_n(\mathbb{R})$ cannot be spanned by nilpotent matrices, for any positive integer $n$.
  32. 32 Let $S \subseteq M_n(\mathbb{R})$ be a nonempty finite set closed under matrix multiplication. Then there exists $A \in S$ such that the trace of $A$ is an integer.
  33. 33 Given a linear transformation $T: \mathbb{Q}^4 \to \mathbb{Q}^4$, there exists a nonzero proper subspace $V$ of $\mathbb{Q}^4$ such that $T(V) \subseteq V$.
  34. 34 If $G$ is a finite group such that the group $\operatorname{Aut}(G)$ of automorphisms of $G$ is cyclic, then $G$ is abelian.
  35. 35 There exists a countable group having uncountably many subgroups.
  36. 36 There exists a nonzero ideal $I \subseteq \mathbb{Z}[i]$ such that the quotient ring $\mathbb{Z}[i]/I$ is infinite (here $i$ is a square root of $-1$ in $\mathbb{C}$).
  37. 37 There exists an injective ring homomorphism from the ring $\mathbb{Q}[x, y]/(x^2 - y^2)$ into the ring $\mathbb{Q}[x, y]/(x - y^2)$.
  38. 38 The set $\{n \in \mathbb{N} \mid n \text{ divides } a^3 - 1, \text{ for all integers } a \text{ such that } \gcd(a, n) = 1\}$ is infinite.
  39. 39 The set of polynomials in the ring $\mathbb{Z}[x]$, the sum of whose coefficients is zero, forms an ideal of the ring $\mathbb{Z}[x]$.
  40. 40 Let $c_1, c_2 > 0$, and let $f, g: \mathbb{R} \to \mathbb{R}$ be functions (not assumed to be continuous) such that for all $x \in \mathbb{R}$, $f(x + c_1) = f(x)$ and $g(x + c_2) = g(x)$. Further, assume that $\lim_{x \to \infty} (f(x) - g(x)) = 0$. Then $f = g$.
