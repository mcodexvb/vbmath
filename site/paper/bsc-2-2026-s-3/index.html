SEC-2A

Artificial Intelligence and Machine Learning
B.Sc. Mathematics · Semester II2026
  1. 1 Answer any \textit{twenty} questions from the following.
  2. 1(a) Machine Learning is data-driven, meaning: (i) Output drives data (ii) Code drives output (iii) Data influences model (iv) None
  3. 1(b) Can Machine Learning models be fully trusted? (i) No, they can make mistakes (ii) Yes, always (iii) Only for small data (iv) Only for neural networks
  4. 1(c) In traditional programming, errors are reduced by: (i) Updating code (ii) Changing data randomly (iii) Ignoring mistakes (iv) Deleting features
  5. 1(d) Predicting whether email is spam: Feature = email text, Label = ? (i) Sender (ii) Time (iii) Spam/Not spam (iv) Length
  6. 1(e) Clustering algorithms try to: (i) Maximize similarity within groups (ii) Minimize similarity (iii) Predict labels (iv) Reduce dimensions
  7. 1(f) Logistic regression decision boundary is: (i) Discontinuous (ii) Linear (iii) Non-linear (iv) Random
  8. 1(g) Which dataset is used to tune hyperparameters? (i) Validation (ii) Training (iii) Testing (iv) Random
  9. 1(h) A model trained and tested on the same data will: (i) Be accurate (ii) Be unbiased (iii) Give misleading results (iv) Be perfect
  10. 1(i) In reinforcement learning, the learner is called: (i) Agent (ii) Action (iii) Feature (iv) Environment
  11. 1(j) In clustering, labels are: (i) Present (ii) Absent (iii) Fixed (iv) Random
  12. 1(k) In multiple regression, coefficients represent: (i) Error (ii) Feature importance (iii) Labels (iv) Noise
  13. 1(l) Which of the following is a feature? (i) House price (ii) Student grade (iii) Age of a person (iv) Final result
  14. 1(m) Splitting of the decision tree stops when: (i) All nodes are pure (ii) Depth limit reached (iii) No improvement (iv) All of the above
  15. 1(n) The technique which is used for sampling data: (i) Cross-validation (ii) Clustering (iii) Bootstrapping (iv) Regression
  16. 1(o) What does KNN stand for? (i) Known Nearest Node (ii) K-Nearest Neighbors (iii) K-Nearest Networks (iv) Kernel Neural Network
  17. 1(p) Random Forest works best when: (i) Features are fixed (ii) Data is ignored (iii) Trees are identical (iv) Trees are diverse
  18. 1(q) KNN is called a ``lazy learner'' because: (i) It does not train explicitly (ii) It ignores data (iii) It is inaccurate (iv) It learns slowly
  19. 1(r) Self-driving car is an example of: (i) Supervised learning (ii) Unsupervised learning (iii) Reinforcement learning (iv) Semi-supervised learning
  20. 1(s) Which task predicts house price? (i) Regression (ii) Classification (iii) Clustering (iv) Dimensionality reduction
  21. 1(t) Dimensionality reduction can help in: (i) Visualization (ii) Speed improvement (iii) Noise reduction (iv) All of the above
  22. 1(u) Support vectors are: (i) Points closest to the decision boundary (ii) Points far from the decision boundary (iii) All data points (iv) Random points
  23. 1(v) Margin in SVM is: (i) Distance between two classes (ii) Distance between hyperplane and nearest pointst (iii) Distance between support vectors (iv) Random value
  24. 1(w) If both training and testing accuracy are low, it indicates: (i) Underfitting (ii) Overfitting (iii) Perfect model (iv) No issue
  25. 1(x) Simple linear regression has: (i) One feature and one output (ii) Many features (iii) No output (iv) Only labels
  26. 1(y) SVM decision boundary is: (i) Always linear (ii) Can be linear or non-linear (iii) Always circular (iv) Random
  27. 1(z) Precision is: (i) TN / Total (ii) FP / Total (iii) TP / (TP + FN) (iv) TP / (TP + FP)
