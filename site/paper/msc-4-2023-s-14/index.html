MMO-41(P5)

M.Sc. Mathematics · Semester IV2023
  1. 1(a) Suppose $C$ is an $[n,k,d]$-linear code over $F_q$. Then show that there exists an $[n,k,d-r]$-linear code over $F_q$ for any $1\le r\le d-1$. [[5]]
  2. 1(b) Construct a $[7,3,2]$-binary linear code using direct sum of two linear codes. [[5]]
  3. 2(a) For $m\ge1$, show that the Reed-Muller code $\mathfrak R(1,m)$ is a binary $[2^m,m+1,2^{m-1}]$-linear code. [[5]]
  4. 2(b) Let $C$ be an $[N,K,D]$-linear code over $F_{q^m}$. Then prove that the trace code of $C$ defined by \[\mathit{Tr}_{F_{q^m}/F_q}(C)=\{(\mathit{Tr}_{F_{q^m}/F_q}(c_1),\ldots,\mathit{Tr}_{F_{q^m}/F_q}(c_n)):(c_1,\ldots,c_n)\in C\}\] is an $[n,k]$-linear code over $F_q$ with $n=N$ and $k\le mK$. [[5]]
  5. 3(a) Let $I$ be a nonzero ideal in $F_q[x]/\langle x^n-1\rangle$ and let $g(x)$ be a nonzero monic polynomial of the least degree in $I$. Then $g(x)$ is a generator of $I$ and divides $x^n-1$. [[5]]
  6. 3(b) How many binary cyclic codes of length 8? Justify your answer. [[5]]
  7. 4(a) Show that a $q$-ary BCH code of length $q^m$ with designed distance $\delta$ has dimension at least $q^m-1-m(\delta-1)$. [[6]]
  8. 4(b) Find the dimension of a narrow-sense 4-ary BCH code of length 63 with designed distance 3. [[4]]
  9. 5(a) Show that a BCH code with designed distance $\delta$ has minimum distance at least $\delta$. [[7]]
  10. 5(b) Let $\alpha$ be a root of $1+x+x^3\in F_2[x]$, and let $C$ be the binary BCH code of length 7 with designed distance 4 generated by $g(x)=\mathit{lcm}(M^0(x),M^1(x),M^2(x))$. Find $d(C)$. [[3]]
  11. 6(a) Let $C$ be a $q$-ary RS code generated by $g(x)=\prod_{i=1}^{\delta-1}(x-\alpha^i)$ with $2\le\delta\le q-1$. Then show that the extended code $C$ is still MDS. [[6]]
  12. 6(b) Find a binary $[21,3,7]$- linear code spanned by $100100\ldots100,010010\ldots010,001001\ldots001$. [[4]]
