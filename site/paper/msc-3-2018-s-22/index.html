MMO-31(P3)

Advanced Real Analysis-I
M.Sc. Mathematics · Semester III2018
  1. 1(a) Define $C^+(f,a)$, the cluster set of $f$ at $a$ from the right. Show that $C^+(f,a)$ is closed. [1+3]
  2. 1(b) For any function $f$ show that the following relations hold except on a countable set\par \[\overline f(x+0)=\overline f(x-0)\ge f(x)\ge\underline f(x+0)=\underline f(x-0).\] [4]
  3. 1(c) Show that the set of all points of discontinuities of any function is an $F_\sigma$-set. [4]
  4. 2(a) State and prove Zygmond theorem. [4]
  5. 2(b) If one of the Dini derivates of a continuous function $f$ is continuous at $x_0$ then show that $f'(x_0)$ exists. [4]
  6. 2(c) Define cantor function on $[0,1]$ and show that it is continuous on $[0,1]$. [4]
  7. 3(a) Let $f$ be a Lebesgue integrable function on $[a,b]$ and let\par \[F(x)=\int_a^xf\ \text{ for }x\in[a,b],\] Show that $F'=f$ a.e on $[a,b]$. [6]
  8. 3(b) If $f$ is absolutely continuous on $[a,b]$ then show that $f$ satisfies the Luzin condition in $[a,b]$. [4]
  9. 3(c) If $f$ is absolutely continuous on $\mathbb R$ and $D^+f\ge0$ a.e then $f$ is non-decreasing. [2]
  10. 4(a) Let $f:[a,b]\to\overline{\mathbb R}$, show that $f$ is u.s.c. at $\xi\in[a,b]$ if and only if\par \[f(\xi)\ge\overline f(\xi)=\max\{\overline f(\xi+0),\overline f(\xi-0)\}.\] [5]
  11. 4(b) Let $\{f_n\}$ be a sequence of Baire I functions converges uniformly to $f$ on $\mathbb R$ show that $f$ is also a Baire I function. [5]
  12. 4(c) Give an example with justifications of a Baire 2 function which is not Baire-I. [2]
  13. 5(a) If $f$ is a Baire Class I function then for each $\alpha$ show that $\{x:f(x)<\alpha\}$ and $\{x:f(x)>\alpha\}$ are $F_\sigma$-sets. [5]
  14. 5(b) If $f$ is a convex function on $[a,b]$ then prove that $f$ is bounded on $[a,b]$ and continuous on $(a,b)$. [2+2]
  15. 5(c) If $f$ has finite number of points of discontinuities in $[a,b]$, then show that $f$ is Baire-I on $[a,b]$. [3]
  16. 6 Answer \textit{any two} of the following: \hfill\par \hspace*{1em}a) Show that $f(x)=\sin x+\cos x$ is absolutely continuous on $[0,1]$.\par \hspace*{1em}b) Prove or disprove\par \hspace*{2.5em}The sum of two convex functions both defined on an interval I is convex on I.\par \hspace*{1em}c) Define Vitali cover. State Vitali covering theorem.
