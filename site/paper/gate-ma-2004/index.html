  1. 1 Let $S$ and $T$ be two subspaces of $\mathbb{R}^{24}$ such that $\dim(S) = 19$ and $\dim(T) = 17$. Then, the \begin{enumerate}[label=(\alph*)] \item smallest possible value of $\dim(S \cap T)$ is $2$ \item largest possible value of $\dim(S \cap T)$ is $18$ \item smallest possible value of $\dim(S + T)$ is $19$ \item largest possible value of $\dim(S + T)$ is $22$ \end{enumerate}
  2. 2 Let $v_1 = (1,2,0,3,0)$, $v_2 = (1,2,-1,-1,0)$, $v_3 = (0,0,1,4,0)$, $v_4 = (2,4,1,10,1)$, and $v_5 = (0,0,0,0,1)$. The dimension of the linear span of $\{v_1, v_2, v_3, v_4, v_5\}$ is \begin{enumerate}[label=(\alph*)] \item $2$ \item $3$ \item $4$ \item $5$ \end{enumerate}

  4. 4 Let $f : \mathbb{R}^4 \to \mathbb{R}$ be a linear functional defined by $f(x_1, x_2, x_3, x_4) = -x_2$. If $\langle \cdot, \cdot \rangle$ denotes the standard inner product on $\mathbb{R}^4$, then the unique vector $v \in \mathbb{R}^4$ such that $f(w) = \langle v, w \rangle$ for all $w \in \mathbb{R}^4$ is \begin{enumerate}[label=(\alph*)] \item $(0, -1, 0, 0)$ \item $(-1, 0, -1, 1)$ \item $(0, 1, 0, 0)$ \item $(1, 0, 1, -1)$ \end{enumerate}
