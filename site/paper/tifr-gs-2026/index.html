TIFR Graduate School · GS 2026 · Mathematics: Stage I Questions

  1. 1 For $\alpha>0$, and for all positive integers $n$, let $a_n=\log(1+n^{-\alpha})$. Then, \begin{enumerate}[label=(\alph*)] \item $\sum_{n=1}^\infty a_n$ is convergent for all $\alpha>0$. \item $\sum_{n=1}^\infty a_n$ is convergent for all $\alpha>1$. \item $\sum_{n=1}^\infty a_n$ is convergent for all $0<\alpha\le1$. \item $\sum_{n=1}^\infty a_n$ is divergent for all $\alpha>1$. \end{enumerate}
  2. 2 What is the value of $\displaystyle\lim_{n\to\infty}\left(\prod_{k=1}^n\frac{k}{k+n}\right)^{1/n}$? \begin{enumerate}[label=(\alph*)] \item $1/e$ \item $1/2$ \item $1/\log(4)$ \item $1/4$ \end{enumerate}
  3. 3 For $x\in[0,1]$, let $f(x)=\displaystyle\sum_{n=1}^\infty\frac{x^n}{n^2}$. Then \begin{enumerate}[label=(\alph*)] \item $f$ is continuous but nowhere differentiable. \item $f$ is differentiable on $(0,1)$ and its derivative extends continuously to $[0,1]$. \item $f$ is differentiable on $(0,1)$ but the derivative diverges as $x\to1^-$. \item $f$ can be extended to a real analytic function on $(0,1+\varepsilon)$ for some $\varepsilon>0$. \end{enumerate}
  4. 4 For each positive integer $n$ and each $x\in[0,1]$, define \[ f_n(x)=\sin(n)\exp\!\Bigl(-n^4\bigl(x-\tfrac1n\bigr)^2\Bigr). \] Which of the following is true about the sequence of functions $(f_n)$ on $[0,1]$? \begin{enumerate}[label=(\alph*)] \item $(f_n)$ converges to $0$ uniformly on $[0,1]$. \item $(f_n)$ converges to $0$ pointwise, but not uniformly, on $[0,1]$. \item $(f_n)$ does not converge pointwise on $[0,1]$. \item $(f_n)$ converges uniformly to a nonzero function on $[0,1]$. \end{enumerate}
  5. 5 Let $f:[0,\infty)\to\mathbb{R}$ be a continuous function. Consider the statements: \begin{enumerate}[label=(\roman*)] \item If $\lim_{x\to\infty}f(x)=\infty$, then $f$ is not uniformly continuous. \item If $f$ is bounded, then $f$ is uniformly continuous. \end{enumerate} Which of the following is correct? \begin{enumerate}[label=(\alph*)] \item Both (i) and (ii) are true. \item (i) is true, (ii) is false. \item (i) is false, (ii) is true. \item Both (i) and (ii) are false. \end{enumerate}
  6. 6 Consider the set $\mathcal A=\{A\in M_{10}(\mathbb{R})\mid A^{10}=0\}$. For each $A\in M_{10}(\mathbb{R})$, define the linear transformation $T_A:M_{10}(\mathbb{R})\to M_{10}(\mathbb{R})$ by $T_A(X)=AX$. Then which of the following is true? \begin{enumerate}[label=(\alph*)] \item For all $A\in\mathcal A$, we have $\det(T_A)=0$ and $\operatorname{trace}(T_A)=0$. \item There exists $A\in\mathcal A$ for which $\det(T_A)\neq0$ whereas $\operatorname{trace}(T_A)=0$. \item There exists $A\in\mathcal A$ for which $\det(T_A)=0$ whereas $\operatorname{trace}(T_A)\neq0$. \item There exists $A\in\mathcal A$ for which $\det(T_A)\neq0$ and $\operatorname{trace}(T_A)\neq0$. \end{enumerate}
  7. 7 Let $(X,d)$ be a complete metric space and $U$ be a proper dense subset of $X$. Let $f:U\to\mathbb{R}$ be a function. Consider the following two statements: \begin{enumerate}[label=(\roman*)] \item If $f$ is continuous, then it can be extended to a continuous function $g:X\to\mathbb{R}$. \item If $f$ is uniformly continuous, then it can be uniquely extended to a continuous function $g:X\to\mathbb{R}$. \end{enumerate} Then which of the following is correct? \begin{enumerate}[label=(\alph*)] \item Both (i) and (ii) are true. \item Both (i) and (ii) are false. \item (i) is true but (ii) is false. \item (ii) is true but (i) is false. \end{enumerate}
  8. 8 Let $(X,d)$ be a metric space with the additional property that $d(x,y)\le\max\{d(x,z),d(y,z)\}$ for all $x,y,z\in X$. Consider the following statements: \begin{enumerate}[label=(\roman*)] \item For all $x,y,z\in X$, at least two of the numbers $d(x,y),d(y,z),d(x,z)$ are equal. \item For each positive real number $r$, and $x,y\in X$, the sets $B(x,r)$ and $B(y,r)$ are either equal or disjoint. \end{enumerate} Which of the following is true? \begin{enumerate}[label=(\alph*)] \item (i) and (ii) are true. \item (i) and (ii) are false. \item (i) is true and (ii) is false. \item (ii) is true and (i) is false. \end{enumerate}
  9. 9 Let $T:\mathbb{R}^n\to\mathbb{R}^n$ be a linear map such that $T\neq0$, and $\mathbb{R}^n=\mathrm{range}(T)\oplus\mathrm{null\ space}(T)$. Consider the following statements: \begin{enumerate}[label=(\roman*)] \item $T$ is diagonalisable. \item There does not exist any integer $k>0$ such that $T^k=0$. \end{enumerate} Which of the following must be true? \begin{enumerate}[label=(\alph*)] \item (i) is false and (ii) is true. \item (i) is true and (ii) is false. \item (i) and (ii) are true. \item (i) and (ii) are false. \end{enumerate}
  10. 10 For any differentiable function $g:\mathbb{R}\to\mathbb{R}$, let \[ A_g=\{x\in[0,1]\mid g(x)=0\},\qquad B_g=\{x\in[0,1]\mid g'(x)=0\}. \] Let $S=\{g:\mathbb{R}\to\mathbb{R}\mid g\text{ is differentiable and }A_g\cap B_g=\emptyset\}$. Which of the following statements is true? \begin{enumerate}[label=(\alph*)] \item For all $g\in S$, the set $B_g$ is finite. \item For all $g\in S$, the set $A_g$ is finite. \item There exists $g\in S$ such that both $A_g$ and $B_g$ are infinite. \item None of the other statements is true. \end{enumerate}
  11. 11 Let $g:[1,\infty)\to\mathbb{R}$ be a function such that \[ g(1)=1\quad\text{and}\quad g'(x)=\frac{1}{x^2+g^2(x)}\ \text{ for all } x\ge1. \] Then which of the following statements is true? \begin{enumerate}[label=(\alph*)] \item $\lim_{x\to\infty}g(x)$ exists, and belongs to $(2,\infty)$. \item $\lim_{x\to\infty}g(x)$ exists, and belongs to $(-\infty,2]$. \item None of the other statements is true. \item $\lim_{x\to\infty}g(x)=\infty$. \end{enumerate}
  12. 12 Let $A,B$ be linear endomorphisms of a finite dimensional vector space over a field. Consider the following statements: \begin{enumerate}[label=(\roman*)] \item Every eigenvalue of $AB$ is an eigenvalue of $BA$. \item Every eigenvector of $AB$ is an eigenvector of $BA$. \end{enumerate} Which of the following is correct? \begin{enumerate}[label=(\alph*)] \item Both (i) and (ii) are true. \item (i) is true, (ii) is false. \item (i) is false, (ii) is true. \item Both (i) and (ii) are false. \end{enumerate}
  13. 13 For a real number $a$, let $\lfloor a\rfloor$ denote the greatest integer less than or equal to $a$, and let $\{a\}=a-\lfloor a\rfloor$. Let $n\ge4$ be an integer. Then the expression \[ \left\lfloor\frac{1}{\{n!\,e\}}\right\rfloor \] equals \begin{enumerate}[label=(\alph*)] \item $n$. \item $n-1$. \item $\lfloor(n-2)e\rfloor$. \item None of the other options. \end{enumerate}
  14. 14 Consider the space $X=\left\{A\in M_2(\mathbb{R})\ \Big|\ AA^{\mathsf J}=\begin{pmatrix}2&-2\\-2&3\end{pmatrix}\right\}$. Then the number of connected components of $X$ equals \begin{enumerate}[label=(\alph*)] \item $0$. \item $1$. \item $2$. \item $4$. \end{enumerate}
  15. 15 Let $V$ be the real vector space of all polynomials in $\mathbb{R}[x]$ of degree less than or equal to $10$. Consider the linear operator $T:V\to V$ defined by $(Tp)(x)=p(2x+1)$ for all $p\in V$. What is the trace of $T$? \begin{enumerate}[label=(\alph*)] \item $11$. \item $2047$. \item $121$. \item None of the other options. \end{enumerate}
  16. 16 Let $1\le p<q$ be integers, and let $f(x,y)=y^p-x^q$. Consider the complex vector space \[ V=\frac{\mathbb{C}[x,y]}{\bigl(f,\ \frac{\partial f}{\partial x},\ \frac{\partial f}{\partial y}\bigr)}. \] Then the dimension of $V$ over $\mathbb{C}$ is: \begin{enumerate}[label=(\alph*)] \item $pq$. \item $pq-p-q+1$. \item $p+q$. \item Infinite. \end{enumerate}
  17. 17 Let $\Gamma\subset\mathbb{R}^2$ be the graph of $y=\sin(x)$ and let $\ell$ be a line in $\mathbb{R}^2$ such that $\#(\Gamma\cap\ell)=n\in\mathbb{N}$. Which of the following statements is necessarily true? \begin{enumerate}[label=(\alph*)] \item $n$ is even. \item $n$ is odd. \item $n\le10$. \item None of the remaining three options. \end{enumerate}
  18. 18 Suppose that $f:(-1,1)\to\mathbb{R}$ is infinitely differentiable, and $|f(x)-1-x-x^2|\le|x|^3$ for all $x\in(-\tfrac13,\tfrac13)$. Then, \begin{enumerate}[label=(\alph*)] \item $f(0)=f'(0)=f''(0)=1$. \item $f(0)=f'(0)=1$ and $f'''(0)=6$. \item $f(0)=f'(0)=1$ and $f''(0)=2$. \item None of the other statements is true. \end{enumerate}
  19. 19 Consider the following two assertions about a group $G$. \begin{enumerate}[label=(\Roman*)] \item $G$ is abelian. \item The map $\phi:G\to G$ defined by $\phi(g)=g^2$ is a group homomorphism. \end{enumerate} Which of the following is true? \begin{enumerate}[label=(\alph*)] \item (I) implies (II), and (II) implies (I). \item (I) implies (II), but (II) does not imply (I). \item (I) does not imply (II), but (II) implies (I). \item (I) does not imply (II), and (II) does not imply (I). \end{enumerate}
  20. 20 Suppose that $f_n:[0,1]\to[0,1]$ is continuous and increasing for each $n\ge1$, and the sequence $(f_n(x))_{n\ge1}$ of real numbers is decreasing for all $x\in[0,1]$. Let $f:[0,1]\to[0,1]$ be the function defined as $f(x)=\lim_{n\to\infty}f_n(x)$. Then \begin{enumerate}[label=(\alph*)] \item $f$ is continuous. \item $f$ is right-continuous but not necessarily left-continuous. \item $f$ is left-continuous but not necessarily right-continuous. \item None of the other assertions is true. \end{enumerate}
  21. 21 If $f:\mathbb{R}\to\mathbb{R}$ is a continuously differentiable function and $S\subset\mathbb{R}$ is a bounded subset, then there exists a constant $C_S>0$ such that $|f(x)-f(y)|\le C_S|x-y|$ for all $x,y\in S$.
  22. 22 There exists a continuous surjection from $\mathbb{Q}$ to $\{0,1,\ldots,2026\}$.
  23. 23 The subset $X=\{f\in C([0,1],\mathbb{R}):\ |f(x)-f(y)|\le|x-y|^{1/2}\ \text{for all } x,y\in[0,1]\}$ of $C([0,1],\mathbb{R})$ is compact.
  24. 24 There is no continuous bijection $f:\mathbb{R}\to[0,1]$.
  25. 25 Let $A,B$ be linear endomorphisms of a finite dimensional vector space over a field. If $A$ and $B$ are diagonalizable, then $AB$ is also diagonalizable.
  26. 26 If $A\in GL_5(\mathbb{C})$ and $A^2$ is diagonalizable, then $A$ is diagonalizable.
  27. 27 A function $f:\mathbb{R}\to\mathbb{R}$ is said to be periodic if there exists a positive real number $c$ such that $f(x+c)=f(x)$ for all $x\in\mathbb{R}$. Then the set of all periodic functions is a linear subspace of the real vector space of all functions from $\mathbb{R}$ to $\mathbb{R}$.
  28. 28 If $p(x)\in\mathbb{C}[x]$ is a polynomial which is not equal to $x$, then the polynomial $p(x)-x$ divides the polynomial $p(p(x))-x$.
  29. 29 Let $A$ be a square matrix with non-negative real entries such that the sum of entries in each row of $A$ is $1$. Then each eigenvalue of $A$ has absolute value less than or equal to $1$.
  30. 30 Let $X$ be a metric space having exactly $4$ points. Then, for some positive integer $n$, there exists a distance preserving map $f:X\to\mathbb{R}^n$, where $\mathbb{R}^n$ is equipped with its Euclidean metric.
  31. 31 Let $f:\mathbb{R}\to\mathbb{R}$ be a continuous function. For each positive integer $n$, let $f_n:\mathbb{R}\to\mathbb{R}$ be defined by $f_n(x)=f(x^n)$. If the sequence of functions $(f_n)$ converges uniformly on $\mathbb{R}$, then $f$ must be a constant function.
  32. 32 Let $X,Y$ be finite metric spaces. Then $X$ and $Y$ are homeomorphic if and only if the real vector spaces $C(X,\mathbb{R})$ and $C(Y,\mathbb{R})$ are isomorphic.
  33. 33 Suppose a finite group $G$ is the union of its Sylow subgroups. Then the order of $G$ is a power of some prime number.
  34. 34 For a $2\times2$ real matrix $A$, if the limit \[ \sin(A)=\lim_{N\to\infty}\sum_{n=1}^N(-1)^{n-1}\frac{A^{2n-1}}{(2n-1)!} \] exists in $M_2(\mathbb{R})$, then all eigenvalues of the limit matrix $\sin(A)$ have absolute value less than or equal to $1$.
  35. 35 Let $A$ be a finite abelian group of order $2025$. Then for every subgroup $H\le A$ we have $A\cong H\times A/H$ as groups.
  36. 36 Consider the map $L:\mathbb{R}[t]\to\mathbb{R}[t]$ given by $L(f)=3f+2f'$, where $f'$ denotes the derivative (with respect to $t$) of the polynomial $f$. Then $L$ is injective, but not surjective.
  37. 37 Let $\sigma_1,\ldots,\sigma_{80}$ be elements of the permutation group $S_{236}$ such that $\sigma_i^3$ is the identity permutation for each $i$. Then there exist $1\le i<j\le80$ such that $\sigma_i$ is conjugate to $\sigma_j$.
  38. 38 For a permutation $\sigma\in S_{10}$, let $\mathrm{Fix}(\sigma)\subseteq\{1,2,\ldots,10\}$ denote the set of fixed points of $\sigma$. Then the average $\dfrac1{10!}\displaystyle\sum_{\sigma\in S_{10}}\#\mathrm{Fix}(\sigma)$ is equal to $1$.
  39. 39 The set $X=\{(b,c)\in\mathbb{R}^2\mid\text{the polynomial }x^2+bx+c\text{ has distinct roots in }\mathbb{C}\}$ is connected.
  40. 40 The integer $1^{6n}+2^{6n}+3^{6n}+\cdots+2025^{6n}$ is divisible by $7$ for all integers $n\ge10$.
