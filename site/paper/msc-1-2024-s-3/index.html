MMC-13

Linear Algebra
M.Sc. Mathematics · Semester I2024
  1. 1(a) Let $A\in M_n(F)$ and $\lambda\in F$. Show that $\lambda$ is an eigen value of $A$ if and only if $|A-\lambda I_n|=0$. [3]
  2. 1(b) Let $\lambda$ be an eigen value of a matrix $A\in M_n(F)$. Show that the geometric multiplicity of $\lambda$ is $n-r(A-\lambda I_n)$ [3]
  3. 1(c) Let $X,Y$ be two nonzero column vectors in $\mathbb R^n$ and $A=XY^t$. Show that 0 is an eigen value of $A$ and every eigen vector corresponding to 0 is orthogonal to $Y$. [4]
  4. 2(a) Let $T:V\longrightarrow V$ be a linear operator, $\beta$ be a basis of $V$ and $\lambda$ be an eigen value of $T$. Show that $v\in V$ is an eigen vector of $T$ corresponding to $\lambda$ if and only if $[v]_\beta$ is an eigen vector of $[T]_\beta$ corresponding to $\lambda$. [4]
  5. 2(b) Let $T:M_n(\mathbb R)\longrightarrow M_n(\mathbb R)$ be defined by $T(A)=A^t$. Find all eigen values and eigen spaces of $T$. [3]
  6. 2(c) Let $T:V\longrightarrow V$ be a linear operator. If every nonzero vector of $V$ is an eigen vector of $T$, then show that $T=cI$ for some scalar $c$. [3]
  7. 3(a) Let $T:V\longrightarrow V$ be a linear operator. Prove that the eigen vectors belonging to the distinct eigen values are linearly independent. [4]
  8. 3(b) Let $T:V\longrightarrow V$ be a linear operator and $V$ be a $T$-cyclic space. If a linear operator $S:V\longrightarrow V$ commutes with $T$, then show that $S=g(T)$ for some polynomial $g(t)$. [3]
  9. 3(c) Let $T:V\longrightarrow V$ be a linear operator, $v\in V$ and $W=\langle v\rangle_T$. If $\dim W=k$, then show that $\{v,T(v),\ldots,T^{k-1}(v)\}$ is a basis of $W$. [3]
  10. 4(a) Let $A\in M_n(F)$. If $F^n$ has a basis of eigen vectors of $A$, then show that $A$ is diagonalizable. [3]
  11. 4(b) State and prove the spectral theorem for the diagonalizable linear operators. [4]
  12. 4(c) Show that two reflections $R_1$ and $R_2$ on a vector space are similar if and only if \[\dim E_1(R_1)=\dim E_1(R_2).\] [3]
  13. 5(a) Let $T:V\longrightarrow V$ be a linear operator and $f(t)\in F[t]$ be such that $f(t)=g(t)h(t)$ for some $g(t),h(t)\in F[t]$. If $\gcd(g(t),h(t))=1$, then show that $\ker f(T)=\ker g(T)\oplus\ker h(T)$. [4]
  14. 5(b) Give an example with justification of a non-diagonalizable matrix $A\in M_3(\mathbb R)$ which satisfies $A^k=I_3$ for some $k\in\mathbb N$. [3]
  15. 5(c) Let $X,Y\in\mathbb R^n$ be two nonzero column vectors. If $X\perp Y$, then show that the matrix $A=XY^t$ is not diagonalizable. [3]
  16. 6(a) Let $T:V\longrightarrow V$ and $\beta=\{v_1,v_2,\ldots,v_n\}$ be a basis of $V$. Then prove that $[T]_\beta$ is upper triangular if and only if $T(v_j)\in\operatorname{span}(\{v_1,v_2,\ldots,v_j\})$ for all $1\leq j\leq n$. [4]
  17. 6(b) Let $T:V\longrightarrow V$ and $\chi_T(t)=(t-\lambda_1)^{n_1}(t-\lambda_2)^{n_2}\cdots(t-\lambda_k)^{n_k}$ where $\lambda_1,\lambda_2,\ldots,\lambda_k$ are distinct eigen values of $T$. Show that $\dim(T-\lambda_i I)^{n_i}=n_i$ for all $1\leq i\leq k$. [3]
  18. 6(c) Find all possible Jordan canonical forms of a linear operator $T$ such that $\chi_T(t)=(t-2)^5$ and $m(t)=(t-2)^2$. In each case find $\dim E_2$. \endgroup \textbf{Use separate answer script for each unit}\par [3]
