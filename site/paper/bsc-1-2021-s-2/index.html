CC-1

Analysis-I
B.Sc. Mathematics · Semester I2021
  1. 1(a) Give $(\epsilon-\delta)$ definition of the limit of a function and hence evaluate $\lim_{x\to5}f(x)$ where $f(x)=x^3+3x-10$, $x\in[4,10]$. Find $\delta$ if $\epsilon=0.5$. [[5]]
  2. 1(b) If $\lim_{x\to a}f(x)=l$ and $\lim_{x\to a}g(x)=m$, then prove that $\lim_{x\to a}f(x)g(x)=lm$. [[5]]
  3. 2(a) Prove that a function $f:[a,b]\to\mathbb R$ is continuous iff for any $c\in[a,b]$ and for any sequence $\{x_n\}\in[a,b]$ converging to $c$, $\{f(x_n)\}$ converges to $f(c)$. [[5]]
  4. 2(b) Find the value of $\lim_{n\to\infty}\left\{\frac1{\sqrt{n^2+1}}+\frac1{\sqrt{n^2+2}}+\cdots+\frac1{\sqrt{n^2+n}}\right\}$. [[5]]
  5. 3(a) If a sequence $\{x_n\}$ converges to $l$ then prove that the sequence $\{y_n\}$ where $y_n=\frac{x_1+x_2+\cdots+x_n}n$ converges to $l$. [[5]]
  6. 3(b) Evaluate $\lim_{n\to\infty}\frac1n\{(a+1)(a+2)\cdots(a+n)\}^{\frac1n}$ if $a>0$. [[5]]
  7. 4(a) Define Cauchy sequence and give an example for the same. Prove that every Cauchy sequence is bounded. Does the converse hold? Justify. [[5]]
  8. 4(b) Examine if the sequence $x_n=1-\frac12+\frac13+\cdots+\frac{(-1)^{n+1}}n$ is a Cauchy sequence. [[5]]
  9. 5(a) State and Prove Lagrange's Mean Value Theorem. [[5]]
  10. 5(b) From the relation $f(x+h)=f(x)+hf'(x+\theta h)$, show that $\theta$ is independent on $x$ for $f(x)=a+bx+cm^x$ where $a,b,c,m$ are constants. [[3]]
  11. 5(c) If $f'(x)=0$ for all values of $x$ in an interval then prove that $f(x)$ is constant in that interval. [[2]]
  12. 6(a) Let $S$ be a non-empty bounded subset of $\mathbb R$ with $supS=M$ and $infS=m$. Find $SupT$ and $InfT$ where $T=\{x-y:x\in S,y\in S\}$. [[4]]
  13. 6(b) Let $x,y\in\mathbb R$ and $x<y$. Then prove that\\(i) there is a rational number $r$ such that $x<r<y$.\\(ii) there is an irrational number $s$ such that $x<s<y$. [[3+1]]
  14. 6(c) Find $SupA$ and $InfA$ where $A=\left\{\frac1m+\frac1n:m,n\in\mathbb N\right\}$. [[2]]
  15. 7(a) Find $y_n$ where $y=e^{ax}\cos bx$. [[4]]
  16. 7(b) If $y=\sin(m\sin^{-1}x)$, prove that\\(i) $(1-x^2)y_2=xy_1-m^2y$\\(ii) $(1-x^2)y_{n+2}-(2n+1)xy_{n+1}+(m^2-n^2)y_n=0$ [[2+4]]
  17. 8(a) Evaluate $\lim_{x\to0}\left(\frac{\sin x}x\right)^{\frac1x}$. [[4]]
  18. 8(b) Find the values of $a,b,c$ so that $\lim_{x\to0}\frac{(a+b\cos x)x-c\sin x}{x^5}=1$. [[6]]
  19. 9(a) Obtain a reduction formula for $\int\cos^mx\sin nx\,dx$ and hence deduce the value of $\int_0^{\frac\pi2}\cos^5x\sin3x\,dx$. [[6]]
  20. 9(b) A function $f:[0,1]\to\mathbb R$ is continuous on $[0,1]$ and $f$ assumes only rational values on $[0,1]$. Prove that $f$ is a constant function. [[4]]
