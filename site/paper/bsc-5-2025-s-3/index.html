MJMA-13

Numerical Analysis
B.Sc. Mathematics · Semester V2025
  1. 1 Answer any ten questions: [$10\times2=20$]
  2. 1(i) State the reasons for which loss of significant digits occurs.
  3. 1(ii) Find the decimal equivalent to the following floating point machine number: 1 10000100 10100001111000000000000
  4. 1(iii) State Weierstrass Approximation Theorem.
  5. 1(iv) Compute the value of $x$ for $y=3.55$ by using the following table: \begin{center}\begin{tabular}{|c|c|c|c|c|}\hline$x$&0&1&2&3\\\hline$f(x)$&3&6&11&18\\\hline\end{tabular}\end{center}
  6. 1(v) Taking $h=2$, what will be the numerical value of $\Delta^{10}[(1-ax)(1-bx^2)(1-cx^3)(1-dx^4)]$? ($a,b,c,d$ are constants).
  7. 1(vi) Find $y_0$, given that $y_1=5,y_2=11,y_3=18,y_4=26$ and $y_5=37$.
  8. 1(vii) Why do we need to study numerical differentiation?
  9. 1(viii) Explain geometrically why does Simpson's $\frac13$rd rule call a parabolic rule.
  10. 1(ix) Find the constants $c_0,c_1$ and $x_1$ so that the quadrature formula $\int_0^1f(x)dx=c_0f(0)+c_1f(x_1)$ has the highest possible degree of precision.
  11. 1(x) State one advantage and one disadvantage of Newton-Raphson method.
  12. 1(xi) Find the number of iterations needed in the bisection method to obtain an approximation with accuracy $10^{-5}$ to the solution of $x^3+4x^2-10=0$ lying in the interval $[1,2]$.
  13. 1(xii) List the differences between partial pivoting and complete pivoting in solving system of linear equations.
  14. 1(xiii) Find all values of $\alpha$ and $\beta$ for which the following matrix is strictly diagonally dominant. $A=\begin{bmatrix}\alpha&1&0\\\beta&2&1\\0&1&2\end{bmatrix}$
  15. 1(xiv) What do you mean by single step method in numerically solving an IVP? Explain with an example.
  16. 1(xv) Compute $y(1.1)$, from the initial value problem $y'=xy,\ y(1.0)=2$, taking $h=0.1$, by Taylor's series method, correct to three decimal places.
  17. 2(a) What do you mean by significant figure of an approximate number? State the rules of significant figures with suitable examples. [1+4]
  18. 2(b) If $u=xyz^2+\frac32x^3y^5$ and errors in $x,y,z$ are $0.005,0.001,0.001$ respectively at $x=3,y=z=1$, compute the maximum absolute and relative errors in evaluating $u$. [3]
  19. 2(c) Find the sum of the approximate numbers $1.3719,29.086,88.61,36.1993,11.8$, which are correct upto the indicated number of digits. Give proper justification in support of your answer. [2]
  20. 3(a) Show that $\cosh\left(\frac{hD}2\right)\equiv1+\frac{\delta^2}4$ [3]
  21. 3(b) Determine the step size $h$ and number of points $n$ to be used in the tabulation of $f(x)=\cos x$ in the interval $[1,2]$ so that the quadratic interpolation will be correct to six decimal places. [3]
  22. 3(c) What do you mean by `round-off errors' in numerical data? Show how these errors propagated in a difference table. List your observations from the difference table. [4]
  23. 4(a) Derive Newton's backward difference formula from Generalized Newton's divided difference interpolation formula. [5]
  24. 4(b) Using Lagrange's interpolation formula, express the following function as sum of partial fractions. $f(x)=\frac{x^2+6x+1}{x^4-10x^3+23x^2+10x-24}$ [5]
  25. 5(a) Derive a formula for the third order derivative of the function $y=f(x)$ from Newton's forward difference interpolation formula and hence obtain $f^{\prime\prime\prime}(1.5)$ from the following table: \begin{center}\begin{tabular}{|c|c|c|c|c|c|c|}\hline$x$&1.5&2.0&2.5&3.0&3.5&4.0\\\hline$f(x)$&3.375&7.000&13.625&24.000&38.875&59.000\\\hline\end{tabular}\end{center} [3+2]
  26. 5(b) Define confluent divided difference. Show that $f[x,x,\cdots,x,x_0,x_1,\cdots,x_n]=\frac1{k!}\frac{d^k}{dx^k}f[x,x_0,x_1,\cdots,x_n]$, where $x$ occurs $(k+1)$ times in the argument of $f[x,x,\cdots,x,x_0,x_1,\cdots,x_n]$. [1+4]
  27. 6(a) Establish Trapezoidal rule from Newton-Cotes quadrature formula (closed type). Estimate the error involved in this rule. [2+4]
  28. 6(b) Write down the quadratic polynomial which takes the same values as $f(x)$ at $x=-1,0,1$ and integrate it to obtain the quadrature formula $\int_{-1}^1f(x)dx=\frac13[f(-1)+4f(0)+f(1)]$. Assuming the error to have the form $Kf^{iv}(\xi)$, $-1<\xi<1$, find the value of the constant $K$. [4]
  29. 7(a) Show that in secant method for root finding, the error in the $(n+1)$th iterate is approximately proportional to the product of the errors of the $n$th and the $(n-1)$th iterate. Hence show that the order of convergence for secant method is $\frac{1+\sqrt5}2$. [3+3]
  30. 7(b) Find the smallest positive root of the equation $(1+x^2)\tan x=3x$ by fixed point iteration method, correct to 5-significant figures. [4]
  31. 8(a) The function defined by $f(x)=\sin\pi x$ has zeros at every integer. Show that when $-1<a<0$ and $2<b<3$, the Bisection method converges to (i) 0, if $a+b<2$ (ii) 2, if $a+b>2$ (iii) 1, if $a+b=2$. [5]
  32. 8(b) Carry out the total operational count required for solving a system of $n$ linear equations in $n$ unknowns by Gaussian elimination method. [5]
  33. 9(a) Find an expression for the iteration matrix $Q_{SOR}$ by successive over-relaxation (SOR) method $\vec x^{(k+1)}=Q_{SOR}\vec x^{(k)}+\vec c,k\ge0$ for solving the linear algebraic system of equations given by the single matrix equation $A\vec x=\vec b$. Hence derive SOR method in its error format. [3+2]
  34. 9(b) Find an $LU$ factorization of the following matrix without using elementary matrices while finding $L$. $A=\begin{pmatrix}3&2&-3\\2&2&5\\1&1&-1\end{pmatrix}$ [5]
  35. 10(a) Derive the Modified Euler's method for solving the initial value problem $\frac{dy}{dx}=f(x,y),\ y(x_0)=y_0$. [5]
  36. 10(b) Compute $y(0.3)$, from the initial value problem $\frac{dy}{dx}=y+\sin x+\ln(x+y),\ y(0)=1.0$, taking $h=0.1$, by Runge-Kutta method of fourth order, correct to four decimal places. [5]
