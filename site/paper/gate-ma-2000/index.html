GATE Mathematics · Mathematics (MA), 2000

  1. 1.1 Let $W$ be the space spanned by $f = \sin x$ and $g = \cos x$. Then for any real value of $\theta$, $f_1 = \sin(x+\theta)$ and $g_1 = \cos(x+\theta)$ \begin{enumerate}[label=(\alph*)] \item are vectors in $W$ \item are linearly independent \item do not form a basis for $W$ \item form a basis for $W$ \end{enumerate}
  2. 1.2 Consider the basis $S = \{v_1, v_2, v_3\}$ for $\mathbb{R}^3$ where $v_1 = (1,1,1)$, $v_2 = (1,1,0)$, $v_3 = (1,0,0)$, and let $T : \mathbb{R}^3 \to \mathbb{R}^2$ be a linear transformation such that $Tv_1 = (1,0)$, $Tv_2 = (2,-1)$, $Tv_3 = (4,3)$. Then $T(2,-3,5)$ is \begin{enumerate}[label=(\alph*)] \item $(-1,5)$ \item $(3,4)$ \item $(0,0)$ \item $(9,23)$ \end{enumerate}
  3. 1.3 For $0 < \theta < \pi$, the matrix \[ \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix} \] \begin{enumerate}[label=(\alph*)] \item has no real eigenvalue \item is orthogonal \item is symmetric \item is skew symmetric \end{enumerate}
  4. 1.4 For the function $f(z) = \dfrac{1 - e^{-z}}{z}$, the point $z = 0$ is \begin{enumerate}[label=(\alph*)] \item an essential singularity \item a pole of order zero \item a pole of order one \item a removable singularity \end{enumerate}
  5. 1.5 The transformation $w = e^{i\theta}\!\left(\dfrac{z - p}{\bar{p}z - 1}\right)$, where $p$ is a constant, maps $|z| < 1$ onto \begin{enumerate}[label=(\alph*)] \item $|w| < 1$ if $|p| < 1$ \item $|w| > 1$ if $|p| > 1$ \item $|w| = 1$ if $|p| = 1$ \item $|w| = 3$ if $p = 0$ \end{enumerate}
  6. 1.6 The value of the integral $\displaystyle\oint_C \frac{dz}{z^2 - 1}$, $C : |z| = 4$, is equal to \begin{enumerate}[label=(\alph*)] \item $\pi i$ \item $0$ \item $-\pi i$ \item $2\pi i$ \end{enumerate}
  7. 1.7 Let $E$ be the set of all rationals $p$ such that $2 < p^2 < 3$. Then $E$ is \begin{enumerate}[label=(\alph*)] \item compact in $\mathbb{Q}$ \item closed and bounded in $\mathbb{Q}$ \item not compact in $\mathbb{Q}$ \item closed and unbounded in $\mathbb{Q}$ \end{enumerate}
  8. 1.8 Let $A$ be the set of points in the interval $(0,1)$ representing the numbers whose expansion as infinite decimals do not contain the digit $7$. Then the measure of $A$ is \begin{enumerate}[label=(\alph*)] \item $1$ \item $0$ \item $\dfrac{1}{2}$ \item $\infty$ \end{enumerate}
  9. 1.9 The Fourier expansion in the interval $[-4, 4]$ of the function \[ f(x) = \begin{cases} -x, & -4 \le x \le 0, \\ x, & 0 \le x \le 4, \end{cases} \] has \begin{enumerate}[label=(\alph*)] \item no cosine term \item no sine term \item both cosine and sine terms \item none of these \end{enumerate}
  10. 1.10 The particular solution of the equation $y'\sin x = y\ln y$ satisfying the initial condition $y\!\left(\dfrac{\pi}{2}\right) = e$, is \begin{enumerate}[label=(\alph*)] \item $e^{\tan(x/2)}$ \item $e^{\cot(x/2)}$ \item $\ln\tan\!\left(\dfrac{x}{2}\right)$ \item $\ln\cot\!\left(\dfrac{x}{2}\right)$ \end{enumerate}
  11. 1.11 The differential equation $\dfrac{dy}{dx} = k(a - y)(b - y)$, when solved with the condition $y(0) = 0$, yields the result \begin{enumerate}[label=(\alph*)] \item $\dfrac{b(a-y)}{a(b-y)} = e^{(a-b)kx}$ \item $\dfrac{b(a-x)}{a(b-x)} = e^{(b-a)ky}$ \item $\dfrac{a(b-y)}{b(a-y)} = e^{(a-b)kx}$ \item $xy = ke$ \end{enumerate}
  12. 1.12 The Sturm--Liouville problem $y'' + \lambda^2 y = 0$, $y'(0) = 0$, $y'(\pi) = 0$ has its eigenvectors given by $y =$ \begin{enumerate}[label=(\alph*)] \item $\sin\!\left(n + \dfrac{1}{2}\right)x$ \item $\sin nx$ \item $\cos\!\left(n + \dfrac{1}{2}\right)x$ \item $\cos nx$; where $n = 0, 1, 2, \dots$ \end{enumerate}
  13. 1.13 Let $G$ be the additive group of integers $I$ and $G'$ be the multiplicative group of the fourth roots of unity. Let $f : G \to G'$ be a homomorphism mapping given by $f(n) = i^n$, where $i = \sqrt{-1}$. Then the Kernel of $f$ is \begin{enumerate}[label=(\alph*)] \item empty set \item $\{4m : m \in I\}$ \item $\{(2m)^2 + 1 : m \in I\}$ \item $\{2m + 1 : m \in I\}$ \end{enumerate}
  14. 1.14 If $A$ is the subspace of $l^\infty$ consisting of all sequences of zeros and ones and $d$ is the induced metric on $A$, then the rare sets in $(A, d)$ are \begin{enumerate}[label=(\alph*)] \item empty set \item all singleton subsets of $A$ \item power set of $A$ \item set $A$ itself \end{enumerate}
  15. 1.15 The norm of the linear functional $f$ defined on $C[-1,1]$ by \[ f(x) = \int_{-1}^{0} x(t)\,dt - \int_{0}^{1} x(t)\,dt \] is \begin{enumerate}[label=(\alph*)] \item zero \item one \item two \item three \end{enumerate} where $C[-1,1]$ denotes a Banach space of all real-valued functions $x(t)$ on $[-1,1]$ with norm given by $\|x\| = \max_{t \in [-1,1]} |x(t)|$.
  16. 1.16 The smallest value of $x$ ($|x| < 1$) correct to two decimal places satisfying the equation \[ x - \frac{x^3}{3} + \frac{x^5}{10} - \frac{x^7}{42} + \frac{x^9}{216} - \frac{x^{11}}{1320} + \dots = 0.4431135 \] is \begin{enumerate}[label=(\alph*)] \item $0.58$ \item $0.47$ \item $0.44$ \item $0.88$ \end{enumerate}
  17. 1.17 The Jacobi's iteration method for the set of equations \[ x_1 + ax_2 = 2, \qquad 2ax_1 + x_2 = 7, \qquad \left(a \ne \frac{1}{\sqrt{2}}\right) \] converges for \begin{enumerate}[label=(\alph*)] \item all values of $a$ \item $a = 1$ \item $|a| < \dfrac{1}{\sqrt{2}}$ \item $\dfrac{1}{\sqrt{2}} < a < \sqrt{\dfrac{3}{2}}$ \end{enumerate}
  18. 1.18 The interpolating polynomial of highest degree which corresponds to the functional values $f(-1) = 9$, $f(0) = 5$, $f(2) = 3$, $f(5) = 15$, is \begin{enumerate}[label=(\alph*)] \item $x^3 + x^2 + 2x + 5$ \item $x^2 - 3x + 5$ \item $x^4 + 4x^3 + 5x^2 + 5$ \item $x + 5$ \end{enumerate}
  19. 1.19 The equation $x^2(y - 1)Z_{xx} - x(y^2 - 1)Z_{xy} + y(y^2 - 1)Z_{yy} + Z_x = 0$ is hyperbolic in the entire $xy$-plane except along \begin{enumerate}[label=(\alph*)] \item $x$-axis \item $y$-axis \item a line parallel to $y$-axis \item a line parallel to $x$-axis \end{enumerate}
  20. 1.20 The solution of the Cauchy problem $u_{yy}(x,y) - u_{xx}(x,y) = 0$; $u(x,0) = 0$, $u_y(x,0) = x$ is $u(x,y) =$ \begin{enumerate}[label=(\alph*)] \item $\dfrac{x}{y}$ \item $xy$ \item $xy + \dfrac{x}{y}$ \item $0$ \end{enumerate}
  21. 1.21 The characteristic curves of the equation $x^2 u_{xx} - y^2 u_{yy} = x^2 y^2 + x$; $x > 0$, $u = u(x,y)$ are \begin{enumerate}[label=(\alph*)] \item rectangular hyperbola \item parabola \item circle \item straight line \end{enumerate}
  22. 1.22 The number of generalized coordinates for a pair of scissors that can move in a plane is \begin{enumerate}[label=(\alph*)] \item $1$ \item $2$ \item $3$ \item $4$ \end{enumerate}
  23. 1.23 The topology $\tau$ on the real line $\mathbb{R}$ generated by the class $\mathcal{I}$ of all closed intervals $[d, d+1]$ with length $1$ is \begin{enumerate}[label=(\alph*)] \item indiscrete \item discrete \item standard topology \item neither discrete nor Hausdorff \end{enumerate}
  24. 1.24 Let norms $\|x\|_1 = \sum_{i=1}^n |\xi_i|$ and $\|x\|_2 = \left(\sum_{i=1}^n |\xi_i|^2\right)^{1/2}$ induce topologies $\tau_1$ and $\tau_2$ on $\mathbb{R}^n$, the $n$-dimensional Euclidean space, then \begin{enumerate}[label=(\alph*)] \item $\tau_1$ is weaker than $\tau_2$ \item $\tau_1$ is stronger than $\tau_2$ \item $\tau_1$ is equivalent to $\tau_2$ \item $\tau_1$ and $\tau_2$ are incomparable \end{enumerate}
  25. 1.25 The probability that exactly one of the events $E$ or $F$ occurs is equal to \begin{enumerate}[label=(\alph*)] \item $P(E) + P(F) - P(EF)$ \item $P(E) + P(F) - 2P(EF)$ \item $P(EF^c) + P(E^c F)$ \item $P(E) + P(F)$ \end{enumerate}
  26. 1.26 If $\{A_n, n \ge 1\}$ is a sequence of events, then $\lim_{n\to\infty} P(A_n) = P\!\left(\lim_{n\to\infty} A_n\right)$ if \begin{enumerate}[label=(\alph*)] \item $\{A_n\}$ is an increasing sequence of events \item $\{A_n\}$ is a decreasing sequence of events \item $\{A_n\}$ is neither increasing nor decreasing sequence of events \item none of these \end{enumerate}
  27. 1.27 Suppose that the five random variables $X_1, \dots, X_5$ are independent and each has standard normal distribution. A constant $C$ such that the random variable \[ \frac{C(X_1 + X_2)}{(X_3^2 + X_4^2 + X_5^2)^{1/2}} \] will have a $t$-distribution, has the value \begin{enumerate}[label=(\alph*)] \item $\dfrac{\sqrt{3}}{2}$ \item $\sqrt{\dfrac{3}{2}}$ \item $\dfrac{3}{2}$ \item [\textit{missing in scan}] \end{enumerate}
  28. 1.28 Suppose that $X_1, \dots, X_n$ are random variables such that the variance of each variable is $1$ and the correlation between each pair of different variables is $\dfrac{1}{4}$. Then $\operatorname{Var}(X_1 + X_2 + \dots + X_n)$ is \begin{enumerate}[label=(\alph*)] \item $\dfrac{n(n+1)}{2}$ \item $\dfrac{n(n+2)}{4}$ \item $\dfrac{n(n+3)}{4}$ \item $\dfrac{n(n+3)}{2}$ \end{enumerate}
  29. 1.29 The objective function of the dual problem for the following primal linear programming problem: \begin{align*} \text{Maximize } & f = 2x_1 + x_2 \\ \text{subject to } & x_1 - 2x_2 \ge 2, \\ & x_1 + 2x_2 = 8, \\ & x_1 - x_2 \le 11, \end{align*} with $x_1 \ge 0$ and $x_2$ unrestricted in sign, is given by \begin{enumerate}[label=(\alph*)] \item minimize $z = 2y_1 - 8y_2 + 11y_3$ \item minimize $z = 2y_1 + 8y_2 + 11y_3$ \item minimize $z = 2y_1 - 8y_2 - 11y_3$ \item minimize $z = 2y_1 + 8y_2 - 11y_3$ \end{enumerate}
  30. 1.30 If $y(t) = 1 + \displaystyle\int_0^t y(v) e^{-(t-v)}\,dv$, then $y(t)$ at $t = 1$ equals \begin{enumerate}[label=(\alph*)] \item $0$ \item $1$ \item $2$ \item $3$ \end{enumerate}
  31. 2.1 Expand the function $f(z) = \dfrac{1}{3 - 2z}$ in powers of $(z - 3)$ and find the radius of convergence of the series so obtained.
  32. 2.2 Develop the Hamiltonian and hence obtain the canonical equations of motion for a system for which the Lagrangian is $L = \dfrac{1}{2}m\dot{q}^2 - \dfrac{\mu}{2}q^2$, where $\dot{q} = \dfrac{dq}{dt}$, $q$ being the generalized co-ordinate of the system.
  33. 2.3 Evaluate $\displaystyle\int_0^{\pi/2} \sqrt{1 - 0.162\sin^2\phi}\,d\phi$ by Simpson's one-third rule by taking the step size as $\dfrac{\pi}{12}$.
  34. 2.4 Show that in an inner product space, $x \perp y$ ($x$ is orthogonal to $y$) if and only if we have $\|x + \alpha y\| = \|x - \alpha y\|$ for all scalars $\alpha$.
  35. 2.5 Let $X$ and $Y$ have joint probability density function \[ f_{X,Y}(x,y) = 2e^{-(x+y)}, \qquad 0 < x < y, \quad 0 < y < \infty. \] Find $P(Y < 3X)$.
  36. 3 Solve the following linear programming problem using the Simplex method: \hfill [5] \begin{align*} \text{Minimize } & f = -40x_1 - 100x_2 \\ \text{subject to } & 10x_1 + 5x_2 \le 2500, \\ & 4x_1 + 10x_2 \le 2000, \\ & 2x_1 + 3x_2 \le 900, \\ & x_1 \ge 0, \quad x_2 \ge 0. \end{align*}
  37. 4 Evaluate the integral $\displaystyle\int_C \frac{e^{1/z^2}}{z^2 + 1}\,dz$, $C : |z - i| = \frac{7}{2}$, where integration is to be taken counterclockwise. \hfill [5]
  38. 5 \begin{itemize} \item[(a)] Construct an analytic function $f(z)$ of which the real part is $u(x,y) = 2xy + \cosh x \sin y$, given that $f(0) = 0$. \hfill [2] \item[(b)] Determine all harmonic functions of the form $u = f\!\left(\dfrac{x^2 + y^2}{x}\right)$ that are not constant. \hfill [3] \end{itemize}
  39. 6 Evaluate $\displaystyle\iint_S (\operatorname{curl}\mathbf{v}) \cdot \mathbf{n}\,dS$, where $\mathbf{v} = 2y\mathbf{i} + 3x\mathbf{j} - z^2\mathbf{k}$ and $S$ is the upper half surface of the sphere $x^2 + y^2 + z^2 = 9$, $\mathbf{n}$ is a positive unit normal vector to $S$, and $C$ is its boundary. \hfill [5]
  40. 7 \begin{itemize} \item[(a)] Examine the series $\displaystyle\sum_{n=1}^{\infty} \frac{nx}{n+x}$, $x \in [0,1]$, as regards to its uniform convergence on the domain $0 \le x \le 1$. \hfill [3] \item[(b)] Prove that the set of points on which a sequence of measurable functions $(f_n)$ converges is measurable. \hfill [2] \end{itemize}
  41. 8 Use the Laplace transform procedure to solve the initial value problem: \hfill [5] \[ t y''(t) + y'(t) + t y(t) = 0; \qquad y(0) = 1, \quad y'(0) = k \quad (k \text{ is a constant}). \]
  42. 9 Construct the Green's function for the boundary value problem: \hfill [5] \[ y''(x) + y(x) = -1; \qquad y(0) = 0, \quad y\!\left(\frac{\pi}{2}\right) = 0, \] and hence solve the equation.
  43. 10 Prove that the set $A$ of all $2 \times 2$ matrices of the form $\begin{bmatrix} a & 0 \\ b & 0 \end{bmatrix}$, where $a, b \in I$ (the set of integers), is a left ideal but not a right ideal in the ring $R$ of all $2 \times 2$ matrices over $I$. \hfill [5]
  44. 11 Show that if $p$ is a prime number, then any group $G$ of order $2p$ has a normal subgroup of order $p$. \hfill [5]
  45. 12 If $(x_n)$ in a Banach space $(X, \|\cdot\|)$ is such that $(f(x_n))$ is bounded for all $f \in X'$, the dual of $X$, then using the uniform boundedness theorem, show that $(\|x_n\|)$ is bounded. \hfill [5]
  46. 13 Let $X$ be the normed space whose points are sequences of complex numbers $x = (\xi_j)$ with only finitely many non-zero terms and norm defined by $\|x\| = \sup_j |\xi_j|$. Let $T : X \to X$ be defined by \[ y = Tx = \left(\xi_1, \frac{1}{2}\xi_2, \frac{1}{3}\xi_3, \dots\right). \] Show that $T$ is linear and bounded, but $T^{-1}$ is unbounded. Does this contradict the open mapping theorem? \hfill [5]
  47. 14 Determine the step-size that can be used to evaluate the integration $\displaystyle\int_1^2 \frac{dx}{x}$ by using Simpson's one-third rule so that the truncation error is less than $5 \times 10^{-4}$, and hence evaluate the integral. \hfill [5]
  48. 15 Solve $\dfrac{d^2y}{dx^2} = x\dfrac{dy}{dx} - y$; $y(0) = 3$, $y'(0) = 0$, to approximate $y(0.1)$ by using the fourth order Runge--Kutta method. \hfill [5]
  49. 16 Use Lagrange's method to solve the equation \hfill [5] \[ \begin{vmatrix} x & y & z \\ a & b & c \\ \dfrac{\partial z}{\partial x} & \dfrac{\partial z}{\partial y} & -1 \end{vmatrix} = 0, \] where $z = z(x,y)$.
  50. 17 \begin{itemize} \item[(a)] Reduce the equation $u_{xx}(x,y) - u_{yy}(x,y) - \dfrac{2}{x}u_x = 0$ to a possible canonical form. \hfill [3] \item[(b)] Reduce the following heat conduction problem with non-homogeneous boundary conditions: \hfill [2] \begin{align*} u_t(x,t) - u_{xx}(x,t) &= 0; \qquad 0 < x < \pi, \quad t > 0, \\ u(0,t) = 0, \quad u(\pi,t) &= 10, \\ u(x,0) &= f(x), \end{align*} to a problem with homogeneous boundary conditions. \end{itemize}
  51. 18 \begin{itemize} \item[(a)] A smooth circular wire rotates with constant angular velocity $\omega$ about the vertical axis $CA$ which lies on the plane of the circle and passes through the point $C$ on the diameter of the circle such that the distance $CO = d$, where $O$ is the centre of the circle. A particle $P$ slides on the wire. Taking $PC = R$ and $\angle PCA = \theta$, develop the Lagrangian of the system and hence the equations of motion if the generalized force-components are $Q_R$ and $Q_\theta$. \hfill [3] \item[(b)] A system moves in a force-free space with kinetic energy given by $T = q_i \dot{q}_i - \sqrt{1 - \dot{q}_i^2}$, where $q_i$ are the generalized coordinates of the system and $\dot{q}_i$ are the generalized velocity components. Show that the generalized accelerations $\ddot{q}_i$ vanish. \hfill [2] \end{itemize}
  52. 19 Let $A$ be a subset of a topological space $(X, \tau)$ and $\tau_A$ be the relative topology on $A$. Then $A$ is $\tau$-connected if and only if $A$ is $\tau_A$-connected. Prove this. \hfill [5]
  53. 20 Let $X_1, X_2, \dots, X_n$ be a random sample from a Poisson distribution with parameter $\theta > 0$. Find the uniformly minimum variance unbiased estimator (UMVUE) of $P(X \le 1) = (1 + \theta)e^{-\theta}$. \hfill [5]
  54. 21 Let $X_1, X_2, \dots, X_n$ be a random sample from a distribution that is normally distributed with mean $\theta_1$ and variance $\theta_2$. Find a best test of the simple hypothesis $H_0 : \theta_1 = 0, \theta_2 = 1$ against the alternative simple hypothesis $H_1 : \theta_1 = 1, \theta_2 = 4$. \hfill [5]
  55. 22 \begin{itemize} \item[(a)] Solve the integral equation $y(t) = t^2 + \dfrac{1}{2}\displaystyle\int_0^t y(v)\sin(t - v)\,dv$. \hfill [3] \item[(b)] Use the Euler--Lagrange condition to show that the shortest distance between two points in a plane is a straight line. \hfill [2] \end{itemize}
