MMC-22

Topology
M.Sc. Mathematics · Semester II2016
  1. 1(a) If $\alpha,\beta$ and $\gamma$ be cardinal numbers, prove that\\(i) $\alpha^{\beta+\gamma}=\alpha^{\beta}\alpha^{\gamma}$\\(ii) $(\alpha^{\beta})^{\gamma}=\alpha^{\beta\gamma}$ [2+2]
  2. 1(b) If $\mathbb{N}$ denotes the set of natural numbers and $\mathbb{R}$ denotes the set of real numbers then prove that (i) $\overline{\overline{2^{\mathbb{N}}}}=\overline{\overline{\mathbb{R}}}$ \quad (ii) $\overline{\overline{\mathbb{R}^{\mathbb{N}}}}=\overline{\overline{\mathbb{R}}}$ [5+1]
  3. 2(a) A necessary and sufficient condition that a family $\mathcal{B}$ of subsets of $X$ forms a base for some topology on $X$. Check whether the collection of closed intervals of the form $[a,b]$, $a,b\in\mathbb{R}$, $a<b$, forms a base for some topology on $\mathbb{R}$. [4+2]
  4. 2(b) Prove that a set in a topological space is open iff it is a neighbourhood of each of its points. [2]
  5. 2(c) Find the interior of the set $[0,1]$ in the lower limit topology on $\mathbb{R}$. [2]
  6. 3(a) Let $f$ be a function from a topological space $(X,\tau)$ to a topological space $(Y,\nu)$. Show that $f$ is continuous iff for any set $A$ in $X$, $f(\overline{A})\subset\overline{f(A)}$. [3]
  7. 3(b) If $f$ and $g$ be two continuous functions from a topological space $(X,\tau)$ to a Hausdorff topological space $(Y,\nu)$ and if $f=g$ over dense subset of $X$ then prove that $f=g$ over $X$. [3]
  8. 3(c) Prove that every closed surjective continuous function is a quotient function. Is every quotient map open (or closed)? Answer with justification. [2+2]
  9. 4(a) Prove that a set in the space of reals with usual topology is connected iff it is an interval. [5]
  10. 4(b) Prove that continuous image of a connected set is connected. Hence show that a continuous real valued function defined over a connected set possesses intermediate value property. [3+2]
  11. 5(a) Prove that a bijective mapping from a compact space to a Hausdorff space is a homeomorphism. Is the result true if Hausdorffness is replaced by $T_1$ property? Answer with reasons. [3+2]
  12. 5(b) Prove that a closed subset of a compact space is compact. Give an example of a compact set which is not closed. If however the space is Hausdorff then show that every compact set is closed. [2+1+2]
  13. 6(a) Prove that a regular Lindel\"of space is normal. [6]
  14. 6(b) Prove that a second countable space is separable. Does the converse hold? Answer with proper reasons. [2+2]
